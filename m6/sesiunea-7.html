Introducere

Până acum, toate programele tale au prelucrat valorile pe măsură ce erau citite: fiecare număr era adunat, comparat cu maximul, numărat, apoi dispărea, pentru că singura lui „casă” era variabila x, rescrisă la următoarea citire. Așa ai putut număra, aduna și afla maximul. În sesiunea 6 am observat însă și limitele acestei abordări: nu poți reparcurge o secvență deja citită, nu o poți ordona și nu poți afișa cifrele unui număr în ordinea corectă atunci când ele sunt obținute în ordine inversă.

Ai putea declara câte o variabilă pentru fiecare valoare, dar pentru 1000 de numere ar trebui 1000 de nume, iar o buclă nu poate parcurge nume diferite. Vectorul rezolvă problema: este un singur nume pentru un grup de variabile de același tip, așezate una după alta în memorie și numerotate. Numărul de ordine, indicele, este o valoare obișnuită, deci poate fi variat de o buclă for. Această sesiune arată cum se declară și cum se parcurge un vector, cum se transformă tiparele din S6 în algoritmi pe vectori și cum se rezolvă, în sfârșit, problemele pe care S6 le lăsase deschise: reparcurgerea, inversarea, sortarea și conversia în altă bază.

Punct cheie

Un vector nu schimbă ideile din S5 și S6: bucla, contorul, maximul și indicatorul rămân la fel. Se schimbă faptul că valorile rămân în memorie și pot fi folosite de oricâte ori, în orice ordine. Singura regulă nouă, dar esențială, este că elementele se numără de la 0, iar C++ nu verifică dacă un indice este valid.

Ce nu dezvoltăm în această sesiune

Toate programele rămân în main: nu folosim funcții definite de utilizator, deci nici nu transmitem vectori către funcții. Nu tratăm tablourile cu mai multe dimensiuni (matricele) și nici șirurile de caractere. Nu folosim nici tipul std::vector și nici funcții de bibliotecă precum sort: scopul sesiunii este să înțelegi algoritmii, iar acestea ar ascunde tocmai ce trebuie învățat.

Ce este un vector

Un vector (numit și tablou unidimensional, în engleză array) este o colecție de elemente de același tip, memorate unul după altul în memorie și accesate printr-un nume comun și un indice. Dacă v este un vector de numere întregi, v[0] este primul său element, v[1] al doilea, și așa mai departe. Fiecare element se comportă exact ca o variabilă obișnuită: îi poți citi valoarea, îl poți modifica, îl poți folosi în expresii.

Trei proprietăți fac vectorul foarte util. Toate elementele au același tip, deci ocupă același spațiu și se pot prelucra uniform. Elementele sunt memorate consecutiv, iar pentru acest motiv calculatorul ajunge la v[i] direct, printr-un calcul simplu pe baza adresei de început, fără să parcurgă elementele dinainte. În sfârșit, indicele poate fi orice expresie întreagă, de exemplu v[i], v[i + 1] sau v[n − 1 − i], ceea ce permite ca o buclă să „plimbe” aceeași instrucțiune peste toate elementele.

Vector, tablou, std::vector

În limbajul curent al orelor de informatică, „vector” înseamnă tablou unidimensional, adică exact ce învățăm aici (în C++ se numește array). Biblioteca standard C++ are și un tip numit std::vector, care este altceva: un obiect care își poate modifica dimensiunea. Nu îl folosim în această sesiune, iar când vei auzi cuvântul „vector” în acest modul, ne referim la tabloul clasic.

Declararea și inițializarea unui vector

Un vector se declară ca o variabilă obișnuită, dar după nume se scrie, între paranteze drepte, numărul de elemente. Forma generală este tip nume[dimensiune];. Declarația int v[5]; rezervă spațiu pentru 5 numere întregi, iar double medie[30]; pentru 30 de numere reale.

Dimensiunea trebuie să fie o valoare cunoscută la compilare: un număr scris direct (100) sau o constantă declarată cu const. Programul nu poate citi mai întâi n și apoi declara un vector cu exact n elemente. De aceea, în probleme se declară un vector suficient de mare pentru cazul cel mai defavorabil din restricții (de exemplu, n ≤ 1000 înseamnă int v[1000];), iar n spune câte dintre locuri sunt folosite efectiv.

C++ – dimensiunea trebuie să fie constantă
const int MAX = 1000;   // constantă: valoarea nu mai poate fi schimbată
int v[MAX];             // corect: dimensiunea este cunoscută la compilare
int w[100];             // corect: dimensiunea este un număr scris direct

int n;
cin >> n;
// int u[n];            // NU în C++ standard: n este cunoscut abia la rulare
int u[n]; merge în unele compilatoare, dar nu este standard

Compilatorul GCC (g++) acceptă, ca extensie, vectori cu dimensiune variabilă (variable-length arrays), dar standardul C++ nu îi permite, iar alte compilatoare îi resping. Codul scris așa nu este portabil și nu îl folosim în acest modul. Compilat cu opțiunea -pedantic-errors, care impune strict standardul, g++ refuză declarația.

Inițializarea

Un vector poate primi valori chiar la declarare, printr-o listă între acolade. Dacă lista are mai puține valori decât vectorul, restul elementelor devin 0. Dacă dimensiunea lipsește, compilatorul o deduce din numărul de valori din listă.

C++ – forme de inițializare
int a[5] = {4, 8, 15, 16, 23};   // 4 8 15 16 23
int b[5] = {1, 2};              // 1 2 0 0 0   (restul devin 0)
int c[5] = {0};                 // 0 0 0 0 0   (toate 0)
int d[] = {3, 6, 9};            // dimensiunea 3 este dedusă din listă

for (int i = 0; i < 5; i++) {
    cout << b[i] << " ";
}
Valori nedefinite

Un vector local (declarat în main) fără inițializare, de exemplu int a[5];, conține valori oarecare rămase în memorie. Citirea unui element înainte ca el să fi primit o valoare produce un rezultat imprevizibil. Un vector global (declarat în afara lui main) are toate elementele 0 de la început. Când un vector trebuie să înceapă de la zero, de exemplu pentru contoare, scrie explicit = {0}.

Unde se declară vectorii mari

Variabilele locale sunt păstrate într-o zonă de memorie numită stivă, a cărei dimensiune este limitată (de ordinul megaocteților, în funcție de sistem). Un vector local de câteva sute de mii de elemente poate depăși această limită și opri programul. Vectorii mari se declară de obicei în afara lui main, ca variabile globale, care sunt păstrate în altă zonă de memorie și sunt automat inițializate cu 0.

C++ – vector global
int v[1000000];   // în afara lui main: variabilă globală, inițial toate elementele sunt 0

int main() {
    v[0] = 5;
    cout << v[0] << " " << v[999999];
}

Folosim această formă doar când dimensiunea este mare (în problemele cu n de ordinul zecilor de mii sau mai mult). Pentru vectori mici, declarația locală, în main, este suficientă. În exemplele din acest material, tot ce este declarat în afara lui main este arătat explicit.

Câte elemente are vectorul declarat?

Operatorul sizeof dă dimensiunea în octeți. Împărțind dimensiunea întregului vector la dimensiunea unui element, se obține numărul de locuri declarate. Atenție: acesta este numărul de locuri rezervate, nu numărul n de elemente folosite efectiv.

C++ – sizeof
int v[7];
cout << sizeof(v) / sizeof(v[0]);

Accesarea elementelor: indexul

Indicele unui element spune câte elemente se află înaintea lui, de aceea primul element, în fața căruia nu este niciunul, are indicele 0. Un element se folosește ca orice variabilă: i se poate atribui o valoare, poate apărea într-o expresie, poate fi citit sau afișat. Indicele poate fi orice expresie care are valoare întreagă.

C++ – citirea și modificarea elementelor
int v[5] = {7, 12, 5, 9, 3};

v[2] = 10;             // 7 12 10 9 3
v[4] = v[0] + v[1];    // 7 12 10 9 19
int i = 3;
v[i - 1] = v[i] * 2;   // 7 12 18 9 19

for (int k = 0; k < 5; k++) {
    cout << v[k] << " ";
}
Indicele nu este valoarea

În v[i], i este poziția elementului, iar v[i] este valoarea ei. Sunt lucruri diferite și pot avea valori complet diferite: în vectorul de mai sus, pentru i = 2 avem v[i] = 18. Când o problemă cere „poziția maximului”, răspunsul este un indice (eventual cu 1 adăugat), nu valoarea maximului.

Ce se întâmplă în afara limitelor

Pentru int v[5], indicii valizi sunt 0, 1, 2, 3 și 4. Expresii precum v[5], v[10] sau v[−1] se referă la memorie care nu aparține vectorului. C++ nu verifică acest lucru, nici la compilare, nici la rulare: programul se compilează și pornește.

Citirea unui astfel de element dă o valoare oarecare, iar scrierea poate modifica alte variabile, poate strica datele programului sau îl poate opri. Standardul numește aceasta comportament nedefinit: nu există nicio garanție privind rezultatul, iar programul poate părea corect la un test și să greșească la altul. Din acest motiv, verificarea limitelor ține de programator: o buclă de parcurgere pentru n elemente are condiția i < n, nu i <= n.

Citirea și afișarea unui vector

Citirea unui vector este o buclă for care citește fiecare element direct în celula lui: cin >> v[i]. Mai întâi se citește n, numărul de elemente, apoi se repetă citirea de n ori, cu i de la 0 la n − 1. Afișarea este, la rândul ei, o buclă care scrie fiecare element.

C++ – citirea și afișarea unui vector
int v[100];
int n;
cin >> n;

for (int i = 0; i < n; i++) {
    cin >> v[i];
}

for (int i = 0; i < n; i++) {
    cout << v[i] << " ";
}

Observă schema for (int i = 0; i < n; i++): pornește de la indicele 0, se oprește înainte de n și parcurge exact indicii valizi 0, 1, ..., n − 1. Această formă va apărea în aproape toate programele sesiunii, iar recunoașterea ei imediată te ajută să observi când ceva nu este în regulă, de exemplu un <= în loc de <.

Poziții de la 1, indici de la 0

În multe manuale și în enunțurile de probleme, elementele sunt numerotate de la 1 („al treilea element”, „poziția 5”). În C++, indicele este cu 1 mai mic decât poziția: elementul de pe poziția p este v[p − 1]. În enunțurile din acest material, pozițiile se numără de la 1, iar programele fac conversia (p − 1 la intrare, i + 1 la ieșire). Alternativ, unii programatori folosesc v[1], ..., v[n] și declară vectorul cu un loc în plus; ambele variante sunt corecte, dar trebuie să le alegi pe una și să nu le amesteci.

Parcurgerea unui vector

Majoritatea algoritmilor pe vectori sunt variații ale unei parcurgeri. Ce diferă de la un algoritm la altul este punctul de plecare, cel de oprire și pasul buclei, iar aceste trei elemente trebuie alese astfel încât toți indicii folosiți în corpul buclei să rămână între 0 și n − 1.

Înainte (0 → n − 1)
for (int i = 0; i < n; i++) {
    cout << v[i] << " ";
}
Înapoi (n − 1 → 0)
for (int i = n - 1; i >= 0; i--) {
    cout << v[i] << " ";
}
Din 2 în 2 (indici pari)
for (int i = 0; i < n; i += 2) {
    cout << v[i] << " ";
}
Perechi de vecini
for (int i = 0; i < n - 1; i++) {
    // compară v[i] cu v[i + 1]
    // i + 1 ajunge cel mult n - 1
}
Prima jumătate
for (int i = 0; i < n / 2; i++) {
    // v[i] și simetricul v[n - 1 - i]
}
De la al doilea element
int maxim = v[0];
for (int i = 1; i < n; i++) {
    if (v[i] > maxim) {
        maxim = v[i];
    }
}

Parcurgerea pe perechi de vecini are nevoie de atenție: pentru că se folosește v[i + 1], indicele i trebuie să se oprească la n − 2, deci condiția este i < n − 1. Parcurgerea pe jumătate este folosită când fiecare element se asociază cu simetricul lui (inversare, palindrom): pentru n impar, elementul din mijloc este propriul simetric și nu necesită prelucrare, iar n / 2 (împărțire întreagă) îl exclude automat.

C++ – C++11: for pe interval (doar pentru informare)
int v[5] = {4, 9, 1, 7, 3};

for (int x : v) {
    cout << x << " ";
}

De la standardul C++11, un vector poate fi parcurs și cu un for pe interval, care oferă pe rând valoarea fiecărui element, fără indice. Este comod când indicele nu contează, dar în această sesiune ai nevoie aproape peste tot de poziții (pentru a compara vecini, a inversa, a insera), așa că folosim forma cu indice.

Algoritmi elementari pe vectori

Tiparele din S6 se aplică neschimbate, dar acum pot fi folosite de mai multe ori asupra acelorași date. În exemplele din această secțiune, vectorul este inițializat direct în program, ca să se vadă rezultatul fără o citire.

Suma, contorizarea și media

Suma este un acumulator, iar numărarea condiționată este un contor în interiorul unui if, exact ca în S6. Media aritmetică are nevoie de suma tuturor elementelor și de numărul lor; împărțirea trebuie să fie reală, de aceea una dintre valori este convertită explicit la double.

C++ – suma, numărul de elemente pare și media
int v[6] = {4, 9, 1, 7, 3, 10};
int n = 6;

long long suma = 0;
int nrPare = 0;
for (int i = 0; i < n; i++) {
    suma += v[i];
    if (v[i] % 2 == 0) {
        nrPare++;
    }
}

double media = (double) suma / n;
cout << suma << " " << nrPare << " " << media;

Programul afișează 34 2 5.66667: suma elementelor este 34, două dintre ele (4 și 10) sunt pare, iar media este 34 / 6 ≈ 5,67. Fără conversia (double), împărțirea suma / n ar fi fost între două numere întregi și ar fi dat 5.

Maximul și minimul, cu poziția

Pentru un vector, este mai util să reții indicele elementului maxim decât valoarea lui: din indice se obține imediat și valoarea (v[poz]), și poziția (poz + 1). Algoritmul pornește cu presupunerea că maximul este primul element (poz = 0) și îl corectează ori de câte ori găsește un element mai mare. Comparația strictă păstrează prima apariție.

C++ – maximul și poziția primei apariții
int v[7] = {4, 9, 2, 9, 1, 9, 5};
int n = 7;

int poz = 0;
for (int i = 1; i < n; i++) {
    if (v[i] > v[poz]) {
        poz = i;
    }
}

cout << "Maxim " << v[poz] << " pe pozitia " << poz + 1;

Pentru minim, singura schimbare este semnul comparației. Ca în S6, poz nu se inițializează cu o valoare arbitrară, ci cu 0, adică cu un element real al vectorului.

Căutarea liniară

Pentru a afla dacă o valoare x se află în vector și unde, se parcurg elementele pe rând până la prima potrivire. Este tiparul cu indicator și break din S6, în care indicatorul este chiar poziția găsită. Valoarea de început trebuie să fie ceva ce nu poate fi un indice valid: −1 (nu 0, pentru că 0 este indicele primului element).

C++ – căutarea primei apariții a lui x
int v[7] = {5, 2, 8, 2, 9, 2, 1};
int n = 7, x = 2;

int poz = -1;
for (int i = 0; i < n; i++) {
    if (v[i] == x) {
        poz = i;
        break;
    }
}

if (poz == -1) {
    cout << "x nu se afla in vector";
} else {
    cout << "x este pe pozitia " << poz + 1;
}

Pentru ultima apariție, vectorul se parcurge de la sfârșit (i de la n − 1 la 0), iar prima potrivire întâlnită este ultima din vector. Alternativ, parcurgi vectorul o singură dată de la început fără break și rescrii poz la fiecare potrivire; la final, poz reține ultima. Căutarea liniară se numește așa pentru că, în cel mai rău caz, verifică toate cele n elemente.

Verificări „pentru toate” și „există”

Proprietățile care privesc toate elementele sau cel puțin un element se verifică, ca în S6, cu un indicator: pentru „există” pornești de la false, pentru „pentru toate” pornești de la true, iar prima dovadă contrară schimbă valoarea și, de obicei, oprește bucla.

C++ – sunt toate elementele pozitive? Există un element negativ?
int v[5] = {3, 8, 1, -6, 2};
int n = 5;

bool toatePozitive = true;
bool existaNegativ = false;
for (int i = 0; i < n; i++) {
    if (v[i] <= 0) {
        toatePozitive = false;
    }
    if (v[i] < 0) {
        existaNegativ = true;
    }
}

cout << toatePozitive << " " << existaNegativ;

Afișarea unui bool cu cout dă 0 pentru false și 1 pentru true; de aceea se afișează 0 1. Unele verificări nu privesc un singur element, ci perechi: verificarea „vectorul este ordonat” compară fiecare element cu vecinul lui și cere parcurgerea pe perechi, cu i < n − 1.

Interschimbarea a două elemente și inversarea unui vector

Pentru a inversa un vector, primul element se schimbă cu ultimul, al doilea cu penultimul și așa mai departe, până la mijloc. Operația de bază este interschimbarea (în engleză swap) a două elemente. Ea necesită o variabilă ajutătoare: dacă ai scrie v[i] = v[j]; v[j] = v[i];, prima atribuire ar șterge valoarea veche a lui v[i] și ambele elemente ar ajunge egale cu v[j].

C++ – interschimbarea corectă, cu variabilă ajutătoare
int aux = v[i];   // salvăm valoarea lui v[i]
v[i] = v[j];      // v[i] primește valoarea lui v[j]
v[j] = aux;       // v[j] primește valoarea salvată

Inversarea pe loc parcurge doar prima jumătate a vectorului: fiecare pas schimbă v[i] cu simetricul său v[n − 1 − i]. Dacă parcurgerea ar merge până la n, fiecare pereche ar fi schimbată de două ori, iar vectorul ar reveni la forma inițială. Numărul de interschimbări este n / 2 (împărțire întreagă); la n impar, elementul din mijloc rămâne pe loc.

C++ – inversarea unui vector pe loc
int v[7] = {1, 2, 3, 4, 5, 6, 7};
int n = 7;

for (int i = 0; i < n / 2; i++) {
    int aux = v[i];
    v[i] = v[n - 1 - i];
    v[n - 1 - i] = aux;
}

for (int i = 0; i < n; i++) {
    cout << v[i] << " ";
}

Inserarea și ștergerea unui element

Un vector are elemente consecutive, deci nu poți „face loc” sau „închide un gol” fără să muți restul elementelor. Vectorul de frecvență

Uneori elementele unui șir sunt numere întregi dintr-un interval mic: cifre (0–9), note (1–10), vârste, numere până la 1000. În acest caz, valorile pot fi folosite ele însele ca indici. Un vector f în care f[x] este numărul de apariții ale valorii x se numește vector de frecvență. Pentru fiecare element citit se execută f[x]++, iar după ce toate au fost citite, f descrie complet șirul, fără ca elementele să mai fie memorate.

C++ – frecvența notelor de la 1 la 10
int note[9] = {7, 9, 10, 7, 5, 9, 7, 10, 8};
int f[11] = {0};      // f[0] nefolosit; f[1], ..., f[10]

for (int i = 0; i < 9; i++) {
    f[note[i]]++;
}

for (int nota = 1; nota <= 10; nota++) {
    if (f[nota] > 0) {
        cout << nota << ": " << f[nota] << endl;
    }
}
Se afișează

8: 1
9: 2
10: 2

Vectorul f are un loc în plus (11 elemente pentru valori de la 0 la 10), deoarece ultima valoare posibilă, 10, trebuie să fie un indice valid. Regula generală: pentru valori de la 0 la M, vectorul are M + 1 elemente. Metoda este foarte rapidă (o singură parcurgere), dar funcționează doar când valorile sunt întregi și nu prea mari.

Sortarea unui vector

A sorta un vector înseamnă a-i rearanja elementele în ordine crescătoare (sau descrescătoare). Există multe metode; aici le prezentăm pe cele două mai simple. Metoda selecției construiește șirul ordonat de la început: găsește cel mai mic element, îl pune pe prima poziție, apoi cel mai mic dintre cele rămase îl pune pe a doua poziție, și tot așa.

C++ – sortarea prin selecție
int v[5] = {7, 3, 9, 1, 5};
int n = 5;

for (int i = 0; i < n - 1; i++) {
    int poz = i;                    // indicele celui mai mic element din v[i..n-1]
    for (int j = i + 1; j < n; j++) {
        if (v[j] < v[poz]) {
            poz = j;
        }
    }
    int aux = v[i];                 // plasăm minimul pe poziția i
    v[i] = v[poz];
    v[poz] = aux;
}

for (int i = 0; i < n; i++) {
    cout << v[i] << " ";
}

Bucla exterioară alege poziția i ce va fi completată, iar bucla interioară este tiparul „minim cu poziție”, aplicat doar pe porțiunea încă nesortată, v[i..n−1]. După pasul i, primele i + 1 poziții conțin cele mai mici i + 1 elemente, în ordine. Ultimul element ajunge de la sine la locul lui, deci bucla exterioară se oprește la n − 2.

Pentru n = 1000, este aproape jumătate de milion, un număr perfect acceptabil. Pentru zeci de mii de elemente, însă, metoda devine lentă, motiv pentru care există algoritmi de sortare mai eficienți, pe care îi vei întâlni mai târziu.

Metoda bulelor

A doua metodă compară în mod repetat perechile de vecini și le interschimbă dacă sunt în ordine greșită. La o trecere prin vector, cea mai mare valoare „urcă” spre sfârșit, ca o bulă, iar trecerile se repetă până când nu mai este nevoie de nicio interschimbare. Un indicator reține dacă în trecerea curentă s-a făcut vreo interschimbare.

C++ – sortarea prin metoda bulelor
int v[5] = {7, 3, 9, 1, 5};
int n = 5;

bool sortat;
do {
    sortat = true;
    for (int i = 0; i < n - 1; i++) {
        if (v[i] > v[i + 1]) {
            int aux = v[i];
            v[i] = v[i + 1];
            v[i + 1] = aux;
            sortat = false;
        }
    }
} while (!sortat);

for (int i = 0; i < n; i++) {
    cout << v[i] << " ";
}

Observă că bucla interioară este parcurgerea pe perechi de vecini, cu i < n − 1, iar indicatorul sortat este inițializat la începutul fiecărei treceri, în interiorul do–while. Ambele metode produc același rezultat; diferă numărul de interschimbări (selecția face cel mult n − 1 interschimbări, bulele pot face mult mai multe) și felul în care ordonarea se construiește.

Aplicație: conversia unui număr în baza 2

În S6 am văzut că atunci când cifrele unui număr se obțin cu % 10 și / 10, ele apar în ordine inversă și că nu le putem afișa în ordinea corectă fără să le memorăm. Erori frecvente

Eroarea 1 – Depășirea limitelor vectorului

Cea mai frecventă și cea mai periculoasă greșeală este folosirea unui indice care nu aparține vectorului. Cauzele tipice sunt o buclă cu i <= n în loc de i < n, un v[i + 1] la ultimul element sau o dimensiune declarată mai mică decât cea din restricții.

C++ – greșit
int v[5];
for (int i = 0; i <= 5; i++) {   // i ia și valoarea 5
    v[i] = i;                    // v[5] nu există
}

La i = 5 se scrie în afara vectorului, iar efectul este imprevizibil: programul poate funcționa „corect” pe computerul tău și să se oprească la corectare. Corect: i < 5. În mod similar, dacă problema garantează n ≤ 1000, dar ai declarat int v[100], orice test cu n > 100 încalcă limitele.

Eroarea 2 – Poziția folosită ca indice

Când enunțul numără pozițiile de la 1, indicele elementului de pe poziția p este p − 1. Folosirea directă a lui p ca indice produce un rezultat greșit, fără nicio eroare de compilare.

C++ – greșit: se șterge elementul de pe poziția 3
int v[5] = {10, 20, 30, 40, 50};
int n = 5, p = 3;

for (int i = p; i < n - 1; i++) {   // ar trebui i = p - 1
    v[i] = v[i + 1];
}
n--;

for (int i = 0; i < n; i++) {
    cout << v[i] << " ";
}

Programul afișează 10 20 30 50, deci a șters elementul 40 (indicele 3), nu 30, care se află pe poziția 3 (indicele 2). Corect este int i = p − 1.

Eroarea 3 – Interschimbare fără variabilă ajutătoare

C++ – greșit: inversare cu interschimbare incorectă
int v[5] = {1, 2, 3, 4, 5};
int n = 5;

for (int i = 0; i < n / 2; i++) {
    v[i] = v[n - 1 - i];
    v[n - 1 - i] = v[i];     // v[i] a fost deja suprascris
}

for (int i = 0; i < n; i++) {
    cout << v[i] << " ";
}

Se afișează 5 4 3 4 5 în loc de 5 4 3 2 1: după prima atribuire, v[i] conține deja valoarea lui v[n − 1 − i], iar a doua atribuire copiază înapoi aceeași valoare. Valorile inițiale 1 și 2 au dispărut. Soluția este variabila aux care salvează valoarea înainte să fie suprascrisă.

Eroarea 4 – Deplasare în sensul greșit la inserare

C++ – greșit: inserarea parcurgând de la început
int v[7] = {10, 20, 30, 40, 50};
int n = 5, k = 2, x = 25;

for (int i = k; i < n; i++) {   // sens greșit: de la stânga la dreapta
    v[i + 1] = v[i];
}
v[k] = x;
n++;

for (int i = 0; i < n; i++) {
    cout << v[i] << " ";
}

Se afișează 10 20 25 30 30 30: valoarea 30 este copiată pe poziția următoare, apoi, din nou, noua valoare a acelei poziții este copiată mai departe și toate elementele după k devin 30. La inserare deplasarea se face de la sfârșit spre k (ca în exemplul din secțiunea „Inserarea și ștergerea unui element”); la ștergere, de la k spre sfârșit.

Eroarea 5 – Uitarea actualizării lui n

C++ – greșit: ștergere fără n--
int v[5] = {10, 20, 30, 40, 50};
int n = 5, k = 1;

for (int i = k; i < n - 1; i++) {
    v[i] = v[i + 1];
}
// lipsește n--

for (int i = 0; i < n; i++) {
    cout << v[i] << " ";
}

Elementele au fost deplasate corect, dar n a rămas 5, deci ultimul element apare de două ori: 10 30 40 50 50. Orice inserare sau ștergere schimbă numărul de elemente folosite, iar n trebuie actualizat imediat (n++, respectiv n--).

Eroarea 6 – Vector local de frecvență neinițializat

C++ – greșit
int f[10];            // valori oarecare, nu 0!
f[3]++;               // incrementează o valoare necunoscută

Un vector de frecvență (sau de contoare) trebuie să pornească din 0: scrie int f[10] = {0};. Fără inițializare, un vector local conține valori rămase în memorie, iar numerele obținute vor fi imprevizibile și, de obicei, vor diferi de la o rulare la alta.

Eroarea 7 – Copierea și compararea vectorilor cu = și ==

Un vector întreg nu poate fi copiat cu o singură atribuire, iar compararea lui cu == nu verifică elementele. Pentru a copia, trebuie să copiezi elementele unul câte unul, cu o buclă. Pentru a compara, parcurgi elementele și folosești un indicator.

C++ – greșit: nu se compilează
int a[3] = {1, 2, 3};
int b[3];
b = a;               // eroare de compilare: atribuirea de tablouri nu este permisă
C++ – corect: copierea element cu element
int a[3] = {1, 2, 3};
int b[3];

for (int i = 0; i < 3; i++) {
    b[i] = a[i];
}

cout << b[0] << b[1] << b[2];

Expresia a == b nu dă erori, dar nu compară conținutul: compară adresele celor doi vectori din memorie, care sunt întotdeauna diferite pentru doi vectori distincți. Rezultatul este deci false chiar dacă toate elementele coincid. Unele compilatoare recente avertizează asupra acestei comparații.

În Java, un tablou creat cu new are toate elementele inițializate cu 0 (pentru tipurile numerice), iar orice acces în afara limitelor produce o excepție (netratată, ea oprește programul cu un mesaj clar), nu un comportament imprevizibil.     for (int i = 2; i * i <= n; i++) {
        if (!compus[i]) {
            for (int j = i * i; j <= n; j += i) {
                compus[j] = true;
            }

    }

    for (int i = 2; i <= n; i++) {

            nr++;
        }

Exerciții introductive (fără scriere de cod)

Rezolvă pe hârtie, apoi verifică cu răspunsul.

1Câte elemente are vectorul declarat int v[8];? Care sunt primul și ultimul indice valid?

Vezi răspunsul

Are 8 elemente, cu indicii 0, 1, ..., 7. Primul indice valid este 0, iar ultimul este 7 (adică dimensiunea minus 1). v[8] nu face parte din vector.

2Ce valori au elementele vectorului int v[5] = {3, 1};?

Vezi răspunsul

3 1 0 0 0. Când lista de inițializare are mai puține valori decât vectorul, elementele rămase sunt inițializate cu 0.

3Ce se întâmplă dacă un program scrie v[10] = 4; pentru un vector int v[10];?

Vezi răspunsul

Indicele 10 este în afara vectorului (indicii valizi sunt 0, ..., 9). C++ nu verifică acest lucru: programul se compilează, iar la rulare comportamentul este nedefinit – poate modifica o altă variabilă, poate opri programul sau poate părea că merge corect. Verificarea limitelor este responsabilitatea programatorului.

4De ce nu se poate scrie, în C++ standard, int n; cin >> n; int v[n];? Ce se face în schimb?

Vezi răspunsul

Standardul cere ca dimensiunea unui vector să fie cunoscută la compilare, iar n este cunoscut abia la rulare (unele compilatoare acceptă totuși construcția, ca extensie nestandard). Se declară un vector cu dimensiunea maximă din restricțiile problemei (de exemplu int v[1000]; pentru n ≤ 1000) și se folosesc doar primele n elemente.

5Câte interschimbări se fac pentru a inversa pe loc un vector cu n = 7 elemente? Dar cu n = 8? Ce se întâmplă cu elementul din mijloc?

Vezi răspunsul

Se fac n / 2 interschimbări (împărțire întreagă): 3 pentru n = 7, respectiv 4 pentru n = 8. Pentru n = 7, elementul din mijloc (indicele 3) este propriul lui simetric și rămâne pe loc.

6Care este deosebirea dintre i și v[i] în bucla for (int i = 0; i < n; i++) cout << v[i];?

Vezi răspunsul

i este indicele (poziția, numărată de la 0) și parcurge valorile 0, 1, ..., n − 1. v[i] este valoarea elementului aflat pe acea poziție. Bucla afișează valorile, nu indicii.

7De ce se inserează un element deplasând elementele începând cu ultimul, iar nu cu cel de pe poziția de inserare?

Vezi răspunsul

Dacă am copia întâi v[k] în v[k + 1], valoarea lui v[k + 1] s-ar pierde, iar la pasul următor am copia din nou aceeași valoare și elementele s-ar repeta. Mergând de la sfârșit spre k, fiecare element este copiat într-o celulă al cărei conținut a fost deja mutat.

8După ștergerea unui element prin deplasare, ce trebuie făcut cu n și de ce?

Vezi răspunsul

Trebuie scăzut cu 1 (n--). Prin deplasare, ultimul element rămâne în memorie în două exemplare. Dacă n nu scade, parcurgerile ulterioare ar include acest duplicat.

9Pentru ce fel de valori se poate folosi un vector de frecvență? Ce dimensiune are pentru valori între 0 și 100?

Vezi răspunsul

Pentru valori întregi dintr-un interval mic, care pot fi folosite ca indici. Pentru valori de la 0 la 100 are 101 elemente (f[0], ..., f[100]), pentru că și 100 trebuie să fie un indice valid.

10Câte comparații v[j] < v[poz] execută sortarea prin selecție pentru n = 6? Care este formula generală?

Vezi răspunsul

5 + 4 + 3 + 2 + 1 = 15. În general, (n − 1) + (n − 2) + ... + 1 = n(n − 1) / 2, indiferent de ordinea inițială a elementelor.

1. Ce este un vector (tablou unidimensional) și ce proprietăți are?

Este o colecție de elemente de același tip, memorate consecutiv și accesate printr-un nume comun și un indice. Accesul la v[i] este direct (nu trebuie parcurse elementele dinainte), iar indicele poate fi orice expresie întreagă, ceea ce permite parcurgerea cu o buclă.

2. Care sunt indicii valizi ai unui vector cu n elemente și de ce primul indice este 0?

Indicii valizi sunt 0, 1, ..., n − 1. Indicele unui element arată câte elemente se află înaintea lui, deci primul element are indicele 0, iar ultimul n − 1. Elementul de pe poziția p (numărată de la 1) este v[p − 1].

3. Ce se întâmplă dacă accesezi v[n] sau v[−1] într-un vector cu n elemente? Cum este tratată situația în Java și în Python?

În C++ nu se verifică nimic: comportamentul este nedefinit (valoare oarecare la citire; la scriere, alte date pot fi alterate sau programul se poate opri). Java semnalează ArrayIndexOutOfBoundsException, iar Python IndexError (în Python, v[−1] este însă valid: ultimul element).

4. Cum alegi dimensiunea unui vector când n se citește de la tastatură? Care este diferența dintre dimensiunea declarată și n?

Dimensiunea declarată trebuie să fie o constantă și se alege din restricțiile problemei (cel puțin valoarea maximă a lui n; la inserare, cu un loc în plus). n este numărul de elemente folosite efectiv, citit la rulare, și care este cel mult egal cu dimensiunea declarată. Toate parcurgerile merg până la n, nu până la dimensiunea declarată.

5. Ce valori au elementele unui vector care nu a fost inițializat? Cum se inițializează cu 0?

Un vector local neinițializat conține valori oarecare; un vector global are toate elementele 0. Un vector local se inițializează cu 0 prin int v[100] = {0};. Contoarele și vectorii de frecvență trebuie întotdeauna inițializați astfel.

6. Care este diferența dintre poziția unui element și indicele lui? Cum se face conversia?

Poziția se numără de la 1, indicele de la 0. Elementul de pe poziția p are indicele p − 1, iar elementul de indice i se află pe poziția i + 1. Enunțurile care cer „poziția” unui element cer, de regulă, i + 1.

7. Cum se caută liniar o valoare într-un vector? De ce poziția găsită se inițializează cu −1, nu cu 0?

Se parcurg elementele până la prima potrivire (v[i] == x), reținând indicele și ieșind cu break. Valoarea de pornire trebuie să nu fie un indice valid: 0 este indicele primului element, deci nu ar putea semnala „nu a fost găsit”, în timp ce −1 nu este indice valid. Căutarea examinează, în cel mai rău caz, toate cele n elemente.

8. Cum se determină maximul unui vector împreună cu poziția lui? De ce se reține indicele, nu valoarea?

Se pornește cu poz = 0 și, pentru i de la 1 la n − 1, se actualizează poz = i când v[i] > v[poz]. Din indice se obțin ambele informații: valoarea (v[poz]) și poziția (poz + 1). Comparația strictă păstrează prima apariție a maximului.

9. Cum se inversează un vector pe loc? De ce este nevoie de o variabilă ajutătoare și de ce parcurgerea merge doar până la n / 2?

Se interschimbă v[i] cu v[n − 1 − i] pentru i < n / 2. Interschimbarea cere variabila aux, altfel prima atribuire pierde valoarea veche. Dacă parcurgerea ar merge până la n, fiecare pereche ar fi schimbată de două ori și vectorul ar reveni la forma inițială.

10. Cum se inserează și cum se șterge un element dintr-un vector? În ce sens se deplasează elementele și ce se întâmplă cu n?

La ștergere (indice k) elementele de după k se mută cu o poziție spre stânga, de la k spre sfârșit, iar n scade cu 1. La inserare elementele de la k încolo se mută cu o poziție spre dreapta, începând cu ultimul, apoi se scrie valoarea nouă pe indicele k, iar n crește cu 1. Sensul greșit duce la suprascrierea elementelor care încă nu au fost copiate.

11. Ce este un vector de frecvență și când poate fi folosit?

Un vector f în care f[x] este numărul de apariții ale valorii x. Se poate folosi când valorile sunt numere întregi dintr-un interval mic (cifre, note, valori până la câteva mii), pentru că ele devin indici. Pentru valori de la 0 la M are M + 1 elemente. Permite rezolvarea într-o singură parcurgere a problemelor de tip „cel mai frecvent”, „câte apariții” sau a sortării prin numărare.

12. Cum funcționează sortarea prin selecție și cea prin metoda bulelor? Câte comparații face prima?

Selecția găsește, pentru fiecare poziție i, cel mai mic element din v[i..n−1] și îl interschimbă cu v[i]; face n(n − 1) / 2 comparații. Metoda bulelor compară repetat perechile de vecini și le interschimbă dacă sunt în ordine greșită, până când o trecere completă nu mai face nicio interschimbare. Ambele produc același vector sortat.

13. De ce conversia unui număr într-o altă bază cere un vector?

Împărțirile succesive furnizează cifrele începând cu cea mai puțin semnificativă, iar scrierea cere ordinea inversă. Cifrele (resturile) se memorează într-un vector pe măsură ce apar și apoi se afișează de la ultima la prima.

14. Prin ce diferă tablourile din C++ de cele din Java și de listele din Python?

C++ are dimensiune fixă, cunoscută la compilare, și nu verifică indicii. Java are dimensiune fixă stabilită la crearea cu new (care poate fi o variabilă) și semnalează excepție la acces în afara limitelor. Python folosește liste, care își modifică dimensiunea (append), pot conține tipuri diferite și verifică indicii. În Java și Python, b = a copiază doar referința, iar în C++ nu se compilează.

Rezumat – De reținut

Cele mai importante idei din această sesiune
  1. Un vector este o colecție de elemente de același tip, memorate consecutiv și accesate prin indice: v[i]. Indicele poate fi orice expresie întreagă.
  2. Pentru n elemente, indicii valizi sunt 0, 1, ..., n − 1. Elementul de pe poziția p (de la 1) este v[p − 1]. Parcurgerea standard este for (int i = 0; i < n; i++).
  3. C++ nu verifică limitele: accesul în afara vectorului este comportament nedefinit. Cauze tipice: i <= n, v[i + 1] la ultimul element, dimensiune mai mică decât n.
  4. Dimensiunea declarată este o constantă și se alege din restricții; n este numărul de elemente folosite. Vectorii mari se declară global (inițial 0); cei locali sunt neinițializați dacă nu scrii = {0}.
  5. Tiparele din S6 (acumulator, contor, maxim / minim, indicator) se aplică neschimbat. Pentru maxim este utilă reținerea indicelui: v[poz] și poz + 1.
  6. Căutarea liniară parcurge elementele până la prima potrivire; poziția de pornire este −1, o valoare care nu este indice valid.
  7. Interschimbarea a două elemente cere o variabilă ajutătoare. Inversarea pe loc interschimbă v[i] cu v[n − 1 − i] pentru i < n / 2.
  8. La ștergere elementele se deplasează spre stânga (de la k spre sfârșit) și n--. La inserare se deplasează spre dreapta, începând cu ultimul, apoi n++.
  9. Vectorul de frecvență (f[v[i]]++) folosește valorile ca indici; pentru valori de la 0 la M are M + 1 elemente și trebuie inițializat cu 0.
  10. Sortarea prin selecție face n(n − 1) / 2 comparații; metoda bulelor interschimbă vecinii în ordine greșită până când nu mai e nevoie de nicio interschimbare.
  11. Conversia în baza b memorează resturile n % b într-un vector și le afișează în ordine inversă.
  12. Un vector nu se copiază cu b = a și nu se compară cu ==; se folosește o buclă. Java și Python verifică indicii; Python are indici negativi și liste cu dimensiune variabilă.
