Introducere

În sesiunea anterioară ai văzut cum poate un program să aleagă între mai multe căi de execuție, în funcție de o condiție — aceasta este structura alternativă. Am amintit atunci, doar pentru a completa clasificarea instrucțiunilor, că mai există o categorie: instrucțiunile de ciclare (numite și repetitive sau iterative), care repetă o secvență de cod de mai multe ori. În această sesiune tocmai aceste instrucțiuni devin subiectul principal.

La fel ca structura alternativă, și structura repetitivă este o structură de control fundamentală — modifică fluxul normal (secvențial) de execuție al unui program, dar nu prin alegerea unei ramuri, ci prin revenirea la o instrucțiune anterioară, atât timp cât o condiție rămâne îndeplinită.

Punct cheie

O structură repetitivă execută în mod repetat o instrucțiune sau un bloc de instrucțiuni, atât timp cât (sau până când) este îndeplinită o anumită condiție. Numărul de repetări poate fi cunoscut dinainte sau poate depinde de o condiție evaluată în timpul execuției.

Ce nu dezvoltăm încă în această sesiune

Ne concentrăm aici pe sintaxa și funcționarea celor trei instrucțiuni de ciclare din C++: while, do–while și for, pe tiparele contor și acumulator și pe buclele controlate printr-o valoare santinelă. Instrucțiunile de salt break și continue, buclele imbricate (o structură repetitivă în interiorul alteia) și algoritmii elementari construiți cu bucle (determinarea maximului, verificarea unei proprietăți, numărarea elementelor care satisfac o condiție) fac obiectul sesiunii următoare.

De ce avem nevoie de repetare

Presupunem că vrem să afișăm mesajul Bun venit! de cinci ori. Folosind doar ce am învățat până acum, ar trebui să scriem instrucțiunea de cinci ori:

C++ – fără repetare
cout << "Bun venit!" << endl;
cout << "Bun venit!" << endl;
cout << "Bun venit!" << endl;
cout << "Bun venit!" << endl;
cout << "Bun venit!" << endl;

Metoda funcționează, dar nu se poate generaliza: dacă am vrea de 1000 de ori, ar trebui scrise 1000 de linii; dacă numărul de repetări este cunoscut abia în momentul execuției (de exemplu, citit de la tastatură), metoda nu mai este deloc aplicabilă. Avem nevoie de o construcție a limbajului care să spună, în esență: „repetă această instrucțiune de n ori" sau „repetă această instrucțiune cât timp este îndeplinită o condiție".

C++ – cu repetare
int i = 0;
while (i < 5) {
    cout << "Bun venit!" << endl;
    i++;
}

Indiferent de câte ori trebuie repetată acțiunea — 5, 1000 sau un număr necunoscut dinainte — structura de mai sus rămâne la fel de scurtă. Aceasta este utilitatea fundamentală a structurii repetitive.

Instrucțiunea while

Instrucțiunea while repetă execuția unei instrucțiuni-corp atât timp cât o condiție este adevărată. Condiția este verificată înaintea fiecărei execuții a corpului — inclusiv înaintea primeia.

Formă generală
while (conditie) {
    instructiune1;
    instructiune2;
    ...
}
condiție? → adevărat → execută corpul → revino la condiție
condiție? → fals → iese din buclă
C++
int i = 1;
while (i <= 5) {
    cout << i << " ";
    i++;
}
// afiseaza: 1 2 3 4 5

Trei elemente trebuie să existe pentru ca bucla să funcționeze corect: (1) o variabilă inițializată înaintea buclei (i = 1); (2) o condiție care implică acea variabilă (i <= 5); (3) o instrucțiune care modifică variabila în corpul buclei, astfel încât, la un moment dat, condiția să devină falsă (i++). Dacă lipsește oricare dintre aceste elemente, bucla fie nu se execută deloc, fie nu se mai oprește niciodată.

Condiția este verificată înainte

Dacă, la prima verificare, condiția este deja falsă, corpul buclei while nu se execută niciodată — nici măcar o singură dată. De exemplu, pentru int i = 10; while (i < 5) { ... }, corpul nu se execută deloc, întrucât 10 < 5 este falsă chiar de la început.

Instrucțiunea do–while

Instrucțiunea do–while este asemănătoare cu while, dar cu o diferență esențială: condiția este verificată după execuția corpului, nu înainte. Corpul buclei este, așadar, executat întotdeauna cel puțin o dată, indiferent de valoarea inițială a condiției.

Formă generală
do {
    instructiune1;
    instructiune2;
    ...
} while (conditie);
Atenție la punct și virgulă

Spre deosebire de while, instrucțiunea do–while se încheie cu ; după paranteza condiției — este singura instrucțiune de ciclare din C++ care cere acest lucru. Omiterea lui produce o eroare de compilare.

C++
int optiune;
do {
    cout << "Introduceti un numar intre 1 si 5: ";
    cin >> optiune;
} while (optiune < 1 || optiune > 5);

cout << "Ati introdus: " << optiune;

Acest exemplu ilustrează un caz de utilizare tipic pentru do–while: validarea unei date de intrare. Utilizatorul trebuie să introducă cel puțin o dată o valoare — nu are sens să verificăm o condiție înainte de a fi citit ceva — iar apoi cererea se repetă atât timp cât valoarea introdusă nu este validă.

while versus do–while

Diferența dintre cele două instrucțiuni pare mică din punct de vedere sintactic — poziția condiției — dar are un efect important asupra numărului minim de execuții ale corpului.

while — testare la început

int i = 10;
while (i < 5) {
    cout << i;
}
// corpul NU se executa
// (conditia e falsa chiar de la inceput)

Corpul se poate executa de zero ori.

do–while — testare la sfârșit

int i = 10;
do {
    cout << i;
} while (i < 5);
// corpul se executa o data
// (verificarea vine dupa)

Corpul se execută întotdeauna cel puțin o dată.

Instrucțiunea for

Instrucțiunea for este utilizată în mod obișnuit atunci când numărul de repetări este cunoscut dinainte, sau atunci când ciclarea este condusă de o variabilă numărătoare care se modifică regulat. Ea reunește, într-o singură linie, cele trei elemente pe care le-am identificat mai devreme la while: inițializarea, condiția și pasul (modificarea variabilei).

Formă generală
for (initializare; conditie; pas) {
    instructiune1;
    instructiune2;
    ...
}
C++
for (int i = 1; i <= 5; i++) {
    cout << i << " ";
}
// afiseaza: 1 2 3 4 5 (identic cu exemplul de la while)

Cele trei componente din paranteză se execută astfel: inițializarea (int i = 1) o singură dată, la începutul buclei; condiția (i <= 5) înaintea fiecărei execuții a corpului, la fel ca la while; pasul (i++) după fiecare execuție a corpului, înainte de a reveni la verificarea condiției.

inițializare (o dată) → condiție? → adevărat → corp → pas → revino la condiție
for este echivalentă cu un while

Orice buclă for (init; cond; pas) { corp; } poate fi rescrisă ca while: init; while (cond) { corp; pas; }. Cele două instrucțiuni nu introduc concepte diferite — for este doar o formă mai compactă, potrivită pentru buclele controlate de un contor.

C++ – echivalența for ↔ while
// varianta for
for (int i = 1; i <= 5; i++) {
    cout << i;
}

// varianta while, echivalenta
int i = 1;
while (i <= 5) {
    cout << i;
    i++;
}

Variații ale instrucțiunii for

for poate număra și descrescător, poate folosi un pas diferit de 1, iar variabila de control poate fi de orice tip numeric:

C++ – variații
// descrescator, de la 10 la 1
for (int i = 10; i >= 1; i--) {
    cout << i << " ";
}

// pas de 2 (doar numere pare de la 0 la 10)
for (int i = 0; i <= 10; i += 2) {
    cout << i << " ";
}
Domeniul de vizibilitate al variabilei din for

O variabilă declarată în inițializarea unui for, ca în for (int i = 0; ...), este vizibilă numai în interiorul buclei (inclusiv în condiție și în pas) — la fel cum o variabilă declarată într-un bloc este vizibilă doar acolo (vezi S4). După încheierea buclei, i nu mai poate fi folosită.

Reprezentarea structurii repetitive: scheme logice și pseudocod

La fel ca la structura alternativă (vezi S4), o structură repetitivă poate fi reprezentată, înainte de a fi scrisă în cod C++, printr-o schemă logică (reprezentare grafică) sau printr-un pseudocod (reprezentare textuală). Diferența esențială față de schema unei structuri alternative este că, după executarea corpului, controlul revine la simbolul de decizie (rombul), în loc să se încheie.

Contor și acumulator

Aproape orice problemă rezolvată cu o buclă folosește una sau ambele dintre următoarele două tipare, care revin în majoritatea programelor cu structuri repetitive.

Contor (numărare)
int numar = 0;
for (int i = 1; i <= n; i++) {
    numar = numar + 1;   // numar++;
}
Acumulator (sumă)
int suma = 0;
for (int i = 1; i <= n; i++) {
    suma = suma + i;
}
Acumulator (produs)
int produs = 1;
for (int i = 1; i <= n; i++) {
    produs = produs * i;
}

Un contor este o variabilă care este mărită (de obicei cu 1) de fiecare dată când se întâmplă un anumit lucru — răspunde la întrebarea „de câte ori?". Un acumulator este o variabilă care adună (sau înmulțește) treptat valori pe parcursul buclei — răspunde la întrebarea „cât în total?". Diferența esențială dintre ele nu este sintactică, ci de rol: un contor este de regulă incrementat cu o valoare fixă (+1), în timp ce un acumulator adună valori care pot diferi la fiecare pas.

Inițializarea contorului/acumulatorului contează

Un acumulator pentru sumă trebuie inițializat cu 0 (elementul neutru al adunării); un acumulator pentru produs trebuie inițializat cu 1 (elementul neutru al înmulțirii), niciodată cu 0 — altfel produsul final ar fi întotdeauna 0, indiferent de valorile înmulțite.

Alegerea structurii de ciclare potrivite

Cele trei instrucțiuni de ciclare din C++ pot, în principiu, rezolva aceleași probleme — orice buclă for se poate scrie cu while, iar un do–while poate fi rescris ca while cu o mică restructurare. Alegerea dintre ele este, în primul rând, o alegere de claritate: care structură exprimă cel mai natural intenția problemei.

SituațieStructură recomandată
Numărul de repetări este cunoscut dinainte (ex: „repetă de n ori", „de la 1 la 100")for
Repetarea depinde de o condiție care nu este legată de un contor (ex: „cât timp mai sunt bani în cont")while
Corpul trebuie executat obligatoriu cel puțin o dată (ex: validarea unei date de intrare, un meniu)do–while
Nu există o regulă absolută

Aceste recomandări descriu tiparul cel mai frecvent, nu o regulă obligatorie a limbajului. C++ nu împiedică folosirea unui while acolo unde numărul de repetări este cunoscut — dar codul devine, de regulă, mai greu de citit dacă structura aleasă nu reflectă natura problemei.

Bucle controlate printr-o valoare santinelă

Nu toate buclele au un număr de repetări cunoscut dinainte. Un tipar frecvent este citirea repetată a unor valori, până când utilizatorul introduce o valoare specială, convenită dinainte, care semnalează oprirea — numită valoare santinelă (din engleză, sentinel value).

C++ – citire până la valoarea santinelă 0
int x;
int suma = 0;

cout << "Introduceti numere, 0 pentru a opri: ";
cin >> x;

while (x != 0) {
    suma += x;
    cin >> x;
}

cout << "Suma este: " << suma;

Observă structura: (1) o citire înainte de buclă (numită, uneori, „citire de pregătire"), care oferă prima valoare de testat; (2) condiția while testează dacă valoarea citită este diferită de santinelă; (3) în interiorul buclei, pe lângă prelucrarea propriu-zisă (suma += x;), se află o a doua citire, care pregătește testul următor. Fără această a doua citire, condiția ar folosi mereu prima valoare citită, iar bucla nu s-ar mai opri niciodată sau nu s-ar mai actualiza corect.

Alegerea valorii santinelă

Valoarea santinelă trebuie să fie una care nu poate apărea în mod normal printre datele valide ale problemei — de exemplu, 0 este o alegere nepotrivită dacă printre valorile de prelucrat se poate afla și numărul 0 însuși. În astfel de cazuri se alege o altă valoare convențională (de exemplu, -1, dacă datele sunt cunoscute a fi pozitive).

Acest tipar folosește while mai degrabă decât for, deoarece numărul de repetări nu este cunoscut dinainte — depinde exclusiv de datele introduse de utilizator, nu de un contor.

Erori frecvente

Eroarea 1 – Bucla infinită prin uitarea pasului

C++ – Greșit
int i = 1;
while (i <= 5) {
    cout << i;
    // lipseste i++; -- i ramane mereu 1, conditia e mereu adevarata
}
C++ – Corect
int i = 1;
while (i <= 5) {
    cout << i;
    i++;
}

Explicație: dacă variabila testată în condiție nu este niciodată modificată în corpul buclei, condiția rămâne mereu adevărată (sau mereu falsă), iar bucla nu se mai oprește — sau nu se execută deloc. Această eroare se numește buclă infinită; dacă apare într-un program, execuția pare „înghețată" și trebuie întreruptă manual.

Eroarea 2 – Punct și virgulă rătăcit după while/for

C++ – Greșit
int i = 1;
while (i <= 5); // ; formeaza corpul buclei!
{
    cout << i;
    i++;
}
C++ – Corect
int i = 1;
while (i <= 5) {
    cout << i;
    i++;
}

Explicație: la fel ca la if (vezi S4), un ; imediat după condiția lui while sau for formează o instrucțiune nulă, care devine corpul buclei. Ca urmare, condiția este verificată la nesfârșit fără ca variabila să fie vreodată modificată — se obține tot o buclă infinită, deoarece i nu este niciodată actualizat. Blocul de mai jos, cu acolade, se execută o singură dată, independent de buclă.

Eroarea 3 – „Off-by-one" (o repetare în plus sau în minus)

C++ – Se dorea afișarea numerelor 1...5
// Gresit -- afiseaza doar 1 2 3 4
for (int i = 1; i < 5; i++) {
    cout << i << " ";
}

// Corect -- afiseaza 1 2 3 4 5
for (int i = 1; i <= 5; i++) {
    cout << i << " ";
}

Explicație: folosirea lui < în loc de <= (sau invers) este una dintre cele mai frecvente surse de erori la bucle — condiția de continuare trebuie verificată cu grijă față de limitele exacte cerute de problemă. Acest tip de greșeală se numește, în engleză, off-by-one error (eroare cu o unitate în plus sau în minus).

Eroarea 4 – Confuzia dintre = și == în condiția buclei

C++ – Greșit
int i = 0;
while (i = 5) { // atribuie 5 lui i; conditia e mereu "adevarata" (5 e nenul)
    cout << i;
}
C++ – Corect
int i = 0;
while (i == 5) {
    cout << i;
}

Explicație: la fel ca la structura alternativă, = este atribuire, nu comparație. Într-o condiție de buclă, o atribuire accidentală cu = produce, de obicei, o condiție mereu adevărată (orice valoare nenulă) — deci o buclă infinită — sau mereu falsă, dacă valoarea atribuită este 0.

Eroarea 5 – Reinițializarea acumulatorului în interiorul buclei

C++ – Greșit
for (int i = 1; i <= 5; i++) {
    int suma = 0; // GRESIT: suma e resetata la fiecare pas!
    suma += i;
}
C++ – Corect
int suma = 0; // initializat o singura data, inainte de bucla
for (int i = 1; i <= 5; i++) {
    suma += i;
}

Explicație: un acumulator trebuie inițializat o singură dată, înaintea buclei — nu în interiorul ei. Dacă inițializarea este plasată în corpul buclei, valoarea acumulată la pasul anterior este pierdută la fiecare iterație, iar rezultatul final este greșit.

Cea mai importantă diferență conceptuală apare la for: în C++ și Java, for este construit din trei componente explicite (inițializare; condiție; pas), potrivite pentru orice tip de progresie numerică. În Python, for este întotdeauna o parcurgere a unei secvențe — for i in range(n): parcurge, pe rând, valorile 0, 1, ..., n-1, generate de funcția range; conceptul de „buclă cu contor" este identic, dar exprimat printr-o parcurgere, nu printr-o formulă cu trei părți.

Aceeași buclă (1 la 5), în trei limbaje
C++    : for (int i = 1; i <= 5; i++) cout << i;
Java   : for (int i = 1; i <= 5; i++) System.out.print(i);
Python : for i in range(1, 6): print(i, end=" ")
De ce range(1, 6) și nu range(1, 5)?

În Python, range(a, b) generează valorile de la a inclusiv, până la b exclusiv. Pentru a obține valorile 1, 2, 3, 4, 5, limita superioară trebuie scrisă 6, nu 5 — o altă formă a capcanei „off-by-one", de data aceasta specifică modului în care Python delimitează un interval.

Exemple rezolvate

Aplicăm, ca și în sesiunea anterioară, aceeași metodologie de rezolvare: cerință, date de intrare, date de ieșire, restricții, un exemplu, proiectarea algoritmului și codul C++.

Exemplul 1 – Afișarea numerelor de la 1 la n

Cerință: Se citește un număr natural n. Se afișează, separate prin spațiu, numerele de la 1 la n.

Date de intrare: un întreg n. Date de ieșire: numerele 1 2 ... n. Restricții: 1 ≤ n ≤ 1.000.000.

Exemplu: se citește 4; se afișează 1 2 3 4.

Algoritm: (1) se citește n; (2) se folosește o variabilă i, de la 1 la n; (3) la fiecare pas se afișează valoarea curentă a lui i — o buclă for este alegerea firească, întrucât numărul de repetări (n) este cunoscut dinainte.

C++
int n;
cin >> n;

for (int i = 1; i <= n; i++) {
    cout << i << " ";
}

Exemplul 2 – Suma primelor n numere naturale

Cerință: Se citește un număr natural n. Se afișează suma 1+2+...+n.

Date de intrare: un întreg n. Date de ieșire: suma primelor n numere naturale. Restricții: 1 ≤ n ≤ 100.000.

Exemplu: se citește 5; se afișează 15 (1+2+3+4+5).

Algoritm: (1) se citește n; (2) se inițializează un acumulator suma cu 0, înaintea buclei; (3) pentru fiecare i de la 1 la n, se adaugă i la suma; (4) se afișează suma.

C++
int n;
cin >> n;

int suma = 0;
for (int i = 1; i <= n; i++) {
    suma += i;
}

cout << suma;

Exemplul 3 – Factorialul unui număr

Cerință: Se citește un număr natural n. Se afișează n! (produsul numerelor de la 1 la n).

Date de intrare: un întreg n. Date de ieșire: n!. Restricții: 0 ≤ n ≤ 12 (pentru ca rezultatul să încapă într-un int).

Exemplu: se citește 5; se afișează 120 (1·2·3·4·5).

Algoritm: (1) se citește n; (2) se inițializează acumulatorul factorial cu 1 (elementul neutru al înmulțirii, nu 0); (3) pentru fiecare i de la 1 la n, se înmulțește factorial cu i; (4) se afișează rezultatul. Pentru n = 0, bucla nu se execută deloc, iar factorial rămâne 1 — valoarea corectă a lui 0!.

C++
int n;
cin >> n;

long long factorial = 1;
for (int i = 1; i <= n; i++) {
    factorial *= i;
}

cout << factorial;
De ce long long?

Factorialul crește foarte rapid — 13! depășește deja limita superioară a unui int. Pentru siguranță, rezultatul unui produs acumulat este de multe ori păstrat într-un tip cu domeniu mai mare, precum long long.

Exemplul 4 – Numărul de cifre ale unui număr

Cerință: Se citește un număr natural n. Se afișează câte cifre are.

Date de intrare: un întreg n. Date de ieșire: numărul de cifre ale lui n. Restricții: 0 ≤ n ≤ 2.000.000.000.

Exemplu: se citește 2024; se afișează 4.

Algoritm: (1) se citește n; (2) atât timp cât n este diferit de 0, se elimină ultima cifră (n = n / 10) și se mărește un contor; (3) se afișează contorul. Numărul de repetări nu este cunoscut dinainte — depinde de valoarea citită — deci while este alegerea potrivită, nu for.

C++
int n;
cin >> n;

int nrCifre = 0;
if (n == 0) {
    nrCifre = 1; // cazul special: 0 are o singura cifra
} else {
    while (n != 0) {
        n /= 10;
        nrCifre++;
    }
}

cout << nrCifre;

Exemplul 5 – Suma cifrelor unui număr

Cerință: Se citește un număr natural n. Se afișează suma cifrelor lui.

Date de intrare: un întreg n. Date de ieșire: suma cifrelor lui n. Restricții: 0 ≤ n ≤ 2.000.000.000.

Exemplu: se citește festival — de fapt 274; se afișează 13 (2+7+4).

Algoritm: (1) se citește n; (2) se inițializează acumulatorul suma cu 0; (3) atât timp cât n este diferit de 0: se extrage ultima cifră cu n % 10, se adaugă la suma, apoi se elimină acea cifră cu n = n / 10; (4) se afișează suma.

C++
int n;
cin >> n;

int suma = 0;
while (n != 0) {
    suma += n % 10;
    n /= 10;
}

cout << suma;

Exemplul 6 – Tabla înmulțirii unui număr

Cerință: Se citește un număr întreg n. Se afișează, câte una pe linie, primele 10 valori ale tablei înmulțirii lui n (n·1 până la n·10).

Date de intrare: un întreg n. Date de ieșire: 10 linii, cu produsele n·1, n·2, ..., n·10. Restricții: 1 ≤ n ≤ 1000.

Exemplu: se citește 7; se afișează, pe linii separate, 7 14 21 28 35 42 49 56 63 70.

Algoritm: (1) se citește n; (2) pentru fiecare i de la 1 la 10, se afișează n * i, urmat de o mutare pe linia următoare — numărul de repetări este fix (10), deci for este structura firească.

C++
int n;
cin >> n;

for (int i = 1; i <= 10; i++) {
    cout << n << " * " << i << " = " << n * i << endl;
}

Exemplul 7 – Sumă cu valoare santinelă

Cerință: Se citesc numere întregi, câte unul, până se introduce valoarea 0, care nu face parte din sumă. Se afișează suma numerelor citite înaintea santinelei.

Date de intrare: o secvență de întregi, terminată cu 0. Date de ieșire: suma numerelor citite, fără santinelă. Restricții: secvența conține cel mult 1000 de valori.

Exemplu: se citește 3 5 -2 0; se afișează 6 (3+5-2).

Algoritm: tipar de buclă cu valoare santinelă: (1) se citește o primă valoare, înaintea buclei; (2) cât timp valoarea citită nu este 0, se adaugă la sumă și se citește următoarea valoare; (3) se afișează suma.

C++
int x, suma = 0;
cin >> x;

while (x != 0) {
    suma += x;
    cin >> x;
}

cout << suma;

Exemplul 8 – Meniu repetat cu do–while

Cerință: Se afișează un meniu cu trei opțiuni (1, 2, 3) și se cere utilizatorului să aleagă una. Dacă opțiunea introdusă nu este validă, cererea se repetă.

Date de intrare: una sau mai multe valori întregi, introduse repetat de utilizator. Date de ieșire: mesajul corespunzător primei opțiuni valide introduse.

Exemplu: se introduce 7, apoi 2; se afișează mesajul asociat opțiunii 2 (după ce 7 este respinsă ca invalidă).

Algoritm: corpul trebuie executat cel puțin o dată — utilizatorul trebuie să aibă șansa să introducă o valoare înainte ca aceasta să poată fi validată — deci se alege do–while, cu condiția de repetare „opțiunea nu este 1, 2 sau 3".

C++
int optiune;

do {
    cout << "1. Suma  2. Produs  3. Iesire\n";
    cout << "Alegeti o optiune: ";
    cin >> optiune;
} while (optiune != 1 && optiune != 2 && optiune != 3);

cout << "Ati ales optiunea " << optiune;

Exerciții introductive (fără scriere de cod)

Rezolvă pe hârtie, apoi verifică cu răspunsul.

1Câte instrucțiuni de ciclare are C++? Numiți-le.

Vezi răspunsul

Trei: while, do–while și for.

2Care este singura dintre cele trei instrucțiuni de ciclare al cărei corp se execută garantat cel puțin o dată?

Vezi răspunsul

do–while — condiția este verificată după executarea corpului, nu înainte.

3Ce se întâmplă dacă, într-o buclă while, condiția este falsă chiar de la prima verificare?

Vezi răspunsul

Corpul buclei nu se execută deloc — execuția trece direct la instrucțiunea de după buclă.

4Care sunt cele trei componente ale unei instrucțiuni for, în ordine?

Vezi răspunsul

Inițializare, condiție, pas — for (initializare; conditie; pas) { ... }.

5La ce moment este evaluat „pasul" dintr-un for — înainte sau după execuția corpului?

Vezi răspunsul

După execuția corpului, și înainte de a reveni la verificarea condiției.

6Care instrucțiune de ciclare are nevoie de ; după condiție?

Vezi răspunsul

do–while: do { ... } while (conditie);

7Ce valoare de inițializare trebuie folosită pentru un acumulator de tip sumă? Dar pentru unul de tip produs?

Vezi răspunsul

Sumă: 0 (elementul neutru al adunării). Produs: 1 (elementul neutru al înmulțirii).

8Ce este o „valoare santinelă"?

Vezi răspunsul

O valoare convențională, care nu apare printre datele valide ale problemei, folosită pentru a marca sfârșitul unei secvențe de date citite repetat.

9De ce o buclă controlată de o valoare santinelă folosește, de regulă, while, și nu for?

Vezi răspunsul

Pentru că numărul de repetări nu este cunoscut dinainte — depinde de datele citite, nu de un contor cu limite fixe.

10Ce se întâmplă dacă, într-o buclă, variabila testată în condiție nu este niciodată modificată în corp?

Vezi răspunsul

Se obține o buclă infinită — condiția rămâne fixă (mereu adevărată sau mereu falsă), iar execuția nu se mai oprește (sau corpul nu se execută niciodată).

Code Tracing – Exerciții

Urmărește execuția fără să rulezi programul. Notează valorile variabilelor la fiecare pas și ce se va afișa. Verifică apoi rulând codul.

Exercițiul 1
C++
int i = 0;
while (i < 3) {
    cout << i << " ";
    i++;
}

Soluție: i=0 (afișează 0) → i=1 (afișează 1) → i=2 (afișează 2) → i=3, condiția devine falsă. Se afișează 0 1 2.

Exercițiul 2
C++
int i = 5;
do {
    cout << i << " ";
    i--;
} while (i > 2);

Soluție: corpul se execută cu i=5,4,3 (afișate), apoi i devine 2 și condiția 2>2 e falsă. Se afișează 5 4 3.

Exercițiul 3
C++
int suma = 0;
for (int i = 1; i <= 4; i++) {
    suma += i * i;
}
cout << suma;

Soluție: 1²+2²+3²+4² = 1+4+9+16 = 30. Se afișează 30.

Exercițiul 4 — do–while cu condiție inițial falsă
C++
int x = 10;
int contor = 0;

do {
    contor++;
} while (x < 5);

cout << contor;

Soluție: chiar dacă x < 5 este falsă de la început, corpul lui do–while tot se execută o dată — contor devine 1, apoi condiția e verificată și e falsă, deci bucla se oprește. Se afișează 1.

Exercițiul 5 — pas negativ
C++
for (int i = 10; i >= 0; i -= 3) {
    cout << i << " ";
}

Soluție: i ia valorile 10, 7, 4, 1; la pasul următor i ar deveni -2, iar -2 >= 0 e fals, deci bucla se oprește. Se afișează 10 7 4 1.

Exercițiul 6 — buclă care nu se execută deloc
C++
int n = 3;
int produs = 1;

for (int i = 5; i <= n; i++) {
    produs *= i;
}

cout << produs;

Soluție: condiția inițială 5 <= 3 este falsă, deci corpul buclei for nu se execută niciodată — produs rămâne 1. Se afișează 1.

Întrebări de autoevaluare

1. Ce este o structură repetitivă și de ce este necesară?

O structură repetitivă execută în mod repetat o instrucțiune sau un bloc, atât timp cât (sau până când) este îndeplinită o condiție. Este necesară pentru că, fără ea, orice acțiune care trebuie repetată de mai multe ori ar trebui scrisă manual de fiecare dată, ceea ce nu se poate generaliza pentru un număr mare sau necunoscut de repetări.

2. Care este diferența esențială dintre while și do–while?

while verifică condiția înaintea fiecărei execuții a corpului, deci corpul se poate executa de zero ori. do–while verifică după execuția corpului, deci acesta se execută întotdeauna cel puțin o dată.

3. Care sunt cele trei componente ale unui for și în ce ordine se execută?

Inițializare (o singură dată, la început), condiție (înaintea fiecărei execuții a corpului) și pas (după fiecare execuție a corpului, înaintea revenirii la condiție).

4. Este for o construcție complet diferită de while, din punct de vedere conceptual?

Nu. Orice for (init; cond; pas) { corp; } este echivalent cu init; while (cond) { corp; pas; } — for este doar o formă mai compactă pentru bucle controlate de un contor.

5. Ce este un contor și ce este un acumulator? Dați câte un exemplu.

Un contor numără de câte ori se întâmplă ceva (ex: numar++;). Un acumulator adună sau înmulțește valori pas cu pas, pentru a obține un total (ex: suma += x;, produs *= x;).

6. De ce trebuie inițializat cu 1, și nu cu 0, un acumulator pentru produs?

Pentru că 1 este elementul neutru al înmulțirii. Dacă acumulatorul ar fi inițializat cu 0, orice înmulțire ulterioară ar da tot 0, indiferent de valorile implicate.

7. Ce este o valoare santinelă și de ce trebuie aleasă cu grijă?

O valoare convențională folosită pentru a marca sfârșitul unei secvențe de date citite repetat. Trebuie aleasă astfel încât să nu poată apărea printre datele valide ale problemei — altfel, o valoare validă ar fi confundată cu semnalul de oprire.

8. Ce este o buclă infinită și ce o provoacă cel mai frecvent?

O buclă a cărei condiție de continuare rămâne mereu adevărată, astfel încât execuția nu se mai oprește. Cauzele frecvente: uitarea instrucțiunii care modifică variabila din condiție, sau un ; rătăcit imediat după condiția lui while/for.

9. Ce este o eroare „off-by-one" și cum apare la o buclă for?

O eroare în care bucla execută cu o repetare în plus sau în minus față de intenția corectă — de exemplu, folosirea lui < în loc de <= (sau invers) în condiția de continuare a buclei.

10. De ce trebuie inițializat un acumulator înaintea buclei, și nu în interiorul ei?

Pentru că, dacă inițializarea este plasată în corpul buclei, valoarea acumulată la pasul anterior este ștearsă la fiecare iterație, iar rezultatul final este incorect.

11. Cum se alege, în general, între while, do–while și for?

for — când numărul de repetări este cunoscut dinainte. while — când repetarea depinde de o condiție care nu este legată de un contor. do–while — când corpul trebuie executat obligatoriu cel puțin o dată.

12. Ce diferență importantă există între for din C++/Java și for din Python?

În C++ și Java, for este format din trei componente explicite (inițializare; condiție; pas). În Python, for parcurge întotdeauna o secvență, de exemplu valorile generate de range(n) — conceptul de buclă cu contor este identic, dar exprimat printr-o parcurgere.

Rezumat – De reținut

Cele mai importante idei din această sesiune
  1. O structură repetitivă execută în mod repetat o instrucțiune sau un bloc, atât timp cât (sau până când) este îndeplinită o condiție — a treia structură de control fundamentală, alături de cea secvențială și cea alternativă.
  2. while verifică condiția înaintea corpului — acesta se poate executa de zero ori.
  3. do–while verifică condiția după corp — acesta se execută întotdeauna cel puțin o dată; necesită ; după condiție.
  4. for (init; conditie; pas) reunește într-o singură linie inițializarea, condiția și pasul — este echivalentă cu un while, dar mai potrivită pentru bucle controlate de un contor, cu număr de repetări cunoscut.
  5. Un contor numără de câte ori se întâmplă ceva; un acumulator adună sau înmulțește valori pas cu pas — ambele trebuie inițializate înaintea buclei (sumă: 0; produs: 1).
  6. O buclă poate fi reprezentată prin schemă logică și pseudocod, la fel ca structura alternativă — diferența vizuală esențială este „revenirea" la testul condiției după executarea corpului, absentă la o simplă decizie.
  7. O buclă controlată printr-o valoare santinelă folosește o citire de pregătire înaintea buclei și o a doua citire în interiorul ei, iar structura potrivită este, de regulă, while.
  8. Alegerea structurii de ciclare este, în esență, o alegere de claritate: for pentru repetări cu număr cunoscut, while pentru condiții fără contor, do–while pentru corp executat obligatoriu măcar o dată.
  9. Erori frecvente: buclă infinită (lipsa pasului, sau ; rătăcit după while/for), eroarea „off-by-one" (< vs. <=), confuzia =/==, reinițializarea acumulatorului în interiorul buclei.
  10. Conceptul de repetare este universal; sintaxa diferă între limbaje — Python nu are do–while și exprimă for printr-o parcurgere (range), nu prin cele trei componente explicite din C++/Java.
  11. Instrucțiunile de salt (break, continue), buclele imbricate și algoritmii elementari construiți cu bucle (maxim, minim, verificare, numărare) sunt subiectul sesiunii următoare.
