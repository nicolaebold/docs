Introducere

Orice program lucrează cu date: nume, prețuri, temperaturi, vârste, rezultate. Pentru a lucra cu date, computerul are nevoie să le memoreze undeva. Variabilele sunt mecanismul prin care rezervăm spațiu în memorie și îi dăm un nume sugestiv.

Dar nu toate datele sunt la fel. Un preț are zecimale, o vârstă nu. Un mesaj este text, un rezultat de test este adevărat/fals. De aceea, în C++, fiecare variabilă are un tip de date declarat explicit – computerul trebuie să știe câtă memorie să aloce și cum să interpreteze biții stocați.

Iar cu datele memorăm, trebuie să și calculăm: adunăm prețuri, comparăm vârste, combinăm condiții. Aceasta înseamnă expresii și operatori.

Unde apar aceste concepte în programe reale?

Orice aplicație reală – de la un site de comerț electronic la un sistem de rezervări sau o aplicație bancară – stochează date în variabile și le procesează prin expresii. Aceasta este fundația absolută a oricărui program.

Concepte fundamentale

Ce este o variabilă?

O variabilă este o locație numită în memoria calculatorului care stochează o valoare. Poți să o gândești ca pe un „sertar etichetat" – eticheta este numele variabilei, sertarul este spațiul din memorie, iar conținutul este valoarea curentă.

Memorie și adrese

Memoria calculatorului este organizată în milioane de celule numerotate (adrese). Când declari int varsta = 25;, compilatorul rezervă automat 4 octeți la o adresă din memorie și îi asociază eticheta „varsta". Tu nu trebuie să cunoști adresa – folosești doar numele.

Fiecare variabilă are trei caracteristici obligatorii:

  • Tip – ce categorie de date stochează (întreg, număr cu zecimale, text, etc.)
  • Nume – identificatorul pe care îl folosești în cod pentru a o accesa
  • Valoare – datele stocate în acel moment (se poate schimba pe parcursul execuției)

C++ – Variante de declarare

Reguli pentru numele de variabile

  • Poate conține litere (a-z, A-Z), cifre (0-9) și underscore (_)
  • Nu poate începe cu o cifră – 1x e invalid, x1 e valid
  • Este case-sensitive – Varsta și varsta sunt variabile diferite
  • Nu poate fi un cuvânt rezervat al limbajului (int, if, for, etc.)
  • Evitați diacriticele – varsta nu vârstă
Convenție de denumire

Folosim camelCase pentru variabile: primul cuvânt cu literă mică, fiecare cuvânt următor cu literă mare. Exemple: pretUnitar, numarStudenti, totalFactura. Evitați nume ca x, a, temp dacă puteți alege ceva mai descriptiv.

Împărțirea întreagă – o capcană frecventă

Dacă ambii operanzi ai / sunt de tip int, rezultatul este și el întreg – zecimalele se pierd. 7 / 2 = 3, nu 3.5. Pentru a obține zecimale, cel puțin un operand trebuie să fie double: 7.0 / 2 = 3.5.

Exemple progresive

Exemplul 1 – Calculul mediei a trei note

Cerință: Declară variabile pentru trei note (cu zecimale) și calculează media lor. Afișează fiecare notă și media.

C++
#include <iostream>
using namespace std;

int main() {
 // Declară și inițializează notele double nota1 = 8.5;
 double nota2 = 9.0;
 double nota3 = 7.5;

 // Calculează media double media = (nota1 + nota2 + nota3) / 3;

 // Afișează cout << "Nota 1: " << nota1 << endl;
 cout << "Nota 2: " << nota2 << endl;
 cout << "Nota 3: " << nota3 << endl;
 cout << "Media: " << media << endl;

 return 0;
}

Rezultat:

Output
Nota 1: 8.5
Nota 2: 9
Nota 3: 7.5
Media: 8.33333

De ce paranteze la media? Fără paranteze, nota1 + nota2 + nota3 / 3 ar evalua mai întâi nota3 / 3 (din cauza priorității) și ar produce un rezultat greșit. Parantezele forțează suma înainte de împărțire.

Ce se întâmplă dacă…?

… folosim int în loc de double pentru prețuri?
C++
int pretFaraTVA = 250;
int cotaTVA = 19; // Greșit! 19 ≠ 0.19
int valoareTVA = pretFaraTVA * cotaTVA; // 250 × 19 = 4750, nu 47.5!

Rezultatul ar fi complet greșit. TVA trebuie exprimat ca fracție zecimală (0.19), ceea ce impune folosirea tipului double.

… eliminăm parantezele de la calculul mediei?
C++
// GREȘIT – fără paranteze:
double media = nota1 + nota2 + nota3 / 3;
// Se evaluează: nota1 + nota2 + (nota3 / 3)
// Adică: 8.5 + 9.0 + (7.5 / 3) = 8.5 + 9.0 + 2.5 = 20.0 — GREȘIT!

// CORECT – cu paranteze:
double media = (nota1 + nota2 + nota3) / 3;
// Se evaluează: (8.5 + 9.0 + 7.5) / 3 = 25.0 / 3 = 8.333

Împărțirea are prioritate mai mare decât adunarea, deci fără paranteze se împarte mai întâi ultimul operand la 3.

… împărțim două int-uri și vrem rezultat cu zecimale?
C++
int a = 7, b = 2;

int rez1 = a / b; // 3 – împărțire întreagă
double rez2 = a / b; // 3.0 – calculul e int, rezultatul e stocat în double
double rez3 = (double)a / b; // 3.5 – cast: convertim a la double înainte de împărțire
double rez4 = a / (double)b; // 3.5 – echivalent
double rez5 = 7.0 / 2; // 3.5 – literal double forțează double division

Tipul rezultatului unei operații aritmetice este determinat de tipurile operanzilor. Dacă ambii sunt int, rezultatul este int, indiferent unde stochezi.

… schimbăm && cu || în verificarea eligibilității?
C++
// Cu &&: ambele condiții trebuie să fie adevărate
bool eligibil_si = (pretProdus >= 100.0) && (cantStoc >= 5);
// Laptop (1200 lei, 8 buc) → true && true = true // Cu ||: suficientă o singură condiție adevărată
bool eligibil_sau = (pretProdus >= 100.0) || (cantStoc >= 5);
// Laptop → true || true = true (același rezultat, dar logică diferită)

// Un caz care le diferențiază – un produs ieftin cu stoc mare:
double pretMic = 50.0;
int stocMare = 100;
bool cu_si = (pretMic >= 100.0) && (stocMare >= 5); // false && true = false
bool cu_sau = (pretMic >= 100.0) || (stocMare >= 5); // false || true = true

Greșeli frecvente

Greșeala 1 – Confuzie între = și ==
C++ – Greșit
int x = 10;
if (x = 5) // GREȘIT: atribuie 5 la x, nu compară! cout << "x este 5";
C++ – Corect
if (x == 5) // CORECT: compară x cu 5 cout << "x este 5";

Explicație: = este operatorul de atribuire – pune o valoare într-o variabilă. == este operatorul de comparație – verifică dacă două valori sunt egale. Confuzia lor este una dintre cele mai frecvente greșeli în C++.

Greșeala 2 – Variabilă neinițializată
C++ – Greșit
int total; // declarată, dar neinițializată
cout << total; // afișează valoare aleatorie din memorie!
C++ – Corect
int total = 0; // inițializat explicit
cout << total; // afișează 0
Greșeala 3 – Tipuri incompatibile
C++ – Greșit
string numar = 42; // 42 este int, nu string
int x = "salut"; // "salut" este string, nu int
C++ – Corect
string numar = "42"; // string
int x = 42; // int
Greșeala 4 – TVA exprimat ca număr întreg
C++ – Greșit
double tva = pret * 19; // pret × 19 = 4750, nu 47.5!
C++ – Corect
double tva = pret * 0.19; // 19% = 0.19

Exemplu de depanare

Cod cu bug
C++
int main() {
 int pretBase = 100;
 int discount = 20; // intenția: 20% int pretFinal = pretBase - pretBase * discount;
 cout << "Pret final: " << pretFinal;
 return 0;
}
Simptom

Programul afișează Pret final: -1900 în loc de 80.

Analiză

pretBase * discount = 100 * 20 = 2000. Programatorul a vrut să calculeze 20% din 100 (adică 20), dar a multiplicat cu 20 în loc de 0.20. Tipul int pentru discount agravează problema.

Corectare
C++ – Corect
double pretBase = 100.0;
double discount = 0.20; // 20% = 0.20
double reducere = pretBase * discount; // 100 × 0.20 = 20
double pretFinal = pretBase - reducere; // 100 - 20 = 80
cout << "Pret final: " << pretFinal; // Afișează: 80

Concluzie: Când lucrezi cu procente, verifică întotdeauna că le exprimi ca fracții zecimale (20% = 0.20) și că folosești double pentru calcule cu zecimale.

Urmărește execuția programului fără să îl rulezi. Scrie valorile variabilelor la fiecare pas și ce se va afișa. Verifică după aceea rulând programul.

int y = 3;

Soluție: 10 / 3 = 3 (împărțire întreagă), 10 % 3 = 1 (restul). Se afișează 3 1.

C++

x += 3;
x *= 2;
cout << x;

Soluție: x = 5, x += 3 → x = 8, x *= 2 → x = 16. Se afișează 16.

Cerințe:

  • Calculează: subtotalul, reducerea (dacă are abonament), baza TVA, TVA, totalul final

Întrebări de autoevaluare

1. Ce este o variabilă și ce trei lucruri o definesc?

O variabilă este o locație numită în memorie. O definesc: tipul (ce fel de date stochează), numele (cu ce o accesezi în cod) și valoarea (ce conține în acel moment).

2. De ce trebuie să declari tipul explicit în C++?

Compilatorul trebuie să știe câtă memorie să aloce și cum să interpreteze biții stocați. Un int ocupă 4 octeți și e interpretat ca număr întreg; un double ocupă 8 octeți și e interpretat ca număr în virgulă mobilă.

3. Care este diferența între = și == în C++?

= este operatorul de atribuire – pune o valoare într-o variabilă. == este operatorul de comparație – verifică dacă două valori sunt egale și returnează true sau false.

4. Ce afișează: int a = 7; int b = 2; cout << a / b;

3. Împărțirea a două int-uri produce un int – zecimalele se pierd. 7 ÷ 2 = 3 rest 1, deci rezultatul este 3.

5. Cum obții rezultat cu zecimale la împărțirea 7 / 2?

Cel puțin un operand trebuie să fie double: 7.0 / 2, 7 / 2.0, (double)7 / 2 sau (double)a / b dacă lucrezi cu variabile.

6. Ce întoarce operatorul % (modulo)?

Restul împărțirii întregi. 7 % 3 = 1 (7 = 3×2 + 1). Util pentru: verificarea parității (n % 2 == 0 → par), extragerea ultimei cifre (n % 10), cicluri.

7. Ce valoare are: bool r = (5 > 3) && (2 > 4)?

false. (5 > 3) = true, (2 > 4) = false. true && false = false. Operatorul && returnează true doar dacă ambele condiții sunt adevărate.

8. Ce greșeală conține: double pret; cout << pret;

Variabila pret este declarată dar neinițializată. Afișează o valoare nedefinită (ce se afla în acel loc de memorie înainte). Trebuie inițializată: double pret = 0.0;

9. Alege tipul corect: temperatura zilei în grade Celsius cu zecimale

double. Temperatura poate fi 23.5°C sau -12.3°C – are zecimale și poate fi negativă. int ar trunchia la 23, respectiv -12.

10. Ce afișează: int x = 5; x += 3; x *= 2; cout << x;

16. x = 5, x += 3 → x = 8, x *= 2 → x = 16.

Rezumat – De reținut

Cele mai importante idei din această sesiune
  1. O variabilă rezervă spațiu în memorie cu un nume sugestiv și un tip fix.
  2. Tipul se alege în funcție de datele stocate: int pentru întregi, double pentru zecimale, string pentru text, bool pentru adevărat/fals.
  3. Inițializează întotdeauna variabilele la declarare.
  4. = este atribuire, == este comparație – confundarea lor produce bug-uri subtile.
  5. Împărțirea a două int-uri produce int – zecimalele se pierd. Folosește double sau cast.
  6. Procentele se exprimă ca fracții zecimale: 19% = 0.19.
  7. Parantezele controlează ordinea evaluării – folosește-le pentru claritate, nu te baza pe memorarea priorităților.
  8. && cere ca toate condițiile să fie adevărate; || cere ca cel puțin una să fie adevărată.
