Variabile și tipuri de date

6 ore (4h teorie + 2h laborator) int · double · char · bool Variabile · Constante · cin/cout Operatori aritmetici de bază C++ · Python · Java

Introducere

Orice program lucrează cu date: vârste, temperaturi, prețuri, inițiale, răspunsuri de tipul adevărat/fals. Pentru a lucra cu date, computerul are nevoie să le memoreze undeva. Variabilele sunt mecanismul prin care rezervăm spațiu în memorie și îi dăm un nume sugestiv.

Dar nu toate datele sunt la fel. Un preț poate avea zecimale, o vârstă de obicei nu. O inițială este un singur caracter, un răspuns este adevărat sau fals. De aceea, în C++, fiecare variabilă are un tip de date declarat explicit – computerul trebuie să știe câtă memorie să aloce și cum să interpreteze biții stocați.

Iar cu datele memorate putem și calcula: adunăm prețuri, calculăm medii, extragem cifrele unui număr. Vom folosi pentru asta câțiva operatori aritmetici de bază – suficient pentru a scrie primele programe utile. Operatorii de comparație, cei logici și modul în care un program ia decizii vor fi aprofundați în sesiunea următoare, după ce stăpânim bine datele asupra cărora aceștia acționează.

Unde apar aceste concepte în programe reale?

Orice aplicație reală – de la un site de comerț electronic la un sistem de rezervări sau o aplicație bancară – stochează date în variabile și le procesează prin calcule. Aceasta este fundația absolută a oricărui program.

La finalul acestei sesiuni vei putea să:

  1. Descrii ce este o variabilă și cum funcționează în memorie
  2. Declari și inițializezi variabile pentru tipurile fundamentale
  3. Identifici tipul potrivit pentru fiecare categorie de date
  4. Diferențiezi o variabilă de o constantă cu nume
  5. Citești valori de la tastatură cu cin și afișezi rezultate cu cout
  6. Utilizezi operatori aritmetici de bază, inclusiv împărțirea întreagă și restul împărțirii
  7. Identifici și corectezi greșelile frecvente legate de tipuri
  8. Urmărești execuția unui program prin trasarea valorilor variabilelor

Date, variabile și operatori – dincolo de C++

Modulul se numește Limbaje de Programare, nu „Limbajul C++". Nu întâmplător: deși în acest curs scriem cod în C++, conceptele din această sesiune – dată, tip de date, variabilă, constantă, operator – nu aparțin lui C++. Ele sunt concepte universale, prezente sub o formă sau alta în orice limbaj de programare folosit azi: Python, Java, C#, JavaScript, Rust etc. Ce diferă de la un limbaj la altul este sintaxa (cum se scriu) și câteva reguli (cum se verifică tipurile, ce se întâmplă la împărțire etc.), nu ideea din spate.

Tipizare statică vs. tipizare dinamică

C++ și Java folosesc tipizare statică: tipul unei variabile se declară explicit în cod și este verificat de compilator înainte ca programul să ruleze. Python folosește tipizare dinamică: nu declari tipul variabilei – acesta este asociat cu valoarea curentă și poate fi verificat abia când linia respectivă de cod se execută.

Concepte fundamentale în C++

Ce este o variabilă?

O variabilă este o locație numită în memoria calculatorului care stochează o valoare. Poți să o gândești ca pe o „cutie etichetată" – eticheta este numele variabilei, cutia este spațiul din memorie, iar conținutul este valoarea curentă.

varsta
18
int
Memorie și adrese

Memoria calculatorului este organizată în milioane de celule numerotate (adrese), grupate în octeți (bytes). Când declari int varsta = 18;, compilatorul rezervă automat 4 octeți la o adresă din memorie și îi asociază eticheta „varsta". Tu nu trebuie să cunoști adresa – folosești doar numele.

Fiecare variabilă are trei caracteristici obligatorii:

  • Tip – ce categorie de date stochează (întreg, număr cu zecimale, caracter etc.)
  • Nume (identificator) – cum o accesezi în cod
  • Valoare – datele stocate în acel moment (se poate schimba pe parcursul execuției)

Valorile de mai sus sunt cele întâlnite pe majoritatea compilatoarelor moderne pentru sisteme desktop pe 32/64 de biți (GCC, Clang, MSVC). Standardul C++ garantează explicit doar dimensiunea lui char (1 octet); pentru celelalte tipuri, dimensiunea exactă poate varia pe alte platforme.

Este important să distingem caracterul '7' de numărul întreg 7: primul este de tip char, al doilea de tip int – au reprezentări diferite în memorie, chiar dacă la afișare pot arăta asemănător.

Cum tratează Python și Java o variabilă „neinițializată"

În Python, conceptul nici nu există: o variabilă ia naștere în momentul primei atribuiri (x = 10) – nu poți „declara" o variabilă goală, fără valoare. În Java, poți scrie int y; la fel ca în C++, dar compilatorul Java este mai strict: dacă încerci să citești valoarea lui y înainte de a-i atribui ceva, obții o eroare de compilare (regula „definite assignment"), nu doar o valoare nedefinită ca în C++. Este un exemplu clar în care aceeași idee (variabilă neinițializată) e tratată diferit de fiecare limbaj.

Reguli pentru numele de variabile

  • Poate conține litere (a-z, A-Z), cifre (0-9) și underscore (_)
  • Nu poate începe cu o cifră – 1x e invalid, x1 e valid
  • Este case-sensitive – Varsta și varsta sunt variabile diferite
  • Nu poate fi un cuvânt rezervat al limbajului (int, if, for etc.)
  • Evitați diacriticele – varsta, nu vârstă
Convenție de denumire

Folosim frecvent camelCase pentru variabile: primul cuvânt cu literă mică, fiecare cuvânt următor cu literă mare. Exemple: pretUnitar, numarStudenti, totalFactura. Evitați nume ca x, a, temp dacă puteți alege ceva mai descriptiv.

Uneori avem nevoie de valori care trebuie să rămână neschimbate pe parcursul programului: numărul de zile ale unei săptămâni, valoarea aproximativă a lui π, numărul de luni ale unui an. O astfel de valoare se declară ca constantă, folosind cuvântul-cheie const.

În Python, nimic nu împiedică tehnic scrierea NR_ZILE = 8 mai departe în cod – „constanta" este doar o convenție de denumire, respectată prin disciplină, nu impusă de limbaj.

Prioritatea operatorilor aritmetici

Când o expresie conține mai mulți operatori aritmetici, C++ îi evaluează într-o ordine bine definită: *, / și % au prioritate mai mare decât + și -.

PrioritateOperatoriExemplu
1 (cel mai mare)() Paranteze(2 + 3) * 4 = 20
2* / %2 + 3 * 4 → 14
3 (cel mai mic)+ -10 - 2 + 3 = 11

Parantezele pot fi folosite oricând pentru a impune explicit ordinea dorită și pentru a face expresia mai ușor de citit.

Aceeași regulă, în toate limbajele
// C++ si Java:
cout << (2 + 3 * 4);   // 14

# Python:
print(2 + 3 * 4)   # 14
Împărțirea întreagă – o capcană frecventă

Dacă ambii operanzi ai / sunt de tip int, rezultatul este și el întreg – zecimalele se pierd (se trunchiază, nu se rotunjesc). 7 / 2 = 3, nu 3.5. Pentru a obține zecimale, cel puțin un operand trebuie să fie double: 7.0 / 2 = 3.5.

Aceeași capcană, comparată în cele trei limbaje — observă că doar Python 3 se comportă diferit implicit:

C++
cout << 7 / 2;    // 3 (int / int)
cout << 7.0 / 2;  // 3.5
Python
print(7 / 2)    # 3.5 - "/" e mereu reala in Python 3
print(7 // 2)   # 3   - "//" e impartirea intreaga
Java
System.out.println(7 / 2);     // 3 (int / int, la fel ca in C++)
System.out.println(7.0 / 2);   // 3.5

Exemple progresive

Exemplul 1 – Calculul mediei a trei note

Cerință: Declară variabile pentru trei note (cu zecimale) și calculează media lor. Afișează fiecare notă și media.

C++
#include <iostream>
using namespace std;

int main() {
    // Declara si initializeaza notele
    double nota1 = 8.5;
    double nota2 = 9.0;
    double nota3 = 7.5;

    // Calculeaza media
    double media = (nota1 + nota2 + nota3) / 3;

    // Afiseaza
    cout << "Nota 1: " << nota1 << endl;
    cout << "Nota 2: " << nota2 << endl;
    cout << "Nota 3: " << nota3 << endl;
    cout << "Media: " << media << endl;

    return 0;
}

Rezultat:

Output
Nota 1: 8.5
Nota 2: 9
Nota 3: 7.5
Media: 8.33333

De ce paranteze la media? Fără paranteze, nota1 + nota2 + nota3 / 3 ar evalua mai întâi nota3 / 3 (din cauza priorității operatorilor) și ar produce un rezultat greșit. Parantezele forțează suma înainte de împărțire.

Ce se întâmplă dacă…?

… folosim int în loc de double pentru prețuri?
C++
int pretFaraTVA = 250;
int cotaTVA = 19; // Gresit! 19 nu e acelasi lucru cu 0.19
int valoareTVA = pretFaraTVA * cotaTVA; // 250 x 19 = 4750, nu 47.5!

Rezultatul ar fi complet greșit. TVA trebuie exprimat ca fracție zecimală (0.19), ceea ce impune folosirea tipului double.

… eliminăm parantezele de la calculul mediei?
C++
// GRESIT - fara paranteze:
double media = nota1 + nota2 + nota3 / 3;
// Se evalueaza: nota1 + nota2 + (nota3 / 3)
// Adica: 8.5 + 9.0 + (7.5 / 3) = 8.5 + 9.0 + 2.5 = 20.0 -- GRESIT!

// CORECT - cu paranteze:
double media = (nota1 + nota2 + nota3) / 3;
// Se evalueaza: (8.5 + 9.0 + 7.5) / 3 = 25.0 / 3 = 8.333

Împărțirea are prioritate mai mare decât adunarea, deci fără paranteze se împarte mai întâi ultimul operand la 3.

… împărțim două int-uri și vrem rezultat cu zecimale?
C++
int a = 7, b = 2;

int rez1 = a / b;          // 3 - impartire intreaga
double rez2 = a / b;       // 3 - calculul e int, doar rezultatul e stocat in double
double rez3 = 7.0 / b;     // 3.5 - literalul 7.0 forteaza impartire reala
double rez4 = a / 2.0;     // 3.5 - la fel, literalul 2.0 forteaza impartire reala

Tipul rezultatului unei operații aritmetice este determinat de tipurile operanzilor implicați în calcul, nu de tipul variabilei în care este stocat rezultatul.

… atribuim o valoare zecimală unei variabile de tip int?
C++
int x = 7.9;
cout << x; // afiseaza 7, nu 7.9!

Partea fracționară este trunchiată (eliminată), nu rotunjită. Dacă ai nevoie de valoarea 7.9, variabila trebuie declarată double, nu int.

Greșeli frecvente

Greșeala 1 – Confuzie între = și ==
C++ – Greșit
int x = 10;
bool egal = (x = 5); // GRESIT: atribuie 5 la x, nu compara!
// dupa aceasta linie, x devine 5, iar "egal" devine true (pentru ca 5 e nenul)
C++ – Corect
int x = 10;
bool egal = (x == 5); // CORECT: compara x cu 5, fara sa modifice x

Explicație: = este operatorul de atribuire – pune o valoare într-o variabilă. == este operatorul de comparație – verifică dacă două valori sunt egale, fără să modifice nimic. Confuzia lor este una dintre cele mai frecvente greșeli în C++.

Greșeala 2 – Variabilă neinițializată
C++ – Greșit

cout << total; // afiseaza o valoare nedefinita din memorie!
C++ – Corect

Greșeala 3 – Confuzie între caracter și literal numeric
C++ – Greșit

int litera = 'A';  // compileaza, dar stocheaza codul ASCII (65), nu are sens
C++ – Corect
char cifra = '7';  // caracterul cifra sapte

Explicație: '7' (între apostrofuri) este caracterul cifră șapte; 7 (fără apostrofuri) este numărul întreg șapte. Cele două au reprezentări diferite în memorie.

C++ – Greșit

Întrebări de autoevaluare

1. Ce este o variabilă și ce trei lucruri o definesc?

O variabilă este o locație numită în memorie. O definesc: tipul (ce fel de date stochează), numele (cu ce o accesezi în cod) și valoarea (ce conține în acel moment).

2. De ce trebuie să declari tipul explicit în C++?

Compilatorul trebuie să știe câtă memorie să aloce și cum să interpreteze biții stocați. Un int ocupă de regulă 4 octeți și e interpretat ca număr întreg; un double ocupă de regulă 8 octeți și e interpretat ca număr în virgulă mobilă.

3. Care este diferența dintre o variabilă și o constantă cu nume?

O variabilă își poate schimba valoarea pe parcursul programului. O constantă (declarată cu const) primește o valoare la inițializare, iar apoi aceasta nu se mai poate modifica.

4. Ce afișează: int a = 7; int b = 2; cout << a / b;

3. Împărțirea a două int-uri produce un int – zecimalele se pierd. 7 ÷ 2 = 3 rest 1, deci rezultatul este 3.

5. Cum obții rezultat cu zecimale la împărțirea 7 / 2?

Cel puțin un operand implicat în calcul trebuie să fie double: 7.0 / 2 sau 7 / 2.0.

6. Ce întoarce operatorul % (modulo)?

Restul împărțirii întregi. 7 % 3 = 1 (7 = 3×2 + 1). Este folosit frecvent pentru extragerea cifrelor unui număr, de exemplu n % 10 dă ultima cifră a lui n.

7. Care este diferența dintre = și == în C++?

= este operatorul de atribuire – pune o valoare într-o variabilă. == este operatorul de comparație – verifică dacă două valori sunt egale și produce un rezultat de tip bool, fără să modifice nimic.

8. Ce greșeală conține: double pret; cout << pret;

Variabila pret este declarată dar neinițializată. Afișează o valoare nedefinită (ce se afla în acel loc de memorie înainte). Trebuie inițializată: double pret = 0.0;

9. Alege tipul corect: temperatura zilei în grade Celsius, cu zecimale

double. Temperatura poate fi 23.5°C sau -12.3°C – are zecimale și poate fi negativă. int ar trunchia la 23, respectiv -12.

10. Ce afișează: int x = 5; x += 3; x *= 2; cout << x;

16. x = 5, x += 3 → x = 8, x *= 2 → x = 16.

11. De ce este 'A' diferit de "A" în C++?

'A' (apostrofuri) este un literal de tip char – un singur caracter. "A" (ghilimele) este un literal de tip șir de caractere, un concept pe care îl vom aprofunda separat. Pentru un singur caracter, folosește întotdeauna apostrofuri simple.

12. Care este diferența dintre tipizarea statică (C++, Java) și cea dinamică (Python)?

La tipizarea statică, tipul unei variabile este scris explicit în cod și verificat de compilator înainte ca programul să ruleze. La tipizarea dinamică, tipul nu se scrie – este asociat cu valoarea curentă și verificat abia când acea linie de cod se execută.

13. De ce 7 / 2 dă rezultate diferite în C++ și în Python 3?

În C++, dacă ambii operanzi sunt int, / face împărțire întreagă (7 / 2 = 3). În Python 3, / face întotdeauna împărțire reală (7 / 2 = 3.5); pentru împărțire întreagă, Python folosește operatorul separat // (7 // 2 = 3).

Rezumat – De reținut

Cele mai importante idei din această sesiune
  1. O variabilă rezervă spațiu în memorie cu un nume sugestiv și un tip fix.
  2. Tipul se alege în funcție de datele stocate: int pentru întregi, double pentru zecimale, char pentru un singur caracter, bool pentru adevărat/fals.
  3. O constantă (const) este o valoare care, după inițializare, nu se mai poate modifica.
  4. Inițializează întotdeauna variabilele la declarare.
  5. cin citește valori de la tastatură, cout afișează valori și texte pe ecran.
  6. = este atribuire, == este comparație – confundarea lor produce bug-uri subtile.
  7. Împărțirea a două int-uri produce int – zecimalele se pierd. Folosește double pentru rezultate cu zecimale.
  8. Procentele se exprimă ca fracții zecimale: 19% = 0.19.
  9. Parantezele controlează ordinea evaluării – folosește-le pentru claritate, nu te baza doar pe memorarea priorităților.
  10. Operatorii de comparație și cei logici sunt de reținut ca referință – folosirea lor practică în decizii (if) urmează în sesiunea 3.
  11. Date, variabile, tipuri și operatori aritmetici sunt concepte universale de programare – C++, Python și Java le exprimă printr-o sintaxă diferită, dar ideea din spate este aceeași.
  12. C++ și Java folosesc tipizare statică (tipul se declară și se verifică la compilare); Python folosește tipizare dinamică (tipul e asociat cu valoarea, verificat la execuție).
