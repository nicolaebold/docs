Date și variabile

6 ore int · double · char · bool Variabile · Constante cin · cout · Operatori

Prerequisite – ce trebuie să știi înainte

  • Ai parcurs S1 (De la calculator la primul program) și știi structura minimală a unui program C++: #include, using namespace std;, int main() { ... return 0; }
  • Ai scris, compilat și rulat cel puțin un program simplu cu cout
  • Nu este necesară experiență anterioară cu variabile sau tipuri de date – acestea sunt introduse de la zero în această sesiune

La finalul acestei sesiuni vei putea să:

  1. Explici ce este o dată într-un program și de ce nu toate datele sunt la fel
  2. Recunoști tipurile fundamentale int, double, char și bool și să alegi tipul potrivit pentru o informație dată
  3. Explici ce este o variabilă și să identifici numele, tipul și valoarea ei
  4. Declari și inițializezi variabile, respectând regulile pentru identificatori
  5. Modifici valoarea unei variabile și să urmărești, pas cu pas, evoluția ei într-un program
  6. Diferențiezi o variabilă de o constantă cu nume și un literal
  7. Citești valori de la tastatură cu cin și să afișezi rezultate cu cout
  8. Efectuezi calcule aritmetice simple, inclusiv împărțirea întreagă și restul împărțirii
  9. Transformi un enunț de problemă într-un set de variabile, tipuri și instrucțiuni

De la instrucțiuni la date

În sesiunea anterioară am privit un program ca pe o succesiune de instrucțiuni precise, executate de calculator. Am scris primul program C++ și am folosit cout pentru a afișa un mesaj fix pe ecran.

Un program real nu se limitează la afișarea unor texte fixe. Pentru a rezolva o problemă, el trebuie să lucreze cu informații: numere, texte, caractere sau valori logice. De exemplu, un program poate avea nevoie să memoreze vârsta unei persoane, temperatura dintr-o cameră, prețul unui produs, inițiala unui nume, numărul de produse din stoc sau răspunsul la o întrebare de tipul adevărat/fals.

Toate aceste informații reprezintă date. În această sesiune vom studia modul în care datele sunt reprezentate și păstrate într-un program și vom introduce unul dintre cele mai importante concepte din programare: variabila.

date→ tipuri de date→ variabile→ valori

Operatorii, expresiile mai complexe și structurile de control (deciziile, repetițiile) vor fi studiate în sesiunile următoare, după ce înțelegem bine ce sunt datele asupra cărora acestea acționează.

Ideea centrală: variabila ca o cutie

Pentru început, vom folosi un model simplu și intuitiv: o variabilă este o cutie în care putem păstra o anumită valoare. Cutia are un nume (pentru a o identifica), este destinată unui anumit fel de conținut, conține la un moment dat o anumită valoare, iar această valoare se poate schimba.

Model simplificat

Acesta este un model didactic, util pentru a înțelege conceptul. În realitate, calculatorul nu creează o cutie fizică – variabila este asociată unei zone din memoria calculatorului. Modelul cutiei ne ajută să raționăm despre program fără să fie nevoie să cunoaștem adresa exactă din memorie.

De la modelul cutiei la memoria calculatorului

Memoria calculatorului este organizată în unități elementare numite octeți (bytes). O dată poate ocupa unul sau mai mulți octeți, în funcție de tipul său și de compilatorul folosit. Numele unei variabile ne permite să folosim o valoare fără să fie nevoie să cunoaștem locul exact în care aceasta este memorată.

De reținut

Programatorul lucrează cu numele variabilei (varsta), nu cu adresa ei din memorie. Compilatorul se ocupă de asocierea dintre nume și zona de memorie corespunzătoare.

Nu toate informațiile arată la fel: 18 este un număr întreg, 18.5 are o parte fracționară, 'A' este un caracter, iar true este o valoare logică. Doar șirul de biți din memorie nu este suficient pentru a preciza semnificația unei valori – este necesar să știm și cum trebuie interpretat acel conținut. Aici intervine noțiunea de tip de date.

Tipuri de date

Un tip de date descrie o categorie de valori și modul în care calculatorul trebuie să lucreze cu ele: ce valori pot fi reprezentate, cum sunt memorate și interpretate, cât spațiu ocupă și ce operații pot fi efectuate asupra lor.

int

Numere întregi, fără parte fracționară.

int varsta = 18;
double

Numere reale, cu parte fracționară.

double temp = 21.5;
char

Un singur caracter, scris între apostrofuri.

char initiala = 'A';
bool

Valoare logică: true sau false.

bool prezent = true;

Tipul int

Tipul int este folosit pentru numere întregi: vârste, cantități, numere de persoane sau obiecte. Domeniul exact de valori depinde de compilator și de platformă, dar pe majoritatea compilatoarelor moderne pentru sisteme desktop pe 32/64 de biți (GCC, Clang, MSVC), int ocupă 4 octeți (32 de biți) și poate reprezenta valori întregi de la −2 147 483 648 până la 2 147 483 647. Standardul C++ garantează însă doar un domeniu minim de cel puțin −32 767 până la 32 767, motiv pentru care nu trebuie să presupunem automat aceeași dimensiune pe orice sistem.

Tipurile float și double

Pentru numere care pot avea parte fracționară folosim tipuri în virgulă mobilă. Pe majoritatea compilatoarelor actuale, float ocupă 4 octeți și double ocupă 8 octeți, ambele fiind reprezentate, de regulă, conform standardului IEEE 754 pentru numere în virgulă mobilă (deși C++ însuși nu impune obligatoriu acest standard). double oferă o precizie mai mare (aproximativ 15–17 cifre zecimale semnificative) decât float (aproximativ 6–7 cifre). Pentru aplicațiile din acest curs vom folosi în principal double.

Precizie finită

Numerele reale sunt reprezentate în calculator cu precizie finită. Unele valori zecimale (de exemplu 0.1) nu pot fi reprezentate exact în binar, ceea ce poate produce mici erori de rotunjire la calcule repetate. Această observație va deveni importantă atunci când vom compara valori reale.

Tipul char

Tipul char reprezintă un singur caracter, scris între apostrofuri: 'A', '7', '#'. Standardul C++ garantează sizeof(char) == 1 – adică un char ocupă, prin definiție, exact un octet, indiferent de compilator sau platformă. Este esențial să distingem caracterul '7' de numărul întreg 7: acestea au reprezentări și semnificații diferite, chiar dacă pot arăta asemănător la afișare.

Caracterele sunt codificate numeric. În standardul ASCII, literei 'A' îi corespunde valoarea numerică 65, iar cifrei '7' îi corespunde valoarea 55. Sistemele moderne folosesc adesea și codificări bazate pe Unicode, compatibile cu ASCII pentru caracterele de bază.

Tipul bool

Tipul bool este folosit pentru informații care pot avea doar două valori: true (adevărat) sau false (fals) – de exemplu, dacă un elev este prezent sau dacă un produs mai este în stoc. Dimensiunea unui bool este definită de implementare, dar este, în mod obișnuit, de 1 octet pe compilatoarele actuale.

Variabile

O variabilă este o zonă de memorie asociată unui nume, în care programul poate păstra o valoare de un anumit tip. Valoarea unei variabile se poate modifica în timpul execuției programului, fără ca numele sau tipul ei să se schimbe.

Identificatorul unei variabile

Numele prin care ne referim la o variabilă se numește identificator. Un identificator bine ales sugerează clar semnificația informației păstrate: nrElevi este mai ușor de înțeles decât x.

În C++, identificatorii sunt formați din litere, cifre și caracterul underscore (_). Un identificator nu poate începe cu o cifră și nu poate fi un cuvânt-cheie al limbajului. C++ face diferență între litere mari și mici (varsta, Varsta și VARSTA sunt trei identificatori diferiți).

Declarare și inițializare

Înainte de a fi folosită, o variabilă trebuie declarată – trebuie precizate tipul și numele ei:

C++
int varsta;

O variabilă poate primi o valoare chiar la declarare – operație numită inițializare:

C++
int varsta = 18;
int varsta;

Variabile neinițializate

O variabilă locală declarată fără inițializare poate avea o valoare inițială nedeterminată (conținutul „vechi" al acelei zone de memorie). Din acest motiv, este o practică bună să inițializăm variabilele înainte de a le folosi.

Constante

Există situații în care avem nevoie de valori care trebuie să rămână neschimbate pe parcursul programului: numărul de zile ale unei săptămâni, valoarea aproximativă a lui π, numărul de luni ale unui an. O astfel de valoare poate fi tratată în program ca o constantă.

C++
const int NR_ZILE = 7;
const double PI = 3.14159;

Cuvântul-cheie const indică faptul că valoarea nu mai poate fi modificată ulterior prin acel nume; o încercare de a atribui o nouă valoare unei constante este o eroare de compilare. Prin convenție (nu prin cerință a limbajului), constantele cu nume sunt scrise adesea cu litere mari.

Citirea și afișarea datelor

Până acum am atribuit valori direct în cod. În multe programe, valorile nu sunt cunoscute în momentul scrierii codului și trebuie introduse de utilizator în timpul execuției. Pentru aceasta folosim cin (citire) și cout (afișare), disponibile prin biblioteca <iostream>.

Citirea unei valori cu cin

C++
int varsta;
cin >> varsta;

Instrucțiunea cin >> varsta; așteaptă introducerea unei valori de la tastatură și o memorează în variabila varsta. Putem citi mai multe variabile într-o singură instrucțiune, în ordinea în care apar:

C++
int a, b;
cin >> a >> b;

Afișarea unei valori cu cout

C++
cout << "Varsta: " << varsta << endl;

Textele fixe (între ghilimele) și valorile variabilelor pot fi combinate în lanț cu operatorul <<. endl trece la un rând nou.

Program complet: citire și afișare

C++
#include <iostream>
using namespace std;

int main() {
    int varsta;
    double inaltime;
    char initiala;

    cin >> varsta >> inaltime >> initiala;

    cout << "Varsta: " << varsta << endl;
    cout << "Inaltime: " << inaltime << endl;
    cout << "Initiala: " << initiala << endl;

    return 0;
}

Modelul frecvent al unui program simplu este: citim date → le păstrăm în variabile → le prelucrăm → afișăm rezultatul.

Primele calcule cu valori

Odată memorate în variabile, valorile pot fi folosite în calcule.

OperatorOperațieExemplu

Împărțirea numerelor întregi

Cea mai frecventă capcană pentru începători

Dacă ambii operanzi ai împărțirii (/) sunt întregi, rezultatul este tot întreg, iar partea fracționară este eliminată (trunchiată), nu rotunjită: 7 / 2 are rezultatul 3, nu 3.5. Pentru un rezultat cu parte fracționară, cel puțin unul dintre operanzi trebuie să fie de tip real, de exemplu 7.0 / 2 sau (double)7 / 2.

Restul împărțirii: operatorul %

Operatorul % calculează restul împărțirii întregi. Este foarte util pentru probleme cu cifrele unui număr:

C++
int n = 379;
int unitati = n % 10;       // 9
int zeci    = n / 10 % 10; // 7
int sute    = n / 100;      // 3

Rezultatul unui calcul salvat într-o variabilă

C++
int lungime = 5;
int latime = 3;
int aria = lungime * latime;

Variabila aria reține rezultatul calculat în momentul atribuirii, nu expresia în sine. Dacă modificăm ulterior lungime, aria nu se actualizează automat.

Operatorii limbajului C++

Un operator este un simbol care indică efectuarea unei operații asupra unuia sau mai multor operanzi. C++ oferă mai multe categorii de operatori; pentru această sesiune sunt relevante primele două rânduri din tabelul de mai jos.

CategorieRolExemple
Aritmeticiefectuează calcule numerice+ - * / %
Atribuiremodifică valoarea unei variabile= += -= *= /= %=
Comparațiecompară două valori (rezultat bool)< <= > >= == !=
Logicicombină condiții logice! && ||
Incrementare / decrementaremăresc sau micșorează o valoare cu 1++ --
Nu confunda = cu ==

= este operatorul de atribuire – copiază o valoare într-o variabilă. == este operatorul de comparație – verifică dacă două valori sunt egale și produce un rezultat bool. Confuzia dintre cei doi este una dintre cele mai frecvente greșeli la începători.

Prioritatea operatorilor

Într-o expresie cu mai mulți operatori, aceștia nu se aplică strict de la stânga la dreapta. *, / și % au prioritate mai mare decât + și -:

C++
2 + 3 * 4   // rezultat: 14, nu 20
(2 + 3) * 4 // rezultat: 20

Parantezele pot fi folosite oricând pentru a impune explicit ordinea dorită și pentru a face expresia mai ușor de citit.

De la enunț la program

Înainte de a scrie codul, este util să transformăm un enunț de problemă într-un model simplu: date de intrare → variabile → calcul → rezultat.

PasÎntrebare
1Ce informații primesc?
2În ce variabile le păstrez și ce nume le dau?
3Ce tip are fiecare variabilă?
4Ce rezultat trebuie să obțin?
5Cum calculez rezultatul din datele de intrare?

Exemplu: „Într-o curte se află n găini și m vaci. Determinați numărul total de picioare." Fiecare găină are 2 picioare, fiecare vacă are 4 picioare, deci picioare = 2 * gaini + 4 * vaci.

C++
#include <iostream>
using namespace std;

int main() {
    int gaini, vaci, picioare;

    cin >> gaini >> vaci;
    picioare = 2 * gaini + 4 * vaci;
    cout << picioare;

    return 0;
}

Întrebări de verificare

Întrebări scurte, fără presiunea unui test formal. Scopul este să verifici dacă ai înțeles ideile esențiale ale sesiunii.

1. Ce este o dată, în sensul folosit în programare?

O informație pe care un program o primește, o păstrează, o prelucrează sau o produce: numere, texte, caractere, valori logice etc.

2. De ce nu este suficient să știm doar șirul de biți al unei valori?

Pentru că aceeași secvență de biți poate fi interpretată diferit în funcție de tip: de exemplu, o anumită secvență poate reprezenta fie un număr întreg, fie un caracter. Tipul spune calculatorului cum trebuie interpretat conținutul.

3. Care este diferența dintre int și double?

int reprezintă numere întregi, fără parte fracționară. double reprezintă numere reale, care pot avea zecimale, cu o precizie mai mare decât float.

4. Ce diferență există între 7, '7' și "7"?

7 este numărul întreg șapte (int); '7' este caracterul cifră șapte (char); "7" este un șir de caractere format dintr-un singur caracter (string). Cele trei au reprezentări și tipuri diferite.

5. Ce este o variabilă?

O zonă de memorie asociată unui nume (identificator), destinată păstrării unei valori de un anumit tip; valoarea ei se poate modifica pe parcursul execuției programului.

6. Care este diferența dintre declarare și inițializare?

Declararea stabilește existența, tipul și numele variabilei (int varsta;). Inițializarea îi oferă o primă valoare, de regulă în același moment cu declararea (int varsta = 18;).

7. De ce este riscant să folosești o variabilă neinițializată?

Pentru că o variabilă locală de tip simplu declarată fără inițializare poate conține o valoare nedeterminată (rămasă întâmplător în acea zonă de memorie), ceea ce poate duce la rezultate imprevizibile.

8. Ce reprezintă un identificator și ce restricții are în C++?

Este numele unei variabile (sau constante). Poate conține litere, cifre și underscore, nu poate începe cu o cifră și nu poate coincide cu un cuvânt-cheie al limbajului. C++ face diferență între litere mari și mici.

9. Ce este o constantă cu nume și cum se declară?

O valoare cu nume care, după inițializare, nu mai poate fi modificată. Se declară folosind cuvântul-cheie const, de exemplu const int NR_ZILE = 7;.

10. Ce rezultat are 7 / 2 în C++ și de ce?

Rezultatul este 3, nu 3.5, deoarece ambii operanzi sunt de tip întreg, iar împărțirea întreagă elimină (trunchiază) partea fracționară.

11. La ce este util operatorul %?

Calculează restul împărțirii întregi. Este folosit frecvent pentru extragerea cifrelor unui număr (de exemplu, n % 10 dă ultima cifră a lui n).

12. Care este diferența dintre operatorii = și ==?

= este operatorul de atribuire – copiază o valoare într-o variabilă. == este operatorul de comparație – verifică egalitatea a două valori și produce un rezultat de tip bool.

13. De ce are 2 + 3 * 4 rezultatul 14 și nu 20?

Pentru că operatorul * are prioritate mai mare decât +, deci se evaluează mai întâi 3 * 4 = 12, apoi 2 + 12 = 14. Pentru a forța ordinea dorită, se folosesc paranteze: (2 + 3) * 4 = 20.

Rezumat – De reținut

Ideile esențiale ale sesiunii 2
  1. Un program lucrează cu date; fiecare dată are un tip care stabilește ce valori poate avea și cum sunt interpretate.
  2. Tipurile fundamentale studiate: int (întregi), double (reale), char (un caracter), bool (adevărat/fals).
  3. O variabilă este o cutie cu nume (identificator), tip și valoare; valoarea se poate modifica, tipul și numele rămân neschimbate.
  4. Declararea stabilește tipul și numele; inițializarea oferă prima valoare.
  5. O constantă cu nume (const) este o valoare care, după inițializare, nu se mai poate modifica.
  6. cin citește valori de la tastatură; cout afișează valori și texte pe ecran.
  7. Împărțirea a doi operanzi întregi produce un rezultat întreg (trunchiat); operatorul % dă restul împărțirii întregi.
  8. Operatorii *, /, % au prioritate mai mare decât + și -; parantezele impun explicit ordinea dorită.
  9. Rezolvarea unei probleme simple urmează adesea schema: date de intrare → variabile → calcul → rezultat.

Ce urmează?

Suma cifrelor unui număr cu trei cifre

Cerință

Citește un număr natural cu exact trei cifre și afișează suma celor trei cifre ale sale.

Exemplu
Intrare: 379
Iesire : 19
Indiciu

Extrage fiecare cifră separat: unități = n % 10, zeci = n / 10 % 10, sute = n / 100. Apoi adună-le.

Soluție
C++
#include <iostream>
using namespace std;

int main() {
    int n, unitati, zeci, sute, suma;
    cin >> n;

    unitati = n % 10;
    zeci    = n / 10 % 10;
    sute    = n / 100;
    suma    = unitati + zeci + sute;

    cout << suma;
    return 0;
}

De reținut: Combinarea / și % pentru extragerea cifrelor este un tipar foarte des întâlnit în exerciții și va reveni frecvent pe parcursul modulului.

7
Celsius în Fahrenheit
double · precedență operatori

Cerință

Citește o temperatură exprimată în grade Celsius și transformă-o în grade Fahrenheit, folosind formula F = C * 9 / 5 + 32.

Exemplu
Intrare: 20
Iesire : 68
Indiciu

Dacă declari C ca double, expresia C * 9 / 5 se evaluează corect ca împărțire reală. Dacă în schimb ai avea 9 / 5 calculat separat între doi întregi, rezultatul ar fi trunchiat la 1 în loc de 1.8 – atenție la ordinea operațiilor și la tipurile implicate.

Soluție
C++
#include <iostream>
using namespace std;

int main() {
    double c, f;
    cin >> c;
    f = c * 9 / 5 + 32;
    cout << f;
    return 0;
}

De reținut: Deoarece c este double, întreaga expresie c * 9 / 5 se evaluează folosind aritmetica în virgulă mobilă, deci rezultatul păstrează partea fracționară corect.

8
Numărul invers
int · construcție de număr

Cerință

Citește un număr natural cu exact trei cifre și afișează numărul format din aceleași cifre, în ordine inversă.

Exemplu
Intrare: 123
Iesire : 321
Indiciu

Extrage cifrele (unități, zeci, sute) exact ca la exercițiul anterior. Apoi construiește noul număr: invers = unitati * 100 + zeci * 10 + sute;

Soluție
C++
#include <iostream>
using namespace std;

int main() {
    int n, unitati, zeci, sute, invers;
    cin >> n;

    unitati = n % 10;
    zeci    = n / 10 % 10;
    sute    = n / 100;
    invers  = unitati * 100 + zeci * 10 + sute;

    cout << invers;
    return 0;
}

Provoacă-te: Ce s-ar întâmpla dacă numărul introdus s-ar termina în 0 (de exemplu 320)? Numărul „invers" ar începe cu 0, iar C++ ar afișa 23, nu 023 – deoarece un întreg nu păstrează zerourile nesemnificative de la început.

Extragerea cifrelor unui număr prin combinarea împărțirii întregi cu restul împărțirii – un tipar fundamental, reîntâlnit constant în programare. Atenția la tipul operanzilor atunci când o expresie trebuie să păstreze o parte fracționară.
