Introducere

În S5 ai învățat cele trei instrucțiuni de ciclare — while, do–while și for — și tiparele care se construiesc cu ele: contorul, acumulatorul și citirea până la o valoare santinelă. Bucla, așa cum a fost prezentată acolo, se oprește doar când condiția ei devine falsă, iar corpul se execută integral la fiecare iterație.

Această sesiune completează imaginea în trei direcții. Mai întâi, două instrucțiuni de salt, break și continue, care permit să părăsești o buclă mai devreme sau să sari peste restul unei iterații. Apoi, buclele imbricate (o buclă în corpul altei bucle), necesare oricând lucrezi cu „rânduri și coloane” sau cu perechi de valori. În fine, algoritmii elementari — numărare condiționată, maxim și minim, verificarea unei proprietăți, numere prime, divizori, cel mai mare divizor comun — construiți din același număr mic de tipare, pe care le combini.

Punct cheie

Aproape orice algoritm elementar se reduce la o buclă, una sau două variabile care păstrează starea calculului (un contor, un acumulator, un maxim, un indicator) și, de multe ori, un if în corpul buclei. Dacă recunoști tiparul, ai rezolvat mare parte din problemă.

Ce nu dezvoltăm încă în această sesiune

Toți algoritmii de aici prelucrează valorile pe măsură ce sunt citite sau generate, fără să le păstreze. De aceea nu putem încă să reparcurgem o secvență citită, să o sortăm sau să afișăm cifrele unui număr în ordinea corectă atunci când ele sunt obținute în ordine inversă — acestea cer tablouri, care vor fi introduse într-o sesiune ulterioară. Nu folosim nici funcții definite de utilizator: tot codul rămâne, ca până acum, în main. Conform structurii evaluării din pagina modulului, această sesiune este ultima dinaintea Testului practic 1.

  1. Utilizezi break pentru a ieși dintr-o buclă înainte ca ea să se termine natural
  2. Utilizezi continue pentru a sări peste restul iterației curente și explici diferența față de break
  3. Construiești bucle imbricate și stabilești de câte ori se execută corpul interior
  4. Urmărești pas cu pas execuția buclelor imbricate
  5. Explici pe ce buclă acționează break și continue în bucle imbricate și ieși din ambele bucle folosind un indicator
  6. Numeri elementele care îndeplinesc o condiție și determini maximul și minimul unei secvențe
  7. Verifici o proprietate de tip „există” sau „pentru toate” cu ajutorul unui indicator
  8. Verifici dacă un număr este prim și determini divizorii unui număr
  9. Calculezi cel mai mare divizor comun cu algoritmul lui Euclid și cel mai mic multiplu comun
  10. Aplici aceste tipare pe cifrele unui număr (cea mai mare cifră, palindrom)
  11. Identifici și corectezi erori frecvente și compari sintaxa din C++ cu cea din Java și Python

Instrucțiunea break — ieșirea dintr-o buclă

Instrucțiunea break întrerupe imediat execuția celei mai interioare bucle în care se află (while, do–while sau for), iar programul continuă cu prima instrucțiune de după buclă. Restul corpului din iterația curentă nu se mai execută, iar condiția buclei nu mai este verificată. Este același cuvânt cheie prin care switch își părăsește ramurile, dar aici el acționează asupra buclei.

începe iterația → s-a ajuns la break? → da → ieșire din buclă; se continuă după ea
s-a ajuns la break? → nu → restul corpului → următoarea iterație

Exemplu: căutăm cel mai mic divizor mai mare decât 1 al unui număr n ≥ 2. Încercăm pe rând d = 2, 3, 4, ... și ne oprim la primul care îl împarte pe n; nu are rost să continuăm.

C++ – primul divizor mai mare decât 1
int n;
cin >> n;

int d = 2;
while (d <= n) {
    if (n % d == 0) {
        break;
    }
    d++;
}

cout << d;

Pentru n = 15, urmărirea arată că bucla se încheie la a doua iterație, prin break, și nu prin condiția d <= n:

230n % d == 0 este adevărat → break; bucla se încheie

Se afișează 3. Dacă n este prim, primul divizor găsit este chiar n (pentru care n % d == 0 este adevărat), deci și în acest caz bucla se termină prin break.

Bucla infinită controlată: while (true)

Uneori motivul opririi apare abia în mijlocul corpului, după ce ai citit sau calculat ceva. În astfel de cazuri se folosește o buclă a cărei condiție este constanta true — deci nu se oprește niciodată prin condiție — și se iese din ea cu break când e cazul. Exemplu: citim un număr între 1 și 5, iar dacă valoarea este invalidă, cerem din nou.

C++ – validarea unei valori cu while (true)
int x;
while (true) {
    cin >> x;
    if (x >= 1 && x <= 5) {
        break;
    }
    cout << "Valoare invalida, reincercati: ";
}
cout << "Ati introdus: " << x;
while (true) nu este o greșeală

O buclă while (true) fără niciun break este într-adevăr infinită, dar când break există și este atins la un moment dat, construcția este perfect corectă. Rezultatul este cel al unui do–while (corpul se execută cel puțin o dată); diferența este că testul poate sta oriunde în corp, nu doar la sfârșit.

Când folosim break?

De regulă, dacă oprirea se poate exprima simplu în condiția buclei, este mai clar să o scrii acolo. break merită folosit atunci când motivul opririi este descoperit în interiorul corpului (ai găsit ce căutai, ai întâlnit o valoare invalidă) și rescrierea ar necesita o condiție compusă greu de citit.

Instrucțiunea continue — sărirea peste o iterație

Instrucțiunea continue oprește doar iterația curentă: instrucțiunile rămase din corp sunt sărite, iar execuția trece la pasul următor al buclei. Bucla în sine nu se încheie. Ce se execută imediat după continue depinde de tipul buclei: la while și do–while se trece direct la verificarea condiției, iar la for se execută mai întâi pasul (de exemplu i++) și abia apoi se verifică condiția.

continue într-un for → pasul (i++) → condiție?
continue într-un while → condiție?

Exemplu: calculăm suma numerelor de la 1 la n care nu sunt multipli de 3. Pentru fiecare multiplu de 3 sărim peste adunare.

C++ – suma numerelor care nu sunt multipli de 3
int n;
cin >> n;

long long suma = 0;
for (int i = 1; i <= n; i++) {
    if (i % 3 == 0) {
        continue;
    }
    suma += i;
}

cout << suma;

Atenție la continue într-un while

Deoarece continue sare peste restul corpului, o instrucțiune care modifică variabila din condiție și se află după el nu se mai execută pentru iterațiile sărite, iar bucla poate deveni infinită. La for problema nu apare, pentru că pasul se execută oricum. Vezi Eroarea 1 din secțiunea „Erori frecvente”.

Bucle imbricate

O buclă este imbricată atunci când apare în corpul altei bucle. Cea din exterior se numește buclă exterioară, iar cea din interior, buclă interioară. Pentru fiecare iterație a buclei exterioare, bucla interioară se execută de la început până la capăt — cu inițializarea ei refăcută — și abia apoi bucla exterioară trece la iterația următoare. Ca la un ceas: acul minutelor parcurge toate cele 60 de poziții pentru fiecare singură poziție a acului orelor.

C++ – 3 rânduri a câte 4 stele
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 4; j++) {
        cout << "*";
    }
    cout << endl;
}

Câte execuții are corpul interior?

Dacă limitele buclei interioare nu depind de bucla exterioară, corpul interior se execută de n · m ori (în primul exemplu, 3 · 4 = 12). Dacă limitele depind de variabila exterioară, trebuie numărate iterațiile interioare pentru fiecare valoare a lui i și adunate — vezi triunghiul de mai jos.

Limite care depind de bucla exterioară: triunghiul

C++ – triunghi de stele

        cout << "*";
    }
    cout << endl;
}
Se afișează

Limita superioară a buclei interioare este i, deci rândul i conține i stele, iar corpul interior se execută 1 + 2 + 3 + 4 = 10 ori. În general, pentru n rânduri, se execută n(n+1)/2 ori. Această sumă crește repede: pentru n = 1000 sunt peste 500 000 de execuții, iar pentru n = 100 000 peste 5 miliarde — de aceea, la bucle imbricate merită să estimezi de la început numărul de execuții.

Se pot imbrica oricare tipuri de bucle între ele: un while într-un for, un for într-un while, un do–while într-un while etc. În exercițiul 9 din laboratorul S5 ai folosit deja un while în interiorul altui while, pentru rădăcina digitală.

break și continue în bucle imbricate

break și continue acționează întotdeauna asupra celei mai interioare bucle care le conține. Un break din bucla interioară nu oprește bucla exterioară: aceasta își continuă iterațiile normal, iar bucla interioară va porni din nou la următoarea iterație exterioară.

C++ – break în bucla interioară
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 3; j++) {
        if (j == 2) {
            break;
        }
        cout << i << j << " ";
    }
}
// afiseaza: 11 21 31

Pentru fiecare i, bucla interioară afișează doar j = 1, apoi j ajunge la 2 și break o întrerupe; bucla exterioară trece însă la i următor. Cum ieșim, atunci, din ambele bucle? C++ nu are break cu etichetă (cum are Java); soluția obișnuită este un indicator verificat în condiția buclei exterioare.

C++ – prima pereche (i, j) cu i·j = 24, cu ieșire din ambele bucle
bool gasit = false;
for (int i = 1; i <= 9 && !gasit; i++) {
    for (int j = 1; j <= 9; j++) {
        if (i * j == 24) {
            cout << i << " " << j;
            gasit = true;
            break;
        }
    }
}

După break, bucla interioară se încheie; bucla exterioară execută pasul i++, apoi verifică condiția i <= 9 && !gasit, care acum este falsă (deoarece gasit este true), deci se încheie și ea. Observă că i a fost totuși incrementat o dată în plus înainte de ieșire: dacă ai nevoie de valorile găsite după buclă, salvează-le în variabile separate, nu te baza pe i și j.

Algoritmi elementari cu bucle

Un algoritm elementar rezolvă o problemă mică și foarte frecventă. Cei mai mulți se obțin combinând aceleași piese: o buclă care parcurge datele, variabile de stare inițializate corect înaintea buclei și un if care decide ce se întâmplă cu fiecare valoare. Parcurgem, în ordine, cele mai importante tipare.

Numărare condiționată

Este contorul din S5, dar incrementat numai când valoarea curentă îndeplinește o condiție. Exemplu: din n numere citite, câte sunt pare?

C++ – câte numere pare
int n, x;
cin >> n;

int nrPare = 0;
for (int i = 1; i <= n; i++) {
    cin >> x;
    if (x % 2 == 0) {
        nrPare++;
    }
}

cout << nrPare;
Paritatea numerelor negative

Verifică paritatea cu x % 2 == 0 (par) și x % 2 != 0 (impar), nu cu x % 2 == 1. În C++, restul unei împărțiri are semnul deîmpărțitului, deci -3 % 2 este -1, nu 1: un test x % 2 == 1 ar considera greșit numărul negativ -3 ca fiind neimpar.

Maximul și minimul unei secvențe

Ținem minte, în variabila maxim, cea mai mare valoare întâlnită până acum. La fiecare valoare nouă o comparăm cu maxim și, dacă este mai mare, o înlocuim. Așadar maxim nu se calculează la final: se actualizează pe parcurs, iar după ce s-a parcurs toată secvența el conține răspunsul. Pentru minim, procedăm identic, cu comparația inversată. Prima valoare citită este cea cu care inițializăm ambele variabile, iar bucla începe de la a doua.

C++ – maximul și minimul a n valori
int n, x;
cin >> n;

cin >> x;
int maxim = x;
int minim = x;

for (int i = 2; i <= n; i++) {
    cin >> x;
    if (x > maxim) {
        maxim = x;
    }
    if (x < minim) {
        minim = x;
    }
}

cout << maxim << " " << minim;

De ce nu inițializăm maximul cu 0?

Dacă toate valorile sunt negative, maxim = 0 ar rămâne neschimbat, iar rezultatul ar fi greșit: 0 nu se află în secvență. Inițializarea cu prima valoare citită funcționează pentru orice secvență nevidă. O alternativă este INT_MIN (pentru maxim), respectiv INT_MAX (pentru minim), constante din <climits> care reprezintă cea mai mică, respectiv cea mai mare valoare de tip int — orice valoare citită le înlocuiește.

C++ – maximul, inițializat cu INT_MIN
// necesita #include <climits>
int n, x;
cin >> n;

int maxim = INT_MIN;
for (int i = 1; i <= n; i++) {
    cin >> x;
    if (x > maxim) {
        maxim = x;
    }
}

cout << maxim;

Indicatori: „există” și „pentru toate”

Uneori nu ai nevoie de o valoare numerică, ci de un răspuns de tip da/nu: există cel puțin o valoare cu o anumită proprietate? Toate valorile au proprietatea? Pentru asta folosim o variabilă bool, numită indicator (în engleză, flag), care își schimbă valoarea o singură dată, când se întâmplă ceva. Cele două tipare sunt simetrice: pornim de la răspunsul „implicit” și îl contrazicem la prima excepție.

„Există” (cel puțin una)
bool exista = false;
while (...) {
    if (conditie) {
        exista = true;
        break;   // optional
    }
}
„Pentru toate”
bool toate = true;
while (...) {
    if (!conditie) {
        toate = false;
        break;   // optional
    }
}

break este opțional: fără el răspunsul rămâne corect, doar că bucla continuă inutil după ce indicatorul și-a primit valoarea finală. Iată două exemple pe cifrele unui număr: „conține numărul cifra 7?” și „sunt toate cifrele impare?”.

C++ – există cifra 7?
int n;
cin >> n;

bool areSapte = false;
while (n != 0) {
    if (n % 10 == 7) {
        areSapte = true;
        break;
    }
    n /= 10;
}

if (areSapte) {
    cout << "DA";
} else {
    cout << "NU";
}
C++ – toate cifrele sunt impare? (n ≥ 1)
int n;
cin >> n;

bool toateImpare = true;
while (n != 0) {
    if (n % 10 % 2 == 0) {
        toateImpare = false;
        break;
    }
    n /= 10;
}

if (toateImpare) {
    cout << "DA";
} else {
    cout << "NU";
}
Cazul limită n = 0

În al doilea exemplu am presupus n ≥ 1. Pentru n = 0 bucla nu s-ar executa, indicatorul ar rămâne true, iar programul ar afirma că „toate cifrele sunt impare”, deși cifra lui 0 este 0, pare. Când afirmația „pentru toate” se aplică unei mulțimi vide, ea este adevărată prin convenție, și trebuie să decizi dacă acest rezultat are sens în problema ta.

Divizori și numere prime

Un număr natural d este divizor al lui n dacă n % d == 0. Divizorii lui n se obțin printr-un simplu contor sau listare cu d de la 1 la n:

C++ – divizorii lui 12
int n = 12;
for (int d = 1; d <= n; d++) {
    if (n % d == 0) {
        cout << d << " ";
    }
}
// afiseaza: 1 2 3 4 6 12

Un număr natural n ≥ 2 este prim dacă are exact doi divizori, 1 și n. Numerele 0 și 1 nu sunt prime. Varianta directă de verificare încearcă toți d de la 2 la n − 1: dacă găsește un divizor, numărul nu este prim. Se poate mult mai eficient. Dacă n = a · b cu 1 < a ≤ b, atunci a · a ≤ a · b = n, deci cel mai mic divizor mai mare decât 1 al unui număr compus nu depășește √n. Este așadar suficient să verificăm d cât timp d * d <= n. Pentru un număr de ordinul 10⁹ asta înseamnă circa 31 600 de verificări, în loc de un miliard.

C++ – verificarea unui număr prim
int n;
cin >> n;

bool prim = true;
if (n < 2) {
    prim = false;
}

for (int d = 2; d * d <= n; d++) {
    if (n % d == 0) {
        prim = false;
        break;
    }
}

if (prim) {
    cout << "DA";
} else {
    cout << "NU";
}

Condiția d * d <= n se folosește în locul lui d <= sqrt(n) pentru a evita funcții de bibliotecă și erorile de rotunjire ale numerelor reale. Pentru n = 29, urmărirea este:

Cazurile 0 și 1

Pentru n = 0 sau n = 1, condiția d * d <= n (adică 4 <= n) este falsă de la început, deci bucla nu se execută și indicatorul ar rămâne true. Fără verificarea n < 2, aceste două numere ar fi declarate prime. Vezi Eroarea 4.

Cel mai mare divizor comun: algoritmul lui Euclid

În S5 ai calculat cmmdc prin scăderi repetate. Algoritmul lui Euclid folosește împărțiri: cel mai mare divizor comun al lui a și b este același cu cel al lui b și al restului împărțirii lui a la b. Se repetă până când restul devine 0; atunci ultimul împărțitor este cmmdc. Formal, cmmdc(a, b) = cmmdc(b, a % b) și cmmdc(a, 0) = a.

C++ – cmmdc prin algoritmul lui Euclid
int a, b;
cin >> a >> b;

while (b != 0) {
    int r = a % b;
    a = b;
    b = r;
}

cout << a;

Pentru a = 18, b = 24 (observă că, dacă a < b, prima iterație le interschimbă):

Pasabr = a % b(a, b) după pas
1182418(24, 18)
224186(18, 6)
31860(6, 0)

Când b devine 0, a = 6 este cmmdc-ul. Se poate arăta că numărul de împărțiri este mic chiar pentru numere mari: mult mai mic decât la scăderi. Pentru a = 1000000 și b = 1, metoda prin scăderi execută 999 999 de scăderi, în timp ce Euclid termină după o singură împărțire (1000000 % 1 este 0).

Cel mai mic multiplu comun. Pentru numere naturale nenule, cmmdc(a, b) · cmmmc(a, b) = a · b, de unde cmmmc = a / cmmdc * b. De exemplu, pentru 18 și 24: 18 · 24 = 432 = 6 · 72, deci cmmmc este 72. Împărțirea se face înainte de înmulțire (a / cmmdc * b, nu a * b / cmmdc): produsul a * b poate depăși limita tipului, chiar dacă rezultatul final ar încăpea în el. Pentru siguranță se folosește long long.

Algoritmi pe cifrele unui număr

În Python, o buclă for sau while poate avea o clauză else, care se execută numai dacă bucla s-a terminat natural, fără break.     print("NU")

    else:

Exerciții introductive (fără scriere de cod)

Rezolvă pe hârtie, apoi verifică cu răspunsul.

1Ce face instrucțiunea break și pe ce buclă acționează atunci când se află în interiorul unor bucle imbricate?

Vezi răspunsul

Întrerupe imediat execuția buclei celei mai interioare care o conține, iar programul continuă cu instrucțiunea de după acea buclă. Bucla exterioară nu este oprită: ea își continuă iterațiile.

2Într-o buclă for, ce se execută imediat după un continue?

Vezi răspunsul

Se sare peste restul corpului, se execută pasul buclei (de exemplu i++) și apoi se verifică condiția. Din acest motiv, continue într-un for nu produce buclă infinită prin lipsa incrementării, spre deosebire de while.

3Câte execuții are corpul interior al buclelor for (int i = 1; i <= 4; i++) și for (int j = 1; j <= 5; j++), imbricate una în alta?

Vezi răspunsul

4 · 5 = 20 de execuții. Limitele buclei interioare nu depind de i, deci numărul de execuții este produsul numerelor de iterații ale celor două bucle.

4Câte execuții are corpul interior al buclelor imbricate for (int i = 1; i <= n; i++) și for (int j = 1; j <= i; j++) pentru n = 6? Dar în general?

Vezi răspunsul

Pentru n = 6: 1 + 2 + 3 + 4 + 5 + 6 = 21. În general, 1 + 2 + ... + n = n(n+1)/2.

5De ce nu este corectă inițializarea int maxim = 0; când se caută cea mai mare valoare dintr-o secvență de numere întregi oarecare?

Vezi răspunsul

Dacă toate valorile sunt negative, nicio comparație x > maxim nu este adevărată, iar maxim rămâne 0 — o valoare care nu aparține secvenței. Corect este să inițializezi maxim cu prima valoare citită (sau cu INT_MIN).

6Ce valoare inițială are un indicator folosit pentru a verifica dacă există un element cu o proprietate? Dar unul folosit pentru a verifica dacă toate elementele au proprietatea?

Vezi răspunsul

Pentru „există”: false, care devine true la prima potrivire. Pentru „toate”: true, care devine false la prima excepție. Se pornește de la răspunsul implicit și se contrazice la prima dovadă.

7Pentru n = 97, de câte ori se execută corpul buclei for (int d = 2; d * d <= n; d++), dacă nu este întrerupt?

Vezi răspunsul

De 8 ori: d ia valorile 2, 3, ..., 9 (9 · 9 = 81 ≤ 97), iar pentru d = 10 avem 100 > 97. Cum 97 este prim, niciun d nu îl împarte, deci bucla nu este întreruptă.

8Câte împărțiri (calcule de rest) execută algoritmul lui Euclid pentru a = 48, b = 18, și care este rezultatul?

Vezi răspunsul

Trei: 48 % 18 = 12, apoi 18 % 12 = 6, apoi 12 % 6 = 0. Ultimul împărțitor nenul, 6, este cmmdc.

9De ce este suficient să căutăm divizori ai lui n doar până la √n, adică cât timp d * d <= n?

Vezi răspunsul

Dacă n = a · b cu 1 < a ≤ b, atunci a · a ≤ a · b = n, deci cel mai mic divizor mai mare decât 1 al unui număr compus satisface a * a <= n. Dacă un număr are un divizor propriu, îl vom găsi înainte ca d * d să depășească n; dacă nu găsim niciunul, numărul (≥ 2) este prim.

10Ce afișează int i = 0; do { i++; if (i == 2) { continue; } cout << i << " "; } while (i < 4);?

Vezi răspunsul

Se afișează 1 3 4. Pentru i = 2, continue sare peste afișare și duce la verificarea condiției i < 4, care este adevărată; bucla continuă. continue nu iese din buclă.

Restricții și precizări
  • 1 ≤ n ≤ 1.000.000.000
Exemplu
Se citește
100
Se afișează
24

Explicație: 100! se termină în 24 de zerouri.

Proiectarea algoritmului
  1. Un zero final provine dintr-un factor 10 = 2 · 5 al produsului. Factorii 2 sunt mai numeroși decât factorii 5, deci numărul de zerouri este exponentul lui 5 din descompunerea lui n!.
  2. Acest exponent este ⌊n/5⌋ + ⌊n/25⌋ + ⌊n/125⌋ + ...: multiplii lui 5 aduc câte un factor 5, multiplii lui 25 încă unul, ș.a.m.d.
  3. Bucla împarte n la 5 în mod repetat și adună câturile: după fiecare împărțire, n conține exact ⌊n/5^k⌋ pentru k-ul curent. Se oprește când n devine 0.
  4. Se afișează suma.
Cod C++
C++
int n;
cin >> n;

long long zerouri = 0;
while (n > 0) {
    n /= 5;
    zerouri += n;
}

cout << zerouri;

Cea mai lungă secvență de valori egale consecutiveGrea

Cerință

Se citește un număr natural n, apoi n numere întregi. Se afișează lungimea celei mai lungi secvențe de valori egale și consecutive din șir.

Date de intrare

Programul citește de la tastatură un întreg n, apoi n numere întregi.

Date de ieșire

Programul afișează lungimea maximă a unei secvențe de valori egale consecutive.

Restricții și precizări
  • 1 ≤ n ≤ 100.000
Exemplu
Se citește
9
1 1 2 2 2 3 3 2 2
Se afișează
3

Explicație: Secvențele sunt 1 1, 2 2 2, 3 3 și 2 2; cea mai lungă are lungimea 3.

Proiectarea algoritmului
  1. Se ține minte valoarea anterioară prev și lungimea secvenței curente curenta; maxRun păstrează cea mai mare lungime văzută. Cu prima valoare citită: prev = x, curenta = 1, maxRun = 1.
  2. Pentru fiecare valoare următoare x: dacă x == prev, secvența curentă continuă (curenta++); altfel începe una nouă (curenta = 1, prev = x).
  3. După fiecare valoare, dacă curenta > maxRun, se actualizează maxRun — este tiparul „maxim” din curs, aplicat pe lungimile secvențelor.
  4. Se afișează maxRun. Nu este nevoie de tablou: contează doar valoarea anterioară.
Cod C++
C++
int n, x;
cin >> n;

cin >> x;
int prev = x;
int curenta = 1;
int maxRun = 1;

for (int i = 2; i <= n; i++) {
    cin >> x;
    if (x == prev) {
        curenta++;
    } else {
        curenta = 1;
        prev = x;
    }
    if (curenta > maxRun) {
        maxRun = curenta;
    }
}

cout << maxRun;

Cerință

Se citește un număr natural n, apoi n numere întregi. Se afișează câte valori din șir sunt strict mai mari decât valoarea imediat anterioară (prima valoare nu are anterioară și nu se numără).

Date de intrare

Programul citește de la tastatură un întreg n, apoi n numere întregi.

Date de ieșire

Programul afișează numărul de valori mai mari decât precedenta.

Restricții și precizări
  • 1 ≤ n ≤ 100.000
Exemplu
Se citește
7
3 5 4 8 8 9 1
Se afișează
3

Explicație: 5 > 3, 8 > 4 și 9 > 8 sunt creșterile; 8 nu este mai mare decât 8, iar 4 și 1 sunt mai mici decât anterioarele.

Proiectarea algoritmului
  1. Se citește prima valoare în prev; contorul nr pornește de la 0.
  2. Pentru fiecare valoare următoare x: dacă x > prev, nr crește. Apoi prev = x, pentru a pregăti comparația următoare.
  3. Se afișează nr.
Cod C++
C++
int n, x;
cin >> n;

int prev;
cin >> prev;

int nr = 0;
for (int i = 2; i <= n; i++) {
    cin >> x;
    if (x > prev) {
        nr++;
    }
    prev = x;
}

cout << nr;

Întrebări de autoevaluare

1. Ce face break și pe ce buclă acționează atunci când se află în interiorul unor bucle imbricate?

Întrerupe imediat cea mai interioară buclă care îl conține, iar execuția continuă cu instrucțiunea de după acea buclă. Bucla exterioară nu este oprită.

2. Care este diferența esențială dintre break și continue?

break încheie complet bucla curentă; continue încheie doar iterația curentă, iar bucla trece la pasul următor (la for, se execută pasul și apoi se verifică condiția; la while și do–while, se verifică direct condiția).

3. De ce poate continue produce o buclă infinită într-un while și cum se evită?

Pentru că sare peste restul corpului, inclusiv peste instrucțiunea care modifică variabila din condiție, dacă aceasta se află după continue. Se evită mutând actualizarea înaintea lui continue sau folosind un for, la care pasul se execută oricum.

4. De câte ori se execută corpul interior al două bucle imbricate, cu n și m iterații independente? Dar dacă bucla interioară merge de la 1 la i?

În primul caz, de n · m ori. În al doilea, 1 + 2 + ... + n = n(n+1)/2 ori, deoarece pentru fiecare i bucla interioară are i iterații.

5. Cum se poate ieși din ambele bucle imbricate în C++?

C++ nu are break cu etichetă. Se folosește un indicator (de exemplu gasit), setat pe true înaintea lui break din bucla interioară și verificat în condiția buclei exterioare. Valorile găsite se salvează în variabile separate, pentru că pasul buclei exterioare se mai execută o dată înainte de ieșire.

6. Cum se determină cea mai mare valoare dintr-o secvență și de ce nu se inițializează maxim cu 0?

Se inițializează maxim cu prima valoare (sau cu INT_MIN), apoi, pentru fiecare valoare următoare mai mare decât maxim, se actualizează. Cu 0, rezultatul ar fi greșit pentru o secvență cu toate valorile negative, pentru că 0 nu se află în secvență.

7. Ce este un indicator (flag) și cu ce valoare se inițializează pentru „există” și pentru „pentru toate”?

Este o variabilă bool care își schimbă valoarea o singură dată, când apare un caz care schimbă răspunsul. Pentru „există” pornește de la false și devine true la prima potrivire; pentru „pentru toate” pornește de la true și devine false la prima excepție.

8. Când trebuie o variabilă de stare (indicator, acumulator) inițializată în interiorul buclei exterioare?

Când valoarea ei trebuie să pornească de la început pentru fiecare element al buclei exterioare — de exemplu, un indicator „conține cifra 7?” sau suma divizorilor unui număr, calculate separat pentru fiecare număr parcurs de bucla exterioară.

9. Cum se verifică dacă un număr este prim și de ce este suficient d * d <= n? Ce cazuri limită apar?

Se încearcă d = 2, 3, ...; dacă un d îl împarte pe n, numărul nu este prim. Dacă n = a · b cu 1 < a ≤ b, atunci a · a ≤ n, deci un număr compus are un divizor d cu d * d <= n. Numerele 0 și 1 nu sunt prime și trebuie tratate separat (n < 2), altfel bucla nu se execută și indicatorul rămâne true.

10. Cum funcționează algoritmul lui Euclid cu resturi și de ce este mai bun decât cel prin scăderi?

Se repetă r = a % b; a = b; b = r; până când b devine 0; atunci a este cmmdc. Folosește proprietatea cmmdc(a, b) = cmmdc(b, a % b). Necesită mult mai puțini pași: pentru a = 1000000, b = 1, scăderile execută 999 999 de pași, iar împărțirile, unul singur.

11. Cum se calculează cmmmc din cmmdc și de ce se face împărțirea înaintea înmulțirii?

Din cmmdc(a, b) · cmmmc(a, b) = a · b rezultă cmmmc = a / cmmdc * b. Împărțirea (exactă) se face întâi pentru ca valorile intermediare să rămână mici: produsul a * b poate depăși limita tipului, chiar dacă cmmmc încape în el. Se folosește long long.

12. Cum se verifică dacă un număr este palindrom, fără tablouri?

Se construiește inversul numărului cu inversul = inversul * 10 + cifra, extrăgând cifrele cu % 10 și / 10 dintr-o copie, și se compară cu numărul inițial. Inversul se păstrează într-un long long, deoarece poate depăși limita lui int.

13. Ce face clauza else a unei bucle for sau while din Python?

Se execută numai dacă bucla s-a terminat natural, fără să fi fost întreruptă de break. Este o particularitate a lui Python, utilă pentru tiparul „caută; dacă nu ai găsit, fă altceva”; C++ și Java nu au echivalent direct.

Rezumat – De reținut

Cele mai importante idei din această sesiune
  1. break încheie imediat cea mai interioară buclă în care se află; continue încheie doar iterația curentă, iar bucla continuă.
  2. La for, pasul se execută și după continue; la while și do–while, continue duce direct la verificarea condiției — de aceea, într-un while, actualizarea variabilei trebuie să preceadă continue.
  3. while (true) împreună cu break construiește o buclă a cărei oprire se decide în interiorul corpului.
  4. Într-o buclă imbricată, bucla interioară se execută complet pentru fiecare iterație a celei exterioare; fiecare buclă are propriul contor.
  5. Numărul de execuții ale corpului interior este produsul iterațiilor când limitele sunt independente (n · m) și suma iterațiilor interioare când limitele depind de bucla exterioară (de exemplu n(n+1)/2 pentru triunghi).
  6. Pentru a ieși din ambele bucle în C++, se folosește un indicator verificat în condiția buclei exterioare; break singur iese doar din cea interioară.
  7. Numărarea condiționată este un contor incrementat într-un if; maximul și minimul se inițializează cu prima valoare din secvență (sau cu INT_MIN / INT_MAX), nu cu 0.
  8. Un indicator (bool) răspunde la „există?” (pornește de la false) sau „pentru toate?” (pornește de la true); variabilele de stare care trebuie reluate pentru fiecare element al buclei exterioare se inițializează în interiorul ei.
  9. Un număr n ≥ 2 este prim dacă niciun d cu d * d <= n nu îl împarte; 0 și 1 nu sunt prime și se tratează separat.
  10. Algoritmul lui Euclid (r = a % b; a = b; b = r; până la b == 0) calculează cmmdc; cmmmc = a / cmmdc * b, cu împărțirea înaintea înmulțirii și long long.
  11. Pe cifrele unui număr (% 10, / 10) se aplică aceleași tipare: contor, maxim, indicator, invers (pentru palindrom).
  12. break și continue există și în Java și Python; Java are break cu etichetă, Python are clauza else pe bucle și nu are do–while.
