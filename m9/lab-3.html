1. De la model la definiție

Modelul Elev din Laboratorul 2 are trei câmpuri: nume (text), an (întreg) și media (real). În C++, același model se scrie cu cuvântul struct, urmat de numele structurii și, între acolade, de câmpurile ei: pentru fiecare câmp, tipul și numele. Textul se scrie ca vector de char; numărul din paranteze este dimensiunea vectorului și include și caracterul de sfârșit, deci char nume[30] păstrează cel mult 29 de litere (Laboratorul 1).

Anatomia definiției unei structuri în C++

    4char nume[30];
    4int an;
    4double media;

  • 2Numele tipului – devine un tip nou, ca int
  • 3Acoladele – încadrează lista de câmpuri
  • 4Câmpurile – câte unul pe linie: tip + nume + ;
  • 5Punct și virgulă – după acolada de închidere; uitarea lui este eroare

2. Declararea și inițializarea obiectelor

După ce tipul este definit, îl folosești ca pe orice alt tip: declari variabile (obiecte) de tipul Elev. La declarare poți să le dai și valori, în ordinea câmpurilor, între acolade. Mai jos, programul definește structura, creează un obiect cu valori și afișează câmpurile lui; același program este scris și în Java și în Python, unde nu există struct, iar rolul lui îl are o clasă care conține numai câmpuri.

Anatomia declarării unui obiect cu inițializare
1Elev 2e = 3{"Ana", 1, 9.5};
  • 1Tipul – structura definită mai sus
  • 2Numele obiectului – numele variabilei
  • 3Valorile – în ordinea câmpurilor: nume, an, media
Dacă dai mai puține valori, restul câmpurilor primesc 0.

Regulă: declarare și inițializare

Elev e; declară un obiect; Elev e = {"Ana", 1, 9.5}; îl declară și îi dă valori în ordinea câmpurilor. Un obiect declarat în main fără valori are câmpuri cu valori nedefinite (ca vectorul local din Laboratorul 1). Elev v[30]; declară un vector de 30 de obiecte.

3. Accesarea și modificarea câmpurilor

Un câmp al unui obiect se alege cu operatorul punct: e.an este câmpul an al obiectului e. El se poate citi, afișa și modifica ca orice variabilă de tipul lui. Un câmp de tip char[30] este un text, deci se modifică ca textele din M6: cu strcpy, nu cu =.

Anatomia accesării unui câmp
1e2.3an = 2;
1s2.3B2.3x
1st2.3note2[i]
  • 1Obiectul – variabila de tip structură
  • 2Punctul – operatorul de selecție; la câmpurile compuse se înlănțuie
  • 3Câmpul – alegi câmpul după nume
Citește de la stânga la dreapta, treaptă cu treaptă: s.B.x = câmpul x al câmpului B al lui s.
C++
#include <iostream>
#include <cstring>
using namespace std;

struct Elev {
    char nume[30];
    int an;
    double media;
};

int main() {
    Elev e = {"Ana", 1, 9.5};
    e.media = e.media - 0.5;
    strcpy(e.nume, "Bia");
    cout << e.nume << " " << e.an << " " << e.media << endl;
    return 0;
}

Regulă: accesul la câmpuri

obiect.camp alege câmpul după nume. Un câmp numeric se modifică cu =; un câmp text se modifică cu strcpy(obiect.camp, "text") (antet în <cstring>). Un nume de câmp care nu există în definiție este o eroare de compilare.

4. Citirea și afișarea unui obiect

Un obiect se citește și se afișează câmp cu câmp, în ordinea pe care o alegi tu. Programul citește de la tastatură numele, anul și media unui elev (numele este un cuvânt, fără spații) și le afișează într-o formă mai prietenoasă.

C++
#include <iostream>
using namespace std;

struct Elev {
    char nume[30];
    int an;
    double media;
};

int main() {
    Elev e;
    cin >> e.nume >> e.an >> e.media;
    cout << e.nume << ", anul " << e.an << ", media " << e.media << endl;
    return 0;
}

5. Copierea și compararea obiectelor

Atribuirea b = a; între două obiecte de același tip copiază câmp cu câmp, inclusiv textele din interior (verificat mai jos; regula este descrisă pe cppreference). După copiere, a și b sunt obiecte independente. Observă contrastul cu vectorii: un vector întreg nu se poate copia cu = (Laboratorul 1), dar un vector aflat într-o structură se copiază odată cu ea.

6. Vectori de structuri

Un vector de structuri este un vector ale cărui elemente sunt fișe. Elev e[30]; declară 30 de fișe; e[i] este fișa cu numărul i, iar e[i].media este rubrica ei. Parcurgerea, căutarea maximului și celelalte modele din M6 se aplică la fel, dar compari câmpul care contează. Programul citește n elevi și afișează elevul cu media cea mai mare.

C++
#include <iostream>
using namespace std;

struct Elev {
    char nume[30];
    int an;
    double media;
};

int main() {
    Elev e[30];
    int n;
    cin >> n;
    for (int i = 0; i < n; i++) {
        cin >> e[i].nume >> e[i].an >> e[i].media;
    }
    int best = 0;
    for (int i = 1; i < n; i++) {
        if (e[i].media > e[best].media) {
            best = i;
        }
    }
    cout << e[best].nume << " " << e[best].media << endl;
    return 0;
}

    char nume[30];
    int an;
    double media;

        cin >> e[i].nume >> e[i].an >> e[i].media;
    }
    for (int i = 0; i < n - 1; i++) {
        for (int j = i + 1; j < n; j++) {
            if (e[j].media > e[i].media) {
                Elev t = e[i];
                e[i] = e[j];
                e[j] = t;
            }
        }
    }
    for (int i = 0; i < n; i++) {
        cout << e[i].nume << " " << e[i].media << endl;
    }
    return 0;
}

Elev e[30]; are 30 de obiecte; e[i].camp alege câmpul fișei i. Căutarea maximului, căutarea și ordonarea se scriu ca la vectorii simpli, comparând câmpul potrivit. La ordonare se interschimbă obiecte întregi (Elev t = e[i]; e[i] = e[j]; e[j] = t;), nu câmpuri separate.

7. Structuri și subprograme

Un subprogram poate primi un obiect ca parametru și poate returna un obiect. Întrebarea importantă este: dacă subprogramul modifică obiectul primit, se schimbă și obiectul din apelant? Răspunsul depinde de felul în care este transmis parametrul. În C++ există două feluri:

Prin valoare și prin referință: ce se întâmplă cu a.an
Prin valoare: f(Elev e)
a.an1
e.an (copie)5

subprogramul modifică copia; a rămâne 1

Prin referință: f(Elev &e)
a.an = e.an5

subprogramul lucrează pe chiar obiectul a; devine 5

Regulă: & în antet = modificările se văd în apelant. citeste → cu &; afiseaza → fără.
  • prin valoare (void f(Elev e)): subprogramul primește o copie a obiectului; ce modifică în interior nu se vede în apelant;
  • prin referință (void f(Elev &e), cu semnul &): subprogramul lucrează pe chiar obiectul din apelant; modificările se văd.
C++
#include <iostream>
using namespace std;

struct Elev {
    char nume[30];
    int an;
    double media;
};

void prinValoare(Elev e) {
    e.an = 5;
}

void prinReferinta(Elev &e) {
    e.an = 5;
}

int main() {
    Elev a = {"Ana", 1, 9.5};
    prinValoare(a);
    cout << a.an << endl;
    prinReferinta(a);
    cout << a.an << endl;
    return 0;
}

#include <iostream>
using namespace std;

struct Punct {
    int x;
    int y;
};

    Punct m;
    m.x = (a.x + b.x) / 2;
    m.y = (a.y + b.y) / 2;
    return m;
}

int main() {
    Punct p = {0, 0};
    Punct q = {4, 6};
    Punct m = mijloc(p, q);
    cout << m.x << " " << m.y << endl;
    return 0;
}

Regulă: structuri ca parametri

Transmiterea prin valoare (Elev e) copiază obiectul: apelantul rămâne neschimbat. Un subprogram poate returna un obiect, cu tipul structurii ca tip returnat. Observația despre Java și Python este verificată pe aceste exemple; nu o extinde la alte tipuri de argumente.

8. Structuri din structuri și câmpuri-vector

Compunerea din modelul de hârtie se scrie la fel în cod: un câmp are ca tip altă structură (definită înainte) sau un vector. Selecția se face în trepte: s.B.x alege întâi capătul B, apoi coordonata x. Pentru un câmp-vector, indicele se pune după numele câmpului: st.note[2].

C++
#include <iostream>
using namespace std;

struct Punct {
    int x;
    int y;
};

struct Segment {
    Punct A;
    Punct B;
};

struct Student {
    char nume[30];
    int note[3];
};

int main() {
    Segment s = {{0, 0}, {3, 4}};
    s.B.x = s.A.x + 1;
    cout << s.B.x << " " << s.B.y << endl;

    Student st = {"Ana", {9, 10, 8}};
    int suma = 0;
    for (int i = 0; i < 3; i++) {
        suma += st.note[i];
    }
    cout << st.nume << " " << suma << endl;
    return 0;
}

Regulă: câmpuri compuse

Tipul unui câmp structură trebuie definit înaintea structurii care îl conține. Inițializarea se scrie cu acolade în acolade, în ordinea câmpurilor. s.B.x se citește de la stânga la dreapta, treaptă cu treaptă; st.note[i] alege elementul i al câmpului-vector.

9. Erori frecvente

Eroarea 1 – Lipsește ; după acolada structurii

Este cea mai frecventă greșeală la prima structură. Mesajul poate părea ciudat, pentru că este raportat pe linia următoare definiției.

g++ – mesajul real
pv.cpp:7:2: error: expected ‘;’ after struct definition

Eroarea 2 – Câmp inexistent sau scris greșit

g++ – mesajul real
camp.cpp:11:15: error: ‘struct Elev’ has no member named ‘medie’; did you mean ‘media’?

Compilatorul spune exact ce câmp nu există; compară numele cu cel din definiție.

Eroarea 3 – Obiect neinițializat

Un obiect local declarat fără valori (Elev e;) are câmpuri cu valori nedefinite. Dacă le afișezi înainte să le completezi, programul poate afișa orice. Inițializează obiectul la declarare (Elev e = {}; pune 0 în câmpurile numerice) sau citește-l imediat.

Eroarea 4 – Domeniu nerespectat

Structura nu verifică domeniul (Laboratorul 2). Un elev cu media 150 sau o fracție cu numitorul 0 se creează fără nicio eroare; verificarea cade pe programul care citește sau modifică datele. Un exemplu de verificare la citire este în exercițiul P6.

Eroarea 5 – Interschimbarea câmpurilor, nu a fișelor

La ordonare, interschimbarea trebuie să mute obiecte întregi. Dacă interschimbi doar e[i].media cu e[j].media, numele rămân pe loc și datele devin false, exact ca la vectorii paraleli.

Cerință

Se citesc două fracții (numărător, numitor). Afișează suma lor, simplificată, în forma numărător/numitor.

Model și plan
  1. Model: Fractie = (numarator, numitor), cu numitor diferit de 0.
  2. Plan: funcția aduna primește două fracții și returnează o fracție nouă: a/b + c/d = (a·d + c·b)/(b·d); funcția cmmdc simplifică rezultatul.
  3. Verificare pe hârtie: 1/2 + 3/4 = (1·4 + 3·2)/8 = 10/8 = 5/4.
Program
C++
#include <iostream>
using namespace std;

struct Fractie {
    int numarator;
    int numitor;
};

int cmmdc(int a, int b) {
    while (b != 0) {
        int r = a % b;
        a = b;
        b = r;
    }
    return a;
}

Fractie aduna(Fractie x, Fractie y) {
    Fractie r;
    r.numarator = x.numarator * y.numitor + y.numarator * x.numitor;
    r.numitor = x.numitor * y.numitor;
    int d = cmmdc(r.numarator, r.numitor);
    r.numarator /= d;
    r.numitor /= d;
    return r;
}

int main() {
    Fractie a, b;
    cin >> a.numarator >> a.numitor;
    cin >> b.numarator >> b.numitor;
    Fractie s = aduna(a, b);
    cout << s.numarator << "/" << s.numitor << endl;
    return 0;
}

#include <iostream>
#include <cmath>
#include <iomanip>
using namespace std;

struct Punct {
    int x;
    int y;
};

struct Segment {
    Punct A;
    Punct B;
};

double lungime(Segment s) {
    int dx = s.B.x - s.A.x;
    int dy = s.B.y - s.A.y;

    for (int i = 1; i < n; i++) {
        if (lungime(s[i]) > maxim) {
            maxim = lungime(s[i]);
        }
    }
    cout << fixed << setprecision(2) << maxim << endl;

}

Întrebări de autoevaluare

1. Cum scrii în C++ o structură cu câmpurile nume (text), an (întreg) și media (real)?

struct Elev { char nume[30]; int an; double media; }; — cu ; după acolada de închidere.

2. Ce descrie definiția unei structuri și ce nu face?

Descrie tipul (câmpurile și tipurile lor). Nu creează obiecte și nu verifică domeniul valorilor.

3. Cum inițializezi un obiect la declarare? Ce se întâmplă cu câmpurile pentru care nu dai valori?

Cu acolade, în ordinea câmpurilor: Elev e = {"Ana", 1, 9.5};. Câmpurile fără valoare primesc 0 (verificat prin rulare).

4. Cum modifici un câmp text al unui obiect?

Cu strcpy(e.nume, "Bia");; atribuirea directă nu compilează.

5. Cum citești și cum afișezi un obiect?

Câmp cu câmp: cin >> e.nume >> e.an; și cout << e.nume;. cin >> e și cout << e nu sunt definite pentru o structură simplă.

6. Ce face b = a; și de ce nu merge a == b?

Copiază câmp cu câmp; obiectele rămân independente. == nu este definit pe structuri simple, deci egalitatea se scrie explicit, comparând câmpurile.

7. Cum ordonezi un vector de structuri?

Ca un vector simplu, comparând câmpul potrivit; la interschimbare se mută obiectul întreg, nu câmpuri separate.

8. Care este diferența dintre transmiterea prin valoare și prin referință?

Prin valoare, subprogramul lucrează pe o copie; prin referință (&), pe obiectul din apelant, deci modificările se văd.

9. Cum se selectează o coordonată dintr-un câmp-structură?

În trepte: s.B.x — întâi câmpul B al lui s, apoi câmpul x al acestuia.

10. Cum arată un câmp-vector în cod?

Se declară ca orice vector (int note[3];), iar elementul i se alege cu st.note[i].

11. Cum deosebești o eroare de lipsă a lui ; după structură?

Compilatorul o raportează pe linia următoare definiției; primul lucru de verificat este acolada de închidere a structurii.

  6. Un vector de structuri se parcurge, se caută în el și se ordonează ca un vector simplu; la interschimbare se mută fișe întregi.
  7. Parametrul prin valoare primește o copie, cel prin referință (&) lucrează pe obiectul din apelant.
  8. Câmpurile pot fi structuri sau vectori; selecția se face în trepte.
  9. Structura nu verifică domeniul; verificarea rămâne în programul care citește sau modifică datele.
