Introducere

În M6 ai scris programe în care datele erau variabile izolate sau vectori de valori de același fel: un vector de numere întregi, un vector de numere reale. Cât timp o problemă are un singur fel de date, această organizare este suficientă. Lucrurile se complică atunci când un același „obiect din lumea reală”, de exemplu un student, are mai multe caracteristici de tipuri diferite: un nume (text) și o notă (număr real). Cum le ții împreună?

Acest laborator are trei scopuri. Primul este practic: același program minim este compilat și rulat în C++, Java și Python, pentru ca mediul de lucru să nu mai fie o necunoscută în laboratoarele următoare. Al doilea este să vezi, pe un exemplu care funcționează în toate cele trei limbaje, de ce vectorii de valori „paralele” sunt o soluție fragilă. Al treilea este să faci primul pas către programarea orientată pe obiecte: definirea unui tip nou, care grupează datele care aparțin împreună. Operațiile asupra acestor date (metodele) apar abia în Laboratorul 1.

Mediul de lucru: de la fișierul sursă la program

Un fișier sursă este un fișier text care conține codul scris de programator. Calculatorul nu îl poate executa direct, iar drumul de la sursă la program care rulează diferă de la un limbaj la altul. În C++, compilatorul (de exemplu g++) traduce fișierul sursă într-un fișier executabil, pe care sistemul de operare îl poate rula. În Java, compilatorul javac produce un fișier .class care conține bytecode, iar comanda java pornește mașina virtuală Java (JVM), care execută acel bytecode. În Python, programul se dă direct interpretorului (python3), care îl rulează fără ca tu să creezi un executabil.

Toate cele trei programe afișează același mesaj, dar structura lor diferă. În C++, execuția pornește din funcția main, iar cout vine din biblioteca inclusă cu #include <iostream>. 💡
Clasic: „C++ e compilat, Java e interpretat, Python e interpretat”

Formularea este prea simplă. Java este mai întâi compilat (în bytecode) și abia apoi bytecode-ul este executat de JVM. Documentația Python spune că Python este un limbaj interpretat, dar adaugă că distincția „poate fi neclară din cauza compilatorului de bytecode”: codul sursă este compilat în bytecode, intern, în implementarea CPython, iar acesta este executat de o mașină virtuală. Corect este să descrii ce pași apar și ce produce fiecare, nu să aplici o etichetă unică limbajului. Mai mult, un limbaj nu este în sine „compilat” sau „interpretat”: modul de execuție ține de implementare. Aici vorbim despre g++, javac + JVM și CPython.

Reamintire: subprograme

Un subprogram (numit în C++ și Python funcție, în Java metodă) este o secvență de instrucțiuni cu un nume, care poate fi apelată de oricâte ori și, la nevoie, primește date și returnează un rezultat. Definiția conține tipul returnat (în C++ și Java), numele, lista de parametri și corpul; apelul scrie numele și, între paranteze, valorile (argumentele) cu care se execută. Tipul void arată că subprogramul nu returnează nicio valoare, iar instrucțiunea return încheie execuția și trimite rezultatul. Variabilele declarate în interiorul unui subprogram sunt locale: există numai cât timp se execută el. Chiar main este un subprogram, cel din care pornește execuția în C++ și Java.

Programul de mai jos conține trei subprograme: maxim returnează cel mai mare dintre două numere, afiseazaNota afișează un mesaj și nu returnează nimic, iar incearcaSaSchimbi modifică parametrul primit. Ultimul arată un fapt important: pentru un număr întreg trimis ca argument, subprogramul lucrează pe propria lui valoare, iar variabila din care a fost luat argumentul nu se schimbă.

C++ · functii.cpp
#include <iostream>
using namespace std;

int maxim(int a, int b) {
    if (a > b) {
        return a;
    }
    return b;
}

void afiseazaNota(double nota) {
    cout << "Nota: " << nota << endl;
}

void incearcaSaSchimbi(int x) {
    x = 100;
    cout << "in functie: " << x << endl;
}

int main() {
    int m = maxim(7, 12);
    cout << m << endl;
    afiseazaNota(9.5);

    int y = 5;
    incearcaSaSchimbi(y);
    cout << y << endl;
    return 0;
}

Problema: date care aparțin împreună, ținute separat

Fie trei studenți, fiecare cu un nume și o notă. Cu ce știi din M6, soluția naturală este un vector pentru nume și un vector pentru note, în care elementele cu același indice se referă la același student: nume[0] și nota[0] descriu primul student. Legătura dintre cei doi vectori nu este înscrisă nicăieri în program, ci există numai în mintea programatorului. Este suficient să uiți această legătură într-un singur loc pentru ca datele să devină false, fără ca vreun compilator să protesteze.

Programul de mai jos ordonează studenții descrescător după notă, cu metoda bulelor din S7, dar interschimbă doar notele. Numele rămân pe loc.

C++ · paralele.cpp
#include <iostream>
using namespace std;

int main() {
    char nume[3][20] = {"Ana", "Bogdan", "Cezar"};
    double nota[3] = {7.0, 9.5, 8.5};

    // sortare descrescatoare dupa nota (metoda bulelor), dar se muta DOAR notele
    for (int i = 0; i < 2; i++) {
        for (int j = 0; j < 2 - i; j++) {
            if (nota[j] < nota[j + 1]) {
                double aux = nota[j];
                nota[j] = nota[j + 1];
                nota[j + 1] = aux;
            }
        }
    }

    for (int i = 0; i < 3; i++) {
        cout << nume[i] << " " << nota[i] << endl;
    }
    return 0;
}

Programul se compilează și rulează fără nicio eroare, dar rezultatul este fals: Ana, care avea nota 7, apare acum cu 9.5, iar Cezar, care avea 8.5, apare cu 7. Dacă studentul ar fi avut și alte caracteristici (grupa, anul), fiecare interschimbare ar fi cerut o variabilă ajutătoare și o interschimbare pentru fiecare dintre vectori, iar uitarea unuia dintre ei ar fi produs aceeași eroare tăcută.

⚠️
Diferența de afișare pentru 7.0

Observă ultima linie: C++ afișează 7, iar Java și Python afișează 7.0. Valoarea din memorie este aceeași, 7.0; diferă doar regulile de afișare ale fiecărui limbaj. Nu o confunda cu o diferență a datelor.

Soluția: un tip nou care grupează datele

Un tip definit de programator descrie un grup de date care aparțin aceluiași lucru. Datele din grup se numesc câmpuri (în engleză fields sau members), fiecare având un nume și un tip. O instanță a tipului este o valoare concretă, care conține câte o valoare pentru fiecare câmp: pentru tipul Student cu câmpurile nume și nota, „Ana, 7.0” este o instanță. Câmpul unei instanțe se accesează cu operatorul punct: s.nota înseamnă „câmpul nota al instanței s”.

În C++ cuvântul cheie folosit în acest laborator este struct. În Java și în Python se folosește class; în Laboratorul 1 vei vedea că o clasă poate conține nu doar date, ci și operații asupra lor. Aici clasele Java și Python conțin numai câmpuri, deci joacă același rol ca un struct.

C++ – tipul Student ca struct; numele este un vector de char
struct Student {
    char nume[20];
    double nota;
};
Java – tipul Student ca clasă cu două câmpuri
class Student {
    String nume;
    double nota;
}
Python – clasă goală; câmpurile apar la atribuire
class Student:
    pass


s = Student()
s.nume = "Ana"
s.nota = 7.0

În C++, un vector de char nu poate primi un text prin atribuire: s.nume = "Ana"; nu se compilează. Textul se copiază cu strcpy din <cstring>, ca în exercițiile tale cu char[]: strcpy(s.nume, "Ana");. Mesajul real al lui g++ 13.3 pentru atribuirea directă este:

g++
atrib.cpp: In function ‘int main()’:
atrib.cpp:11:12: error: incompatible types in assignment of ‘const char [4]’ to ‘char [20]’
   11 |     s.nume = "Ana";
      |     ~~~~~~~^~~~~~~

Observă diferența din Python: clasa nu declară câmpurile. Un obiect Python primește un atribut în momentul în care i se atribuie o valoare, de exemplu s.nume = "Ana"; clasa Student de mai sus este doar un „recipient” gol. Acesta este un mod de lucru adecvat pentru acest laborator, dar nu singurul și nu cel obișnuit în programele mai mari; modul uzual, cu un inițializator, este tratat mai târziu (vezi sesiunea X).

Un vector de instanțe

Cu tipul Student definit, cei trei studenți formează un singur vector, iar interschimbarea a două elemente mută cu totul un student, cu nume și notă. Programul de mai jos face aceeași sortare ca mai înainte, dar rezultatul este corect.

C++ · inregistrare.cpp
#include <iostream>
#include <cstring>
using namespace std;

struct Student {
    char nume[20];
    double nota;
};

int main() {
    Student s[3];
    strcpy(s[0].nume, "Ana");    s[0].nota = 7.0;
    strcpy(s[1].nume, "Bogdan"); s[1].nota = 9.5;
    strcpy(s[2].nume, "Cezar");  s[2].nota = 8.5;

    // sortare descrescatoare dupa nota: se interschimba Studentii intregi
    for (int i = 0; i < 2; i++) {
        for (int j = 0; j < 2 - i; j++) {
            if (s[j].nota < s[j + 1].nota) {
                Student aux = s[j];
                s[j] = s[j + 1];
                s[j + 1] = aux;
            }
        }
    }

    for (int i = 0; i < 3; i++) {
        cout << s[i].nume << " " << s[i].nota << endl;
    }
    return 0;
}

LimbajCe este un element al vectoruluiCe face aux = s[j]
C++un Student întreg, păstrat chiar în vectorcreează o copie a studentului (se copiază fiecare câmp); atribuirea s[j] = s[j + 1] copiază și ea câmpurile

Pentru C++, atribuirea de copiere generată automat pentru un tip cu câmpuri copiază câmp cu câmp, iar un câmp care este vector (aici nume) este copiat element cu element (cppreference, Copy assignment operator). Pentru Java, o variabilă de tip clasă nu conține obiectul, ci o referință la el, iar copierea unei referințe nu copiază obiectul (JLS 4.3.1). Pentru Python, documentația spune că atribuirile nu copiază date, ci doar leagă nume de obiecte (Python Tutorial, cap. 9). Consecințele acestei diferențe sunt tema centrală a Laboratorului 1.

⚠️
Java: crearea vectorului nu creează studenții

În Java, new Student[3] creează un vector cu trei locuri pentru referințe, toate având inițial valoarea null (JLS 4.12.5), adică nu indică niciun obiect. De aceea programul Java de mai sus are o buclă care execută s[i] = new Student(); pentru fiecare loc. În C++, Student s[3]; creează direct trei instanțe. În Python, lista pornește goală și primește obiecte prin append.

Erori frecvente

Eroarea 1 – Ai uitat un caracter obligatoriu (; sau o paranteză)

Cu o instrucțiune neterminată, programul nici nu pornește. Mesajele cele mai utile sunt primele: ele spun fișierul, linia și ce lipsește. Mesajele de mai jos sunt cele reale produse de g++ 13.3, javac 21 și Python 3.13 pentru programul „Salut, POO!” din care s-a șters ; (în C++ și Java), respectiv paranteza de închidere (în Python).

g++ – primele 3 linii ale mesajului
e1.cpp: In function ‘int main()’:
e1.cpp:5:34: error: expected ‘;’ before ‘return’
    5 |     cout << "Salut, POO!" << endl
javac
E1.java:3: error: ';' expected
        System.out.println("Salut, POO!")
                                         ^
1 error
python3
    print("Salut, POO!"
         ^
SyntaxError: '(' was never closed

Observă că g++ indică linia 5 (cout), deși ; trebuia pus la sfârșitul ei: compilatorul își dă seama de lipsă abia când întâlnește return pe linia următoare. Locul unde se vede eroarea nu coincide întotdeauna cu locul unde a apărut. În Python, mesajul se referă la paranteza deschisă, nu la finalul fișierului.

Eroarea 2 – Numele clasei publice nu coincide cu numele fișierului (Java)

Fișierul E2.java conține clasa publică Altceva. Compilarea cu javac eșuează:

javac E2.java
E2.java:1: error: class Altceva is public, should be declared in a file named Altceva.java
public class Altceva {
       ^
1 error

Regula este impusă de javac, nu de limbajul Java în sine: specificația limbajului (JLS 7.6) spune că sistemul gazdă poate impune ca un tip public să se afle într-un fișier cu același nume, dacă pachetele sunt păstrate într-un sistem de fișiere. În practică, folosind javac, trebuie să respecți regula: clasa publică Hello se află în Hello.java.

Eroarea 3 – Folosești un element al vectorului Java înainte de new

Java – greșit: elementul s[0] este null
Student[] s = new Student[3];
s[0].nume = "Ana";     // s[0] nu indică niciun obiect

Programul se compilează, dar oprește execuția cu o excepție. Mesajul real produs de JDK 21 este:

java Npe
Exception in thread "main" java.lang.NullPointerException: Cannot assign field "nume" because "<local1>[0]" is null
	at Npe.main(Npe.java:9)

Mesajul exact poate diferi între versiuni ale JDK; ce rămâne constant este tipul excepției, NullPointerException. Remediul este să creezi mai întâi obiectul: s[0] = new Student();.

Eroarea 4 – Vectori paraleli desincronizați

Este eroarea din secțiunea anterioară: rezultatul este fals, dar programul nu semnalează nimic. Singurul remediu este să nu mai separi datele care aparțin împreună, adică să folosești un tip care le grupează.

Media notelor dintr-un vector de studențiUșoară

Cerință

Un vector conține trei studenți: Ana (7.0), Bogdan (9.5) și Cezar (8.5). Se afișează media notelor lor.

Proiectarea algoritmului
  1. Se creează vectorul de studenți (în Java, fiecare loc primește un new Student()).

    for (int i = 0; i < 3; i++) {
        suma += s[i].nota;
    }

}

4Un student are nume, nota, grupa și anul de studiu. Câți vectori paraleli ar fi necesari? Câte interschimbări de elemente trebuie scrise pentru a muta un student, cu vectori paraleli, respectiv cu un vector de instanțe? Propus de autor

Patru vectori paraleli, deci patru interschimbări (fiecare cu variabila ei ajutătoare). Cu un vector de instanțe este nevoie de o singură interschimbare, cea a elementelor vectorului.

Vezi răspunsul

C++ afișează 7, iar Java afișează 7.0 (rezultatele programelor din această pagină). Valoarea din memorie este aceeași; diferă regulile de afișare.

6Ce conține s[0] imediat după Student[] s = new Student[3]; în Java? Dar după Student s[3]; în C++? Propus de autor

Vezi răspunsul

În Java, s[0] este null: un loc pentru referință, care nu indică încă niciun obiect (JLS 4.12.5). În C++, s[0] este deja un obiect Student, creat prin inițializare implicită; câmpurile lui, nume (vector de char) și nota (double), rămân neinițializate (valori nedeterminate), deci citirea lor înainte de atribuire nu este permisă (cppreference, Default-initialization).

7Un fișier Python conține, pe linia 1, print("a") și, pe linia 2, print("b" (fără paranteza de închidere). Se va afișa „a”? Propus de autor

Vezi răspunsul

Nu. Fișierul este compilat în întregime înainte de execuție, deci eroarea de sintaxă din linia 2 este raportată înainte să se execute linia 1. Verificat prin rulare cu Python 3.13: se afișează numai mesajul SyntaxError.

8În secvența Student aux = s[j]; s[j] = s[j + 1]; s[j + 1] = aux;, ce se mută efectiv în C++, în Java și în Python? Propus de autor

Vezi răspunsul

În C++ se copiază câmpurile fiecărui student, deoarece elementele vectorului sunt chiar instanțele. În Java și în Python elementele vectorului (listei) sunt referințe, deci se interschimbă referințele, iar obiectele nu se mută și nu se copiază. Rezultatul vizibil al sortării este același în cele trei limbaje.

9Ce afișează programul din secțiunea „Reamintire: subprograme” după apelul incearcaSaSchimbi(y), pentru y = 5? De ce? Propus de autor

Vezi răspunsul

Se afișează 5 (după linia „in functie: 100”). Subprogramul a modificat propria valoare a parametrului x, nu variabila y din apelant; ieșirile reale sunt în secțiunea respectivă. Concluzia este verificată doar pentru argumente numerice.

Vezi răspunsul

maxim returnează un int prin return, iar rezultatul se folosește (int m = maxim(7, 12);). afiseazaNota este void: nu returnează nimic, ci doar afișează un mesaj.

Code Tracing – Exerciții

Urmărește execuția fără să rulezi programul. Notează valorile câmpurilor la fiecare pas și ce se va afișa; apoi verifică rulând codul. Exercițiile sunt propuse de autor, iar soluțiile au fost verificate prin rulare.

Exercițiul 1 — copierea unei instanțe în C++
C++ (tipul Student ca în secțiunea anterioară)
struct Student {
    char nume[20];
    double nota;
};

Student a;
strcpy(a.nume, "Ana");
a.nota = 6.0;
Student b = a;
b.nota = b.nota + 2;
cout << a.nota << " " << b.nota;

Soluție: Student b = a; creează o copie a lui a, cu nota = 6.0. Apoi se modifică numai b, care ajunge la 8. Se afișează 6 8 (C++ nu afișează partea fracționară nulă).

Exercițiul 2 — interschimbarea a două instanțe
C++
Student s[2];
strcpy(s[0].nume, "Ana");    s[0].nota = 5.0;
strcpy(s[1].nume, "Bogdan"); s[1].nota = 9.0;
Student aux = s[0];
s[0] = s[1];
s[1] = aux;
cout << s[0].nume << " " << s[1].nume;

Soluție: aux primește o copie a lui s[0] (Ana). s[0] = s[1] copiază câmpurile lui Bogdan peste s[0]. s[1] = aux copiază câmpurile lui Ana în s[1]. Vectorul este acum Bogdan, Ana. Se afișează Bogdan Ana.

Exercițiul 3 — același cod ca în exercițiul 1, în Python
Python
class Student:
    pass


a = Student()
a.nota = 6
b = a
b.nota = b.nota + 2

Soluție: spre deosebire de C++, b = a nu creează o copie: a și b sunt două nume pentru același obiect. Modificarea b.nota = b.nota + 2 se vede și prin a. Se afișează 8 8. (În Java, o secvență echivalentă dă același rezultat: b = a copiază referința.)

Vezi răspunsul

Un atribut al unui obiect Python este creat în momentul atribuirii (s.nota = 7.0). Dacă nu a fost atribuit, citirea lui produce o eroare de execuție, AttributeError. Este o diferență față de C++ și Java, unde câmpurile sunt declarate în tip și toate instanțele le au.

2Scrie, în Java, secvența care creează un vector de două Student și le completează (Ana 7.0, Bogdan 9.5), apoi spune câte obiecte Student există după execuție. Propus de autor

Vezi răspunsul

Sunt două obiecte (nu trei): vectorul conține referințe, iar vectorul în sine nu este un Student.

Java
Student[] s = new Student[2];
s[0] = new Student();
s[1] = new Student();
s[0].nume = "Ana";    s[0].nota = 7.0;
s[1].nume = "Bogdan"; s[1].nota = 9.5;

3Programul C++ Student s; cout << s.nota; compilează fără probleme. Este corect să-l folosești pentru a afișa o notă implicită? Răspunde cu ajutorul sursei. Propus de autor

Vezi răspunsul

Nu. Pentru un obiect cu durată de stocare automată, câmpul nota, de tip scalar, nu primește nicio valoare la declarare și are o valoare nedeterminată; până la C++23, citirea unei astfel de valori este comportament nedefinit, iar C++26 înlocuiește regula cu „comportament eronat” (cppreference, Default-initialization). Indiferent de standard, nu se citește un câmp înainte de a-l fi completat.

Întrebări de autoevaluare

0. Ce este un subprogram și ce înseamnă void?

Un subprogram este o secvență de instrucțiuni cu nume, apelabilă de oricâte ori, care poate primi parametri și poate returna un rezultat. void arată că nu returnează nicio valoare. În Java se numește metodă.

1. Ce produce fiecare dintre comenzile g++ ... -o hello, javac Hello.java și python3 hello.py?

Prima produce un fișier executabil, a doua un fișier Hello.class cu bytecode (executat apoi de JVM prin java Hello), iar a treia rulează direct programul, fără ca tu să obții un fișier executabil. În CPython, sursa este totuși compilată intern în bytecode (Python, glosar).

2. De ce nu este corectă afirmația „Python este interpretat, deci nu este compilat”?

Documentația Python spune că distincția dintre limbaje interpretate și compilate „poate fi neclară” din cauza compilatorului de bytecode: în CPython, sursa este compilată în bytecode, care apoi este executat de o mașină virtuală. Mai precis, termenii descriu implementări, nu limbaje în sine.

3. Ce sunt vectorii paraleli și care este riscul lor?

Sunt doi sau mai mulți vectori în care elementele cu același indice descriu același lucru. Riscul este desincronizarea: dacă o operație (de exemplu, o interschimbare) este aplicată unuia dintre vectori și uitată pe celălalt, datele devin false fără nicio eroare de compilare sau de execuție.

4. Ce este un câmp și cum se accesează?

Un câmp este o dată cu nume și tip, aparținând unui tip definit de programator. Se accesează prin operatorul punct pe o instanță: s.nota.

5. Ce este o instanță? Dă un exemplu.

O valoare concretă a unui tip definit de programator, cu câte o valoare pentru fiecare câmp. De exemplu, „Ana, 7.0” este o instanță a tipului Student.

6. Ce conține un vector Java de tip Student[] imediat după crearea cu new Student[3]?

Trei referințe cu valoarea null (JLS 4.12.5). Obiectele trebuie create separat, cu new Student().

7. Ce se întâmplă la Student aux = s[j]; în C++, Java și Python?

În C++ se creează o copie a instanței (câmp cu câmp). În Java se copiază referința, iar în Python numele aux este legat de același obiect, deci în ambele limbaje nu apare un obiect nou.

8. De ce se afișează 7 în C++ și 7.0 în Java pentru aceeași valoare?

Valoarea din memorie este aceeași. Diferă regulile de afișare ale cout, respectiv ale System.out.println.

Rezumat – De reținut

✅
Cele mai importante idei din acest laborator
  1. Drumul de la sursă la program diferă: executabil în C++, bytecode (.class) executat de JVM în Java, rulare directă prin interpretor în Python (care compilează totuși intern în bytecode).
  2. Citește mesajul de eroare: el indică fișierul, linia și, de obicei, ce lipsește. Locul unde se vede eroarea nu este mereu locul unde a apărut.
  3. Datele care aparțin aceluiași lucru nu se păstrează în vectori paraleli: orice operație uitată pe unul dintre vectori produce date false, fără nicio eroare.
  4. Un tip definit de programator grupează câmpuri; o instanță are o valoare pentru fiecare câmp; câmpul se accesează cu ..
  5. Tiparele din M6 (acumulator, maxim cu poziție, sortare) se aplică neschimbat pe un vector de instanțe; se reține indicele.
  6. Un subprogram are tip returnat (C++, Java), nume, parametri și corp; se apelează cu nume(argumente). Pentru un argument numeric, variabila din apelant nu este modificată de subprogram.
  7. Elementele unui vector C++ de instanțe sunt instanțele însele; în Java și Python sunt referințe la obiecte. În Java, new Student[3] nu creează studenții.
