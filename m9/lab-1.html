Introducere

În Laboratorul 0 ai grupat datele care aparțin împreună într-un tip nou. Totuși, operațiile asupra acestor date au rămas în afara tipului: dacă ai nevoie de aria unui dreptunghi, scrii d.latime * d.inaltime în fiecare loc din program unde ai nevoie de ea. Dacă formula trebuie schimbată, trebuie găsite și modificate toate locurile. Mai grav, nimic din program nu spune că acea formulă „aparține” dreptunghiului.

O clasă rezolvă problema, deoarece pune în același loc datele și operațiile care le folosesc. Dreptunghiul își știe lățimea, înălțimea și felul în care își calculează aria; programul doar îi cere „spune-mi aria”. Acest laborator introduce vocabularul de bază (clasă, obiect, câmp, metodă, instanțiere) și insistă pe o întrebare care produce confuzii chiar și la programatori experimentați: ce se întâmplă atunci când scrii b = a pentru două obiecte?

Clasă și obiect: definiții

O clasă este un tip definit de programator care descrie, pentru toate obiectele de același fel, datele pe care le au (numite câmpuri, sau atribute) și operațiile pe care le pot executa (numite metode). Un obiect (numit și instanță a clasei) este o realizare concretă a unei clase, cu propriile valori pentru câmpuri. Instanțierea este crearea unui obiect pornind de la o clasă. O metodă este o funcție definită în interiorul unei clase, care se apelează pe un obiect, de exemplu a.arie(), și lucrează cu câmpurile acelui obiect.

În limba română, „clasa” este planul, iar „obiectul” este ceea ce construiești după plan. Clasa Dreptunghi spune că orice dreptunghi are o lățime, o înălțime și o arie calculabilă; obiectul a este un anumit dreptunghi, de 4 pe 3. Din aceeași clasă poți crea oricâte obiecte, iar fiecare are propriile valori ale câmpurilor.

Confuzii clasice

1. Clasă și obiect nu sunt același lucru. Dreptunghi este clasa; a și b sunt obiecte. Clasa descrie, obiectul există în program cu valori concrete.

2. În Java și Python, variabila a nu este obiectul. Variabila conține o referință către obiect. Specificația Java spune că variabilele de tip clasă păstrează referințe, nu obiecte, iar copierea unei referințe nu copiază obiectul (JLS 4.3.1). Documentația Python spune că „atribuirile nu copiază date, ci doar leagă nume de obiecte”.

3. class și struct în C++ sunt aproape identice. Conform cppreference, ele diferă doar prin accesul implicit la membri (și la clasele de bază). Putem verifica diferența direct: într-un struct, câmpul se poate accesa din main; într-un class, nu (vezi „Erori frecvente”).

4. Metoda nu este o funcție oarecare. Ea aparține clasei și lucrează pe obiectul pe care este apelată.

Definirea unei clase

Clasa Dreptunghi are două câmpuri întregi (latime și inaltime) și trei metode: arie, perimetru și scaleaza. Fiecare metodă este scrisă cu tipul returnat, numele, o listă de parametri între paranteze și un corp între acolade. Tipul void înseamnă „nu returnează nicio valoare”; în rest, valoarea se returnează cu return. Metoda scaleaza(int k) primește un parametru, k, și modifică ambele câmpuri.

C++ – class Dreptunghi
class Dreptunghi {
public:
    int latime = 0;
    int inaltime = 0;

    int arie() {
        return latime * inaltime;
    }

    int perimetru() {
        return 2 * (latime + inaltime);
    }

    void scaleaza(int k) {
        latime = latime * k;
        inaltime = inaltime * k;
    }
};

Mai multe detalii merită observate. În C++ scriem public: pentru ca membrii să poată fi folosiți din afara clasei, pentru că într-un class accesul implicit este privat; controlul accesului este tratat într-o sesiune ulterioară (vezi sesiunea X). Declarația int latime = 0; din interiorul clasei dă câmpului o valoare inițială, iar în C++ forma aceasta este permisă începând cu C++11 (cppreference, Class declaration). În Java nu scriem aici niciun modificator de acces; subiectul este amânat (vezi sesiunea X).

În Python, metodele au un prim parametru, numit prin convenție self, prin care primesc obiectul pe care sunt apelate; câmpurile se acced prin self.latime. Documentația spune că numele self este doar o convenție, fără o semnificație specială pentru limbaj. Apelul a.arie() este echivalent cu Dreptunghi.arie(a) (Python Tutorial, cap. 9). În C++ și Java, metoda folosește direct numele câmpurilor; this există și poate fi scris explicit (this->latime în C++, this.latime în Java), dar în acest laborator nu este necesar.

⚠️
Python: valoarea implicită este un atribut al clasei, nu al obiectului

Liniile latime = 0 și inaltime = 0, scrise direct în clasa Python, creează atribute ale clasei, partajate de toate obiectele care nu au propria valoare. Documentația le numește variabile de clasă și le recomandă pentru date comune, nu pentru date proprii fiecărei instanțe. Le folosim aici doar ca să dăm obiectelor o valoare implicită fără un inițializator. Modul obișnuit de a crea câmpuri proprii fiecărui obiect, __init__, este tratat mai târziu (vezi sesiunea X).

Atribuirea a.latime = 4 nu modifică atributul clasei: creează un atribut al obiectului a. Rezultatul rulării programului de mai jos arată diferența:

Instanțierea și accesul la membri

Crearea unui obiect se face diferit în cele trei limbaje, dar rezultatul este similar. În C++, declararea Dreptunghi a; creează direct un obiect. În Java, new Dreptunghi() creează obiectul, iar variabila a primește o referință către el. În Python, apelul Dreptunghi() creează obiectul, iar numele a este legat de el. Odată creat, obiectul are propriile câmpuri, iar acestea se accesează cu operatorul punct; metodele se apelează tot cu punct, urmate de paranteze: a.arie().

Obiectele create din aceeași clasă sunt independente: modificarea unuia nu o schimbă pe a celuilalt. Programul următor definește o clasă Contor cu un câmp și două metode, creează două contoare și le modifică separat.

C++
#include <iostream>
using namespace std;

class Contor {
public:
    int valoare = 0;

    void creste() {
        valoare = valoare + 1;
    }

    void reseteaza() {
        valoare = 0;
    }
};

int main() {
    Contor c;
    Contor d;
    c.creste();
    c.creste();
    c.creste();
    d.creste();
    cout << c.valoare << " " << d.valoare << endl;
    c.reseteaza();
    cout << c.valoare << " " << d.valoare << endl;
    return 0;
}

Copierea și referința: ce înseamnă b = a

Aceasta este diferența cea mai importantă dintre cele trei limbaje. Programul de mai jos creează un dreptunghi a de 4 pe 3, execută b = a (prin Dreptunghi b = a; în C++ și Java, și b = a în Python) și apoi dublează dimensiunile lui b. Ce se întâmplă cu a?

C++
#include <iostream>
using namespace std;

class Dreptunghi {
public:
    int latime = 0;
    int inaltime = 0;

    int arie() {
        return latime * inaltime;
    }

    int perimetru() {
        return 2 * (latime + inaltime);
    }

    void scaleaza(int k) {
        latime = latime * k;
        inaltime = inaltime * k;
    }
};

int main() {
    Dreptunghi a;            // obiect nou; câmpurile primesc 0 din declarație
    a.latime = 4;
    a.inaltime = 3;

    Dreptunghi b = a;        // C++: b este o COPIE a lui a
    b.scaleaza(2);

    cout << "a: " << a.latime << "x" << a.inaltime << " arie=" << a.arie() << endl;
    cout << "b: " << b.latime << "x" << b.inaltime << " arie=" << b.arie() << endl;
    return 0;
}

Nu extinde regula unui limbaj la celelalte

Același cod aparent, b = a, are efecte diferite. Nu poți deduce din comportamentul unui limbaj ce se întâmplă în altul. Comportamentul C++ de aici (copiere) este cel implicit pentru tipurile de clasă folosite așa: atribuirea de copiere generată automat copiază câmp cu câmp (cppreference, Copy assignment operator). C++ are și mecanisme care permit comportament apropiat de cel din Java, prin pointeri sau referințe, dar ele nu fac obiectul acestui laborator (vezi sesiunea X).

Copia reală, în Java și Python

Când ai nevoie de un obiect nou, independent, cu aceleași valori, în Java și în Python îl creezi explicit și îi copiezi câmpurile. Același procedeu funcționează și în C++. Programul de mai jos face acest lucru: c este un obiect separat, deci modificarea lui nu schimbă pe a.

Un vector de obiecte

Tiparele din M6 se aplică neschimbat. Programul următor reține, într-un vector de trei dreptunghiuri, poziția celui cu aria cea mai mare. Nu se reține aria: din poziție se obțin atât dreptunghiul, cât și aria lui. Ca în Laboratorul 0, în Java fiecare element trebuie creat cu new.

C++
#include <iostream>
using namespace std;

class Dreptunghi {
public:
    int latime = 0;
    int inaltime = 0;

    int arie() {
        return latime * inaltime;
    }
};

int main() {
    Dreptunghi d[3];
    d[0].latime = 2;  d[0].inaltime = 3;
    d[1].latime = 5;  d[1].inaltime = 1;
    d[2].latime = 4;  d[2].inaltime = 4;

    int poz = 0;
    for (int i = 1; i < 3; i++) {
        if (d[i].arie() > d[poz].arie()) {
            poz = i;
        }
    }
    cout << "Dreptunghiul " << poz + 1 << " are aria " << d[poz].arie() << endl;
    return 0;
}

Cerință

Un vector conține trei dreptunghiuri, cu dimensiunile 2×3, 5×1 și 4×4. Afișează poziția (de la 1) și aria celui cu aria maximă.

Proiectarea algoritmului
  1. Se folosește clasa Dreptunghi, cu metoda arie().
  2. Se aplică tiparul maxim cu poziție: poz = 0, apoi, pentru i de la 1, dacă d[i].arie() > d[poz].arie() atunci poz = i.

Vezi răspunsul

Întrebări de autoevaluare

1. Ce este o clasă și ce este un obiect?

Clasa este un tip definit de programator care descrie datele (câmpuri) și operațiile (metode) comune obiectelor de același fel. Obiectul (instanța) este o realizare concretă a clasei, cu propriile valori ale câmpurilor.

2. Ce este instanțierea și cum se face în C++, Java și Python?

Este crearea unui obiect pornind de la o clasă. În C++: Dreptunghi a;. În Java: Dreptunghi a = new Dreptunghi();. În Python: a = Dreptunghi().

3. Ce este o metodă și cum se deosebește de o funcție obișnuită?

O metodă este o funcție definită într-o clasă, apelată pe un obiect (a.arie()), care lucrează cu câmpurile acelui obiect.

4. Cum accesează o metodă câmpurile obiectului pe care este apelată?

În C++ și Java folosește direct numele câmpului (opțional this). În Python primește obiectul ca prim parametru, self, și scrie self.latime.

5. Ce efect are b = a în C++, Java și Python?

În C++ se creează o copie a obiectului (câmp cu câmp). În Java se copiază referința, deci a și b indică același obiect. În Python numele b este legat de același obiect ca a.

6. Cum obții o copie independentă a unui obiect în Java sau Python?

Creezi un obiect nou și îi copiezi câmpurile unul câte unul (de regulă într-o metodă numită, de exemplu, copie()).

7. Ce valoare au câmpurile unui obiect la creare, în fiecare limbaj?

În C++ și Java, câmpul cu valoare dată în clasă o primește. Fără valoare dată: în Java, valoarea implicită după tip (0, 0.0, false, null); în C++, pentru un obiect local, un câmp scalar are valoare nedeterminată. În Python, câmpul nu există până la prima atribuire (sau este vizibil atributul clasei, dacă există).

8. Ce este NullPointerException și când apare?

Este excepția Java produsă când folosești o referință null ca și cum ar indica un obiect, de exemplu un element al unui vector creat cu new, dar necompletat cu obiecte.

9. De ce un atribut de clasă de tip listă, în Python, este o capcană?

Pentru că este partajat de toate obiectele clasei: modificarea listei prin unul dintre obiecte este vizibilă prin toate (Python Tutorial, cap. 9).

10. Prin ce diferă class și struct în C++?

Sunt aproape identice; diferă prin accesul implicit la membri: privat pentru class, public pentru struct (cppreference, Class declaration; verificat prin compilare).

Rezumat – De reținut

✅
Cele mai importante idei din acest laborator
  1. O clasă descrie câmpurile și metodele comune; un obiect este o instanță concretă, cu propriile valori. Din aceeași clasă se pot crea oricâte obiecte independente.
  2. O metodă se definește în clasă și se apelează pe un obiect: a.arie(). Ea lucrează cu câmpurile acelui obiect (this opțional în C++ și Java; self obligatoriu în Python).
  3. b = a copiază obiectul în C++ și copiază referința în Java și Python. Nu extinde regula unui limbaj la celelalte.
  4. Pentru o copie independentă în Java și Python, creezi un obiect nou și îi copiezi câmpurile.
  5. Câmpurile C++ cu valoare dată în clasă sunt inițializate; fără valoare, un câmp scalar al unui obiect local este nedeterminat. În Java, câmpurile au valori implicite, iar variabilele locale nu.
  6. În Java, un vector de obiecte conține inițial null; fiecare obiect trebuie creat cu new.
  7. În Python, un atribut de clasă este partajat; unul mutabil (listă) este o capcană. Atribuirea a.x = ... creează un atribut al obiectului, nu modifică clasa.
  8. Tiparele din M6 (maxim cu poziție, acumulator, căutare) se aplică neschimbat pe vectori de obiecte.
